# LearningAssistant 业务梳理文档

> **文档说明**：梳理 LearningAssistant 的用户角色、核心业务流程和用户痛点（已对照 2026-08 最新代码补全细化）。

---

## 一、用户角色

| 角色名称 | 角色描述 | 核心目标 | 主要使用场景 | 占比估算 |
|---------|---------|---------|-------------|---------|
| **主动学习者** | 有明确学习目标，主动规划学习的用户 | 高效记忆知识、达成学习目标 | 日常学习、复习、目标管理、查看统计数据 | 60% |
| **应试备考者** | 应对考试（语言/学科/职业）的用户 | 短时高效突破、错题强化 | 集中刷题、错题复习、趣味游戏巩固、模拟测试 | 25% |
| **兴趣探索者** | 碎片化时间学习、兴趣驱动的用户 | 轻松获取知识、保持学习习惯 | 碎片学习、收藏浏览、AI 对话、内置浏览器摘录 | 10% |
| **内容管理者** | 大量导入/整理学习内容的用户 | 高效管理知识库、内容分类 | 批量导入、目录管理、PDF 提炼、标签整理 | 5% |

## 二、核心业务流程

### 2.1 主学习流程

```mermaid
flowchart TD
    A[启动应用] --> B[选择/切换用户]
    B --> C[选择学科+子类别]
    C --> D{选择学习模式}
    D -->|学习模式| E[顺序学习新内容]
    D -->|快速模式| F[快速浏览+标记]
    D -->|复习模式| G[间隔重复复习]
    E --> H[展示学习卡片]
    F --> H
    G --> H
    H --> I[用户操作: 认识/不认识/详情]
    I -->|认识| J[标记为已知 + XP奖励]
    I -->|不认识| K[标记为未知 + 加入复习队列]
    I -->|查看详情| L[展开释义/例句/发音]
    J --> M{是否继续?}
    K --> M
    L --> M
    M -->|是| H
    M -->|否| N[学习统计 + 成就结算]
    N --> O[返回主界面]
```

> 说明：错题本 / 收藏夹 / 学习路径 / 导入内容均可通过 `UnifiedStudyEntryService` 统一接入该学习流程（P-001 已落地）。

### 2.2 AI 增强学习流程

```mermaid
flowchart TD
    A[学习卡片界面] -->|触发AI| B{选择AI功能}
    B -->|AI 问答| C[向AI提问当前知识点]
    B -->|AI 导师| D[导师对话式深度讲解]
    B -->|费曼学习| E[用户输出理解 + AI评估]
    B -->|渐进提示| F[层层递进的提示引导]
    C --> G[AI 生成回答]
    D --> G
    E --> G
    F --> G
    G --> H[保存对话/笔记]
    H --> I[返回学习流程]
```

> 最新代码已提供统一 AI 侧边栏（`AIAgentSidebarPanel`）与能力面板（`AIAbilityPanel`），多厂商（Deepseek/豆包/OpenAI 兼容）自动回退。

### 2.3 PDF 深度阅读流程

```mermaid
flowchart TD
    A[打开PDF文件] --> B[PDF渲染展示]
    B --> C{用户操作}
    C -->|高亮文本| D[创建高亮标注]
    C -->|添加书签| E[添加页签书签]
    C -->|OCR识别| F[图片文字识别]
    C -->|翻译| G[选中文本翻译]
    C -->|TTS朗读| H[语音朗读文本]
    C -->|加入学习| I[提取内容→学习项]
    D --> J[高亮同步到学习系统]
    I --> K[导入学习队列]
    J --> L[继续阅读]
    E --> L
    F --> L
    G --> L
    H --> L
    K --> M[跳转到学习模块]
```

> 最新代码通过 `PdfStudyIntegration` + `HighlightSyncService` 实现 PDF 与学习系统的双向打通。

### 2.4 游戏化巩固流程（新增）

```mermaid
flowchart TD
    A[主界面/学习结果] --> B{选择趣味学习}
    B -->|单词消消乐| C[WebView2 游戏]
    B -->|记忆翻牌| D[配对翻牌]
    B -->|连连看| E[连线消除]
    B -->|打地鼠| F[快速反应]
    B -->|拼写| G[单词拼写]
    C --> H[游戏结果反馈]
    D --> H
    E --> H
    F --> H
    G --> H
    H --> I[错题回写 + XP/成就结算]
    I --> J[返回学习]
```

### 2.5 数据统计与报告流程（目标流程，当前处于初始版本）

```mermaid
flowchart TD
    A[学习/复习/番茄/游戏等行为] --> B[统一统计聚合]
    B --> C[概览指标]
    B --> D[趋势/分类/记忆/热力图]
    B --> E[错题/目标分析]
    B --> F[日/周/月报告]
    C --> G[首页 Dashboard]
    D --> H[学习数据中心]
    E --> H
    F --> I[报告展示 + 导出/AI总结]
    G --> J[点击进入数据中心]
```

> ⚠️ 现状：该流程目前**未打通**——统计数据多源、时长未记录、统计入口失效（见问题清单 W-004~W-010）。本流程为《优化改进方案.md》的目标形态。

## 三、用户痛点分析

| 痛点编号 | 痛点描述 | 影响角色 | 痛点等级 | 对应现有功能 | 改善方向 |
|---------|---------|---------|---------|-------------|---------|
| P-001 | 学习入口分散，不同来源的内容学习体验不一致 | 主动学习者 | 🔴 高 | 学习/错题/收藏/路径各自为政 | ✅ 已通过 `UnifiedStudyEntryService` 统一接入学习引擎 |
| P-002 | AI 能力分散在多个面板，切换繁琐 | 全部角色 | 🟠 中高 | 问答/导师/费曼/提示各独立 | ✅ 已新增统一 AI 侧边栏，可继续整合 |
| P-003 | 大量学习项时加载慢、卡顿 | 内容管理者 | 🔴 高 | 全量加载到内存 | 分页+虚拟列表+懒加载 |
| P-004 | 学习推荐不够智能，难以针对性强化薄弱点 | 应试备考者 | 🟠 中高 | 基础推荐算法 | ✅ 已新增 `LearningRecommendationService`，可继续结合薄弱点分析 |
| P-005 | 数据安全担忧，本地存储易丢失 | 全部角色 | 🟠 中高 | 百度网盘备份 | ✅ 已新增本地 `BackupService` 多 Provider 备份 |
| P-006 | 学习反馈不够及时，难以保持动力 | 兴趣探索者 | 🟡 中 | 游戏化系统已有基础 | ✅ 已新增趣味游戏、即时反馈、鼓励机制 |
| P-007 | **学习数据统计维度单一，无法深度分析** | 主动学习者 | 🔴 高 | 初始版本图表统计，未与项目结合 | 统一统计底座 + 学习数据中心 + AI 报告（见优化方案） |
| P-008 | 移动端缺失，只能在电脑前学习 | 全部角色 | 🔴 高 | 纯桌面端 | 移动端/Web端规划（远期） |
| P-009 | **首页用户切换交互不灵活（下拉框）、新增按钮与设置重复** | 全部角色 | 🟠 中高 | 顶部下拉 + ➕ 按钮 | 头像+浮层面板切换，删除重复按钮（见优化方案） |
| P-010 | **学习时长统计失真（`TimeSpentMinutes` 无赋值点）** | 主动学习者 | 🔴 高 | 时长类统计/报告 | 补时长写入，口径可配置（见优化方案） |

## 四、业务要点总结

1. 产品已从"基础记忆工具"演进为**学习工作台**：新增统一学习入口、智能推荐、趣味游戏、内置浏览器、PDF 学习打通、百度网盘 AI 分析、本地备份。
2. 当前**最大的业务短板是数据统计/图表/报告**（初始版本、未打通、入口失效、时长失真），是下一阶段核心优化对象。
3. **多用户体验**（切换不灵活、入口重复）是需要顺手清理的交互问题。
