 
# LearningAssistant 产品UI/UX优化提示词


## 一、角色与目标

**角色定位**：
你是一位资深产品设计师兼教育科技（EdTech）交互专家，专精于将复杂的学习理论（如间隔重复、主动回忆、费曼学习法）转化为直观、沉浸式的界面体验。你擅长通过"事件驱动"设计，让孤立的功能模块产生化学反应，形成完整的学习闭环。

**核心目标**：
在不新增功能模块的前提下，解决当前 LearningAssistant 存在的三大核心问题：
1. **功能孤岛**：各模块（成就、挑战、复习、联想、费曼等）之间缺乏联动，数据不互通。
2. **交互断裂**：教学闭环不完整（如渐进提示无正误反馈），用户缺乏方向感。
3. **体验割裂**：AI能力分散在不同页面，用户需频繁跳转才能获取完整学习支持。


## 二、UI视觉统一规范（先立规矩）

在逐模块优化之前，先建立一套全产品统一的设计语言，确保所有界面的一致性。

### 2.1 设计令牌

| 设计元素 | 规范值 |
|----------|--------|
| 主品牌色 | `#6C5CE7`（紫罗兰，代表智慧与创造力） |
| 成功/掌握色 | `#00B894`（翠绿，代表正确与进步） |
| 危险/未掌握色 | `#FF7675`（珊瑚红，代表错误与提醒） |
| 警告/待办色 | `#FDCB6E`（琥珀黄，代表待复习与挑战） |
| 卡片圆角 | 主卡片 12px / 徽章及图标 50% / 按钮 8px |
| 主按钮高度 | 40px，字号 14px，字重 Medium |
| 正文字号 | 14px，行高 1.6 |
| 标题字号 | 20px，字重 Semibold |
| 间距系统 | 4px / 8px / 16px / 24px / 32px（四的倍数） |
| 阴影层级 | 轻微（卡片悬浮）: 0 2px 8px rgba(0,0,0,0.06）<br>中等（弹窗/浮层）: 0 8px 32px rgba(0,0,0,0.12） |
| 空状态组件 | 统一格式：**[插画区（160px）] + [标题（16px, Bold）] + [描述（14px, 二级文字色）] + [主行动按钮]** |

### 2.2 进度展示规范

| 使用场景 | 推荐组件 |
|----------|----------|
| 学习项进度（如 12/409） | 线性进度条 + 百分比数字 |
| 成就/等级进度 | 环形进度条（带圆端头） |
| 列表内单项完成度 | 数字 + 百分比（如 42%），配合微型线性条 |
| 每日挑战整体进度 | 大环形进度 + 文字说明（如"完成 1/4 · 25%"） |

### 2.3 空状态统一规范

**所有空状态统一采用以下四要素结构：**

| 要素 | 规范 |
|------|------|
| 插图 | 160×160px SVG插画（灰色调，带轻微装饰） |
| 主标题 | 16px，Bold，主文字色（如"今日复习已清空"） |
| 描述文字 | 14px，二级文字色（如"太棒了！今日所有复习任务已完成"） |
| 行动按钮 | 主色填充按钮（如"去学习新知识 →"） |

**适用页面**：复习空状态、推荐列表空状态、错题本为空、收藏夹为空。


## 三、各模块逐项优化需求

### 3.1 成就系统

**现状问题**：进度展示冰冷（仅"42%"和"3/7"数字），解锁状态区分度弱（仅靠"✅已解锁"文字），缺乏仪式感和惊喜感。

**优化需求**：

1. **徽章可视化改造**
   - 将每个成就设计为卡片形式，包含：**成就图标（48×48px） + 名称 + 描述 + 进度**
   - 未解锁状态：图标显示为**灰色剪影 + 🔒锁头标记**
   - 已解锁状态：图标为**彩色渐变**，卡片带微光晕边框
   - 解锁瞬间触发**庆祝粒子动画**（撒花/星星飘散，持续1.5秒）

2. **进度展示优化**
   - 将"42%"替换为**环形进度条**（直径40px，圆端头stroke，宽度4px）
   - 将"3/7"改为**星级显示**（★☆☆☆☆☆），已完成的用实心星标亮

3. **隐藏成就彩蛋**
   - 设计3-5个隐藏成就（如"凌晨学者"、"周末战士"），未解锁时完全不可见
   - 达成条件时触发**全屏祝贺弹窗**（深色蒙层 + 成就名称 + 特殊音效）

4. **分类筛选优化**
   - 当前"全部/学习/坚持/精通/特殊"tab样式需增强视觉反馈：选中态加下划线（4px主色）或背景色块，文字从Regular切换为Semibold
   - 每个tab后显示该分类已解锁数量小角标（如"学习 3"）


### 3.2 每日挑战

**现状问题**：任务卡片与学习入口割裂（用户看到"答对10道题"却不知道去哪里做），奖励领取交互不清晰，缺乏倒计时紧迫感。

**优化需求**：

1. **任务即入口（核心改造）**
   - 每个任务卡片整体可点击（不只是按钮）
   - 点击后**直接跳转**到对应的学习/功能界面，并自动应用所需的过滤条件
   - 具体映射关系：
     - "答对10道题" → 跳转到「快速学习模式」，自动选择用户常用的学科
     - "今天至少学习一次" → 跳转到「首页推荐学习项」
     - "收藏5个内容" → 跳转到「PDF阅读器」或「学习页」，并弹出收藏引导浮层

2. **奖励领取交互增强**
   - "领取奖励"按钮点击后触发**XP数字向上飘动动画**（+5 XP从按钮位置飘到左上角XP总数位置）
   - 配合**金币入袋音效**（可用Web Audio API合成简短清脆提示音）
   - 领取后按钮状态变为"已领取 ✓"，不可再次点击

3. **倒计时刷新机制**
   - 在"完成 1/4 · 25%"旁边显示距离下次刷新（每日6:00）的倒计时："剩余 8小时32分"
   - 倒计时结束时，如用户在线则自动刷新任务列表并弹出轻提示

4. **奖励视觉强化**
   - 在任务卡片的奖励XP数字旁增加**小金币图标** 🪙，而非仅文字"+5 XP"
   - 已完成任务的卡片整体透明度降低至60%，增加"已完成 ✓"的视觉标记


### 3.3 间隔重复复习

**现状问题**：空状态（0待复习）时新用户不知所措；趋势图仅有数据展示，缺乏行动指导与风险预警。

**优化需求**：

1. **空状态改造（替换当前仅显示"今日复习已完成"的文字）**
   - 标题："今日复习已清空！"
   - 描述："太棒了！你已完成所有到期的复习项。学习新内容将自动填充明天的复习队列。"
   - 行动按钮：【立即学习新内容 →】，点击跳转至学科选择页

2. **数据解读（趋势图下方新增洞察区）**
   - 格式：`📊 [结论句] + [具体数据] + [建议行动]`
   - 示例1（保持率高）："📊 你的7天保持率为100%，表现优异！但「霜」字已临近遗忘边界，建议今日巩固 → [立即复习]"
   - 示例2（待复习积压）："📊 你有12项待复习内容积压，建议优先处理已过期3天以上的项目 → [按紧急排序]"
   - 示例3（新用户无数据）："📊 开始学习后，这里将展示你的记忆保持趋势。首次复习建议在学习后24小时进行。"

3. **今日统计卡片视觉增强**
   - 当前三个统计（今日待复习/今日已复习/记忆保持率）建议改为带图标的卡片形式：
     - 📋 今日待复习：**3** 项
     - ✅ 今日已复习：**12** 项
     - 📈 记忆保持率：**92%**
   - 每个统计卡片加迷你环形进度（或微型趋势箭头，表示较昨日的变化）


### 3.4 联想学习

**现状问题**：纯文字列表（同义词/相关词）浪费了"联想"的视觉潜力；用户无法自定义关联，缺少交互深度。

**优化需求**：

1. **升级为力导向气泡图**
   - 中心词（如"霜"）为大球（直径80px，主色渐变）
   - 一级联想词（同义词/相关词）为中球（直径48px，同色系但明度稍低）
   - 二级联想词（知识点细节）为小球（直径32px，灰色）
   - **连线粗细代表关联强度**：强关联（如"雪"）→ 粗线（3px），弱关联（如"冷"）→ 细线（1px）
   - 支持拖拽平移和缩放查看

2. **手动关联功能**
   - 气泡图底部工具栏增加【🔗 手动建立关联】按钮
   - 操作方式：点击一个词 → 点击另一个词 → 弹出对话框："这两个词有什么关系？" 输入文字描述
   - 用户建立的关联用**虚线彩色连线**区分于AI生成的实线
   - 所有手动关联存入数据库，作为知识图谱的"用户主权"数据

3. **右侧详情面板联动**
   - 点击气泡图中的任意节点，右侧详情面板实时更新
   - 当前右侧的"从左侧选择一个联想项查看详情"已正确引导，但需改为动态显示选中节点的具体内容
   - 详情面板增加【📝 补充笔记】和【➕ 添加到复习队列】按钮


### 3.5 渐进提示

**现状问题**：用户提交猜测后无正误反馈，教学闭环断裂；提示等级（0/4）与按钮点击之间无视觉联动。

**优化需求**：

1. **正误判定反馈（核心改造）**
   - 用户提交"你的猜测"后，系统需给出即时反馈，而非仅记录
   - 反馈机制：
     - **语义模糊匹配**：使用简单的字符串相似度（或调用轻量级AI）评估回答
     - **接近**（如回答"水汽"vs正确答案"冰晶"）→ 绿色边框闪烁 + "接近！看看提示2再做补充"
     - **完全正确** → 🎉 全屏绿色闪动 + "太棒了！继续下一题"
     - **错误** → 红色边框闪烁 + 自动展开提示1
   - 若集成AI能力，可调用AI对用户输入进行0-100分打分并生成简短评语（如"思路对了，但'凝结'比'水汽'更精确"）

2. **提示按钮视觉反馈**
   - 当前"提示1/提示2/提示3/提示4"的按钮点击后应改变状态：
     - 已查看的提示按钮变为**灰色已读态** + 对勾标记 ✓
     - 当前可查看的提示按钮高亮（主色背景）
     - 当前不可查看的提示按钮显示🔒锁头标记
   - "提示等级：0/4"改为**圆点步进器**：●○○○ → 点击后 ●●○○

3. **状态持久化**
   - 用户关闭页面后重新打开，应恢复到上次的提示进度（提示等级和猜测内容需保存）


### 3.6 费曼学习法

**现状问题**：自问自答形式无法保存回答内容，缺乏历史对比，无法体现"简化"的进步。

**优化需求**：

1. **步骤导航增强**
   - 当前顶部"第3步/共4步"为纯文字，建议改为**面包屑步进器**：
     ```
     ① 学习 ─── ② 教学 ─── ③ 复习巩固 ◀（当前）─── ④ 简化
     ```
   - 已完成步骤显示 ✓ 标记，当前步骤高亮，未完成步骤灰色

2. **回答记录与保存（核心改造）**
   - 每个问题下方增加**多行文本输入框 + 保存按钮**
   - 支持**语音输入**（使用Web Speech API或集成阿里云语音识别），点击🎙️按钮开始录音，自动转文字填入输入框
   - 点击保存后，回答内容存入数据库，关联到当前学习项（如"霜"字）

3. **历史版本对比**
   - 在"第4步 简化"完成后，展示对比视图：
     ```
     第一次解释（3天前）："霜是冬天窗户上白白的..."
     ────────────────────────────────────
     最终解释（今天）："霜是水汽在0℃以下凝结的冰晶"
     ✅ 简化了 47% 的字数，保留了核心概念
     ```
   - 此对比视图可作为成就解锁条件（如"成功简化3个概念"）


### 3.7 测试报告

**现状问题**：只展示"结果"（正确率0%、掌握数0），无下一步动作指引，且数据展示存在重复字段（"已掌握"出现两次）。

**优化需求**：

1. **修复数据展示重复**
   - 当前"已掌握"字段在卡片和列表区重复出现，删除列表区的冗余展示
   - 统一为：**总题数 | 已掌握（含百分比） | 未掌握（含百分比）**

2. **智能处方（核心改造）**
   - 报告底部新增"诊断建议"区域，格式如下：
     - 有错题时：`💊 诊断建议：错误集中在「部首」类题目（错误率65%），推荐前往【语文 → 识字 → 部首专项】进行巩固练习 → [立即前往]`
     - 无错题时：`🎉 完美通过！你的表现非常出色。建议进入下一单元或挑战更高难度。 → [下一单元]`

3. **错题本联动**
   - 点击"未掌握"数字区域（或专门的"查看错题"按钮），底部展开错题列表
   - 每道错题显示：题目 + 用户错误答案 + 正确答案 + 【立即重练】按钮
   - 重练正确后，该题自动从错题本移除


### 3.8 WebView2浏览器

**现状问题**：仅为普通浏览器，与学习体系完全割裂，无任何学习相关的功能集成。

**优化需求**：

1. **划词剪藏（核心改造）**
   - 用户选中网页中的文字后，右键菜单增加 **"📥 保存为学习卡片"** 选项
   - 点击后弹出快速创建卡片对话框：
     - 自动填入：内容（选中文字）+ 来源（网页标题 + URL）
     - 用户选择：学科/子分类 + 可选标签
     - 点击保存 → 直接存入学习项数据库，可在"学习"模块中复习

2. **AI摘要侧栏**
   - 点击"豆包/DeepSeek"等AI按钮后，**不在当前页跳转**，而是从右侧滑出一个侧栏面板（宽度320px）
   - 侧栏中显示AI对**当前完整网页**的智能摘要（调用AI API）
   - 摘要内容底部增加【📌 保存摘要为笔记】按钮

3. **书签分类增强**
   - 当前仅"书签"列表，建议增加分类功能：在学习类/参考类/待读类/已完成 四个默认分类
   - 支持用户自定义分类名称
   - 点击分类下的书签时，自动记录访问次数和最后访问时间


## 四、系统级"化学融合"优化（最重要）

当前最大的问题是**功能模块各自为政**，以下是三个"胶水层"优化，让所有模块产生联动。

### 4.1 统一"AI工具箱"悬浮入口

**现状**：AI问答、联想学习、渐进提示、费曼学习法分布在4个不同页面，用户学"霜"字需反复切换。

**优化方案**：
- 在学习项展示页面（显示"霜"的主界面），右下角增加一个固定的悬浮按钮 🧠 **AI教练**（主色渐变，带微光晕）
- 点击后**从右侧滑出一个统一侧栏**（宽度360px），整合四个AI能力标签：

| 标签 | 功能 | 上下文 |
|------|------|--------|
| 💬 问答 | 随时向AI提问 | 自动将当前学习项（"霜"）作为上下文 |
| 🧠 费曼 | 用白话解释当前概念 | 直接展示"霜是什么意思？"等引导问题 |
| 💡 提示 | 自我测试 | 已输入猜测后可查看渐进提示 |
| 🔗 联想 | 查看关联图 | 展示以"霜"为中心的力导向气泡图 |

- 侧栏底部显示当前上下文："正在学习：霜（语文 · 识字）"
- **效果**：用户零跳转，所有AI能力围绕当前学习对象服务


### 4.2 数据流转闭环（事件驱动架构）

定义全局学习事件，模块间通过事件总线（EventBus）解耦联动：

| 事件 | 触发源 | 自动触发的下游动作 |
|------|--------|-------------------|
| `ItemLearned` | 学习页点击"会了" | 1. 更新每日挑战"答对"进度 +1<br>2. 增加XP（+10）<br>3. 检查成就条件（如"百题斩"）<br>4. 自动加入间隔重复队列 |
| `ItemWrong` | 学习页点击"不会" | 1. 自动记入错题本<br>2. 每日挑战"答对"进度 -1（或暂停计数）<br>3. 累计错题达10道 → 解锁成就"屡败屡战" |
| `PDFHighlight` | PDF阅读器创建高亮 | 1. 弹出提示"是否生成复习卡？"<br>2. 确认后自动创建学习项存入数据库<br>3. 加入间隔重复队列 |
| `ChallengeCompleted` | 每日挑战完成1项 | 1. 弹出XP奖励飘字动画<br>2. 检查是否完成全部挑战 → 触发"本周达人"成就进度+1 |
| `ReviewDone` | 复习模块完成1项 | 1. 更新记忆保持率趋势图数据<br>2. 检查是否有错题本中对应项 → 自动移除 |

**技术实现建议**：使用 `EventBus` 模式（如 `Prism.Events` 或自建轻量级事件聚合器），各模块订阅感兴趣的事件，解耦业务逻辑。


### 4.3 全局快捷键统一

当前学习页已有`K`/`U`/`Space`等快捷键，需扩展到全局一致性：

| 快捷键 | 全局功能 | 适用页面 |
|--------|----------|----------|
