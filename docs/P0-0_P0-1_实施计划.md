# P0-0 / P0-1 可执行实施计划

> **范围**：身份统一（P0-0）+ PDF 学习入口合并（P0-1）
> **目标**：打通“PDF 选中内容 → 用户个人学习库 → 学习窗口可见 → 复习/错题挂到稳定身份”的最小垂直链路。
> **原则**：不改 UI 大布局，不引入知识点树，不新增练习功能；只修地基和一条入口。
> **前置文档**：`docs/学习闭环整合与分类体系优化建议.md` 第十章。

---

## 0. 交付目标与非目标

### 交付目标

1. `LearningItem.Id` 成为学习项的唯一稳定身份，事件、复习、学习状态不再用 `MainContent` 当主键。
2. 旧词库自动补齐 `Id`，旧数据仍可加载，失败可回滚。
3. 全仓库只保留一条“PDF → 学习”的写路径：`IStudyEntryService`。
4. PDF 导入内容写入**当前用户个人内容库**，不修改共享词库 JSON。
5. 学习窗口重新打开后能看到导入内容，重复导入不产生重复项。

### 非目标

- 不做知识点树、适龄段、重要等级 UI（P1）。
- 不做跟读/听写练习与练习账本（P2）。
- 不做 PDF 标注数据结构大改，只在 `ExtendedProperties` 里带来源信息。
- 不迁移所有历史进度到 ID；采用“双键兼容、逐步回填”。

## 2. 先定 5 个设计决策

| 决策 | 结论 | 理由 |
|---|---|---|
| D1 身份字段 | **`ItemKey` 直接复用 `LearningItem.Id`**，不新增第二个 GUID | 避免两套 ID 漂移 |
| D2 去重键 | 新增 `CanonicalKey = subject|subcategory|Normalize(MainContent)`，仅用于判重 | 可重建、可迁移、不参与持久化主键 |
| D3 个人内容存储 | 首期使用**按用户隔离的 JSON 目录**，由 `ContentLoaderService` 合并；系统词库只读 | 改动最小，复用现有 JSON 加载链 |
| D4 兼容策略 | 所有查询“**ItemKey 优先，Content 回退**” | 旧数据不迁移也能用 |
| D5 入口 | 只保留 `IStudyEntryService` 一条写路径 | 删除三套重复逻辑 |

> 个人内容用 JSON 是首期折中；P1/P2 需要更强查询时，可平滑迁移到 SQLite，接口不变。

### 任务 P0-0.1 新增身份工具

**新增文件**：`LearningAssistant.Core/Services/Learning/LearningItemIdentity.cs`

```csharp
using System.Text;
using System.Text.RegularExpressions;
using LearningAssistant.Models.Learning;

namespace LearningAssistant.Services.Learning;

public static class LearningItemIdentity
{
    /// <summary>确保学习项拥有稳定 Id；返回最终使用的 Key。</summary>
    public static string EnsureKey(LearningItem item)
    {
        if (string.IsNullOrWhiteSpace(item.Id))
            item.Id = Guid.NewGuid().ToString("N");
        return item.Id;
    }

    /// <summary>判重键：学科 + 子类别 + 规范化内容。仅用于去重，不作为持久主键。</summary>
    public static string GetCanonicalKey(LearningItem item)
        => $"{item.Subject}|{item.SubCategory}|{Normalize(item.GetMainContent())}";

    public static string Normalize(string? text)
    {
        if (string.IsNullOrWhiteSpace(text)) return string.Empty;
        var value = text.Normalize(NormalizationForm.FormKC).Trim();
        value = Regex.Replace(value, @"\s+", " ");
        return value.ToLowerInvariant();
    }
}
```

**注意**：

- 不做词干化/同义词合并；首期只做大小写、全半角、空白归一化，避免误合并。
- 中文不做 `ToLowerInvariant` 之外的处理。

**验收**：

- 同一单词的不同大小写/多余空格得到相同 `CanonicalKey`；
- 不同子类别的同名内容得到不同 `CanonicalKey`。

```csharp
public List<LearningItem> LoadItems(LearningContext context)
{
    var systemItems = LoadSystemItems(context);              // 原逻辑
    if (!context.IncludePersonalContent)
        return systemItems;

    var personalItems = _personalContentStore.Load(
        context.UserId, context.Subject, context.SubCategory);

    if (personalItems.Count == 0)
        return systemItems;

    var result = new List<LearningItem>(systemItems.Count + personalItems.Count);
    var index = new Dictionary<string, int>(StringComparer.Ordinal);

    void Add(LearningItem item)
    {
        var key = LearningItemIdentity.GetCanonicalKey(item);
        if (index.TryGetValue(key, out var i))
            result[i] = item;      // 个人内容覆盖系统内容
        else
        {
            index[key] = result.Count;
            result.Add(item);
        }
    }

    foreach (var item in systemItems) Add(item);
    foreach (var item in personalItems) Add(item);
    return result;
}
```

### 任务 P0-1.4 实现 `StudyEntryService`

**新增文件**：`LearningAssistant.Core/Services/Learning/StudyEntryService.cs`

```csharp
public sealed class StudyEntryService : IStudyEntryService
{
    private readonly IPersonalContentStore _store;
    private readonly IUserSessionService _session;
    private readonly IContentLoaderService _contentLoader;
    private readonly ILogger<StudyEntryService>? _logger;

    public async Task<StudyEntryResult> AddAsync(
        StudyEntryRequest request, CancellationToken ct = default)
    {
        var text = CleanText(request.Text);
        if (string.IsNullOrWhiteSpace(text))
            return new(string.Empty, string.Empty, false, false, null);

        var userId = _session.CurrentUserId;
        var (subject, subCategory) = ResolveCategory(request, text);

        var item = new LearningItem
        {
            Id = Guid.NewGuid().ToString("N"),
            Subject = subject,
            SubCategory = subCategory,
            MainContent = text,
            Meaning = request.Translation?.Trim() ?? string.Empty,
            Example = request.Note?.Trim() ?? string.Empty,
            Status = LearningStatus.New,
            CreatedAt = DateTime.Now,
            ExtendedProperties = BuildSourceProperties(request)
        };

        var canonicalKey = LearningItemIdentity.GetCanonicalKey(item);
        var existing = _store.Load(userId, subject, subCategory)
            .FirstOrDefault(i => LearningItemIdentity.GetCanonicalKey(i) == canonicalKey);

        if (existing != null)
            return new(existing.Id, canonicalKey, false, true, existing);

        _store.Upsert(userId, subject, subCategory, item);
        _logger?.LogInformation("Added study item {ItemId} from {SourceType}", item.Id, request.SourceType);

        return new(item.Id, canonicalKey, true, false, item);
    }
}
```

**分类规则（首期）**：

```csharp
private static (SubjectType Subject, SubCategoryType Sub) ResolveCategory(
    StudyEntryRequest request, string text)
{
    if (request.Subject is { } s && request.SubCategory is { } c)
        return (s, c);

    if (LooksLikeEnglish(text))
    {
        var wordCount = CountWords(text);
        if (wordCount == 1) return (SubjectType.English, SubCategoryType.EnglishWord);
        if (wordCount <= 6 && !EndsWithSentencePunctuation(text))
            return (SubjectType.English, SubCategoryType.EnglishPhrase);
        return (SubjectType.English, SubCategoryType.EnglishSentence);
    }

    // 中文首期只做保守判断，避免把段落塞进“识字”
    if (text.Length <= 2) return (SubjectType.Chinese, SubCategoryType.ChineseCharacter);
    if (text.Length <= 8) return (SubjectType.Chinese, SubCategoryType.ChineseWord);
    return (SubjectType.Chinese, SubCategoryType.ChineseComprehensive);
```

## 6. 迁移、回滚与监控

### 迁移顺序

1. 启动时执行 `ItemIdentity-v1`（补 Id，带备份）。
2. 执行数据库补列 `ItemKey`（`RepairSchema` 幂等）。
3. 启动完成后才允许加载词库与学习窗口（避免迁移中读写竞争）。
4. 首次保存学习状态/复习时，逐步为新记录写入 `ItemKey`。

### 回滚

- 代码回滚：旧版本忽略 `ItemKey` 列，按 `Content` 继续工作。
- 数据回滚：使用 `*.bak-*` 恢复词库；数据库新增列可保留，不影响旧代码。
- 开关回滚：`EnableUnifiedStudyEntry=false` 立即停用新入口。
- 个人内容目录可整体移走，系统词库不受影响。

### 监控/诊断

建议在设置页或日志中输出：

- 补 Id 数量、失败文件数；
- 无 `ItemKey` 的复习记录数、学习状态数；
- 孤儿来源（`SourcePdfPath` 不存在）数量；
- 个人内容重复项数量（同 `CanonicalKey`）。
