# LearningAssistant 需求分析与设计文档

---

## 一、项目概述

### 1.1 项目简介

**LearningAssistant**（学习助手）是一款基于 C# WinForms 开发的桌面端学习辅助应用，旨在通过多种学习模式、AI辅助、游戏化激励等方式帮助用户高效学习。

### 1.2 技术栈

| 分类 | 技术 | 版本 |
|------|------|------|
| 框架 | .NET | 10.0 (Windows 7+) |
| UI | WinForms | - |
| 数据库 | SQLite | EF Core |
| AI服务 | DeepSeek / Doubao | - |
| TTS | Qwen TTS | - |
| 翻译 | 百度翻译API | - |
| PDF渲染 | PdfiumViewer | - |
| OCR | Tesseract | - |
| 依赖注入 | Microsoft.Extensions.DependencyInjection | - |

### 1.3 架构模式

采用 **MVP（Model-View-Presenter）** 架构模式：

| 层 | 职责 | 实现位置 |
|----|------|----------|
| **View** | 界面展示与用户交互 | Forms/UserControls |
| **Presenter** | 视图与模型之间的协调者 | Presenters/ |
| **Model** | 数据模型与业务逻辑 | Models/ + Services/ |

### 2.2 用户角色

| 角色 | 描述 | 权限 |
|------|------|------|
| 普通用户 | 日常学习使用 | 使用所有学习功能 |
| 管理员 | 内容管理 | 编辑学习内容模板 |

### 2.3 业务流程

#### 2.3.1 学习流程

```
用户选择学科 → 选择子分类 → 选择模式 → 学习项展示 → 标记掌握/未掌握 → 自动保存进度 → 继续学习或退出
```

#### 2.3.2 PDF阅读流程

```
打开PDF文件 → 渲染页面 → 阅读/标注 → 高亮/书签/OCR/翻译/TTS → 保存标注 → 关闭
```

#### 2.3.3 间隔重复流程

```
进入复习 → 获取待复习项 → 展示内容 → 用户评分(0-5) → 计算下次复习时间 → 更新状态
```

#### 2.3.4 AI辅助学习流程

```
选择内容 → 触发AI功能 → 调用AI服务 → 返回结果 → 展示/朗读/收藏
```

### 4.2 核心服务设计

#### 4.2.1 学习引擎（IStudyEngine）

**职责**：管理学习流程、进度追踪、模式切换

**核心方法**：

| 方法名 | 功能 | 参数 | 返回值 |
|--------|------|------|--------|
| Initialize | 初始化学习会话 | userId, language, subCategory, wordBankFile, mode, sortOrder | void |
| GetCurrentItem | 获取当前学习项 | - | LearningItem? |
| HasNext | 判断是否有下一项 | - | bool |
| MoveNext | 移动到下一项 | - | void |
| SetCurrentIndex | 设置当前索引 | index | void |
| MarkCurrentAsKnown | 标记当前项为已知 | - | void |
| MarkCurrentAsUnknown | 标记当前项为未知 | - | void |
| MarkItemsAsKnown | 批量标记已知 | contents | int |
| MarkItemsAsUnknown | 批量标记未知 | contents | int |
| GetStatistics | 获取学习统计 | - | StudyStatistics |
| SaveProgress | 保存进度 | - | void |
| ResetProgress | 重置进度 | - | void |
| AddUnknownItem | 添加未掌握项 | content, subCategory | void |

#### 4.2.4 PDF服务（IPdfService）

**职责**：PDF文件处理与渲染

**核心方法**：
