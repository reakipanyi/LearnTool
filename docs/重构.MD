

## 统一学习助手（UnifiedLearningAssistant）系统设计提示词

### 一、项目目标
开发一个基于 **.NET 8** 的 Windows Forms 桌面应用，**合并**原有的「双语智能学习工具」与「PDF阅读学习助手」功能，形成一个统一的学习平台。用户可在同一窗口内自由切换**学习模式**（汉字、单词、成语等）和**PDF阅读模式**，两种模式既可独立使用，也能深度联动（例如从 PDF 中划词添加至生词本、调用 AI 解释文本）。  
- **界面必须支持窗口自适应**（缩放、分辨率变化时控件合理调整）  
- **TTS 语音朗读统一使用 QwenTTS**（阿里云百炼）  
- **PDF 工具集成 AI 智能提问面板**（可对选中文本提问、解释、生成练习）  
- **整体 UI 优化**为儿童友好风格：大按钮、圆角卡片、清晰反馈、支持触摸操作

### 二、技术栈与架构
- **框架**：.NET 8 (或 .NET 6) Windows Forms  
- **设计模式**：MVP（Model-View-Presenter）+ 服务层 + 依赖注入（`Microsoft.Extensions.DependencyInjection`）  
- **PDF 渲染**：`PdfiumViewer` 或 `Pdfium.Net.SDK`  
- **OCR**：`Tesseract` (可配置语言包)  
- **翻译**：百度翻译 API（配置化）  
- **TTS**：QwenTTS（通过 HTTP 调用阿里云 DashScope API）  
- **AI 解释/问答**：SiliconFlow API 或 通义千问 API（统一 `IAIService`）  
- **音频播放**：`NAudio` 或 `VLC` 播放 TTS 生成的音频文件  
- **数据持久化**：JSON（`System.Text.Json`），可选 `SQLite` 扩展  
- **依赖注入容器**：`Microsoft.Extensions.DependencyInjection`  
- **异步编程**：`async/await`，所有 I/O 和网络调用不阻塞 UI

### 四、核心功能与整合要求

#### 1. 主界面 `MainForm`
- 使用 `TabControl` 提供两个标签页：**「双语学习」** 和 **「PDF阅读助手」**。
- 顶部菜单栏：`文件`（切换用户、退出）、`设置`、`统计`、`内容编辑器`（仅学习模式）。
- 状态栏：当前登录用户、TTS 状态（Qwen 在线/离线）、AI 服务状态。
- **自适应**：`TabControl` `Dock = Fill`；菜单栏固定；状态栏固定在底部；所有子窗体嵌入时同样自适应。

#### 2. 双语学习模块 `LearningForm`
- **完全保留原功能**：两种学习模式（快速/学习）、多玩家进度、自动保存、AI 释义面板（复用 AI 服务）。
- **新增功能**：在 AI 释义面板增加一个按钮「**添加到 PDF 提问板**」，可将当前单词/句子发送到 PDF 模块的 AI 提问输入框（若 PDF 模块已打开且处于活动状态）。
- **界面自适应**：超大文字区随窗口缩放而改变字体大小（最小 36pt，最大 120pt）；右侧 AI 面板可折叠（使用 `SplitContainer`）。
- **语音**：所有朗读调用 `IQwenTtsService`。

#### 3. PDF 阅读模块 `PdfReaderForm`
- **布局**：
  - 左侧 `TreeView` 显示文件夹及 PDF 文件树。
  - 中央 `Panel` 内嵌 `PdfiumViewer` 控件（支持缩放、翻页、手型光标）。
  - 右侧 `TabControl` 工具面板（包含「OCR/翻译」、「标注工具」、「AI 提问」三个子页）。
- **AI 提问面板**：
  - 一个 `TextBox` 用于输入问题或显示选中的文本。
  - 一个按钮「**向 AI 提问**」，调用 `IAiQuestionService` 发送文本及上下文（当前页面文本片段），返回答案显示在下方 `RichTextBox` 中。
  - 支持朗读 AI 答案（QwenTTS）、复制、添加到生词本（调用学习模块的接口，将生词加入当前用户的未掌握清单）。
- **OCR 与翻译**：用户框选图片区域 → 调用 `IOcrService` 识别 → 自动调用 `ITranslationService` 翻译 → 结果显示在翻译面板，并可选朗读或添加至生词本。
- **标注功能**：支持红线、黄高亮，持久化保存（每页独立文件）。
- **记忆功能**：自动记录上次打开的 PDF 和页码。
- **自适应**：左侧树和右侧面板宽度可调（`SplitContainer`）；PDF 渲染区自动缩放适应容器大小。

#### 4. 统一 TTS 服务：`QwenTtsService`
- 实现 `ITTSService` 接口：
  ```csharp
  Task SpeakAsync(string text, string language = "zh", float speed = 1.0f);
  Task StopAsync();
  bool IsSpeaking { get; }
  ```
- 内部使用 `HttpClient` 调用阿里云 DashScope API（`https://dashscope.aliyuncs.com/api/v1/services/audio/tts/text-to-audio`），支持缓存音频文件（`CacheService`），播放使用 `AudioPlayer`（基于 `NAudio` 或 `SoundPlayer`）。
- 配置项：API Key、Model（如 `qwen-tts`）、默认音色、语速、音量。

#### 5. AI 服务整合
- `IAIService` 用于学习模块的详细释义（输入单词/汉字，输出音标、释义、例句）。
- `IAiQuestionService` 用于 PDF 内的自由提问（接受任意文本，返回大模型回答）。
- 两者共享同一个底层 API 调用（如 SiliconFlow 或通义千问），通过不同的 `system prompt` 区分用途。
- 支持结果缓存（`ICacheService`），减少重复请求。

#### 6. 跨模块联动
- 定义一个 `IMessageBus` 或简单的事件聚合器（`EventAggregator`）实现学习模块与 PDF 模块的松耦合通信。
- 主要事件：
  - `AddWordToLearningList(string word, string language)` – PDF 划词后添加到学习模块的生词本。
  - `SendToAiQuestionPanel(string text)` – 学习模块将当前项发送到 PDF 的 AI 提问输入框。

#### 7. 自适应窗口设计细则
- 所有窗体设置 `MinimumSize` (例如 1024x768)。
- 使用 `TableLayoutPanel` 和 `FlowLayoutPanel` 进行行列比例布局。
- 关键控件（如 PDF 渲染区域、学习内容显示区）设置 `Anchor = Top | Bottom | Left | Right`。
- 字体大小支持全局设置（`SettingForm` 滑动条），所有控件的字体通过递归更新，并重新计算布局。
- 对于高分屏（DPI 感知），在 `Program.cs` 中启用 `ApplicationHighDpiMode = HighDpiMode.PerMonitorV2`。

#### 8. 用户体验优化
- 按钮圆角（重写 `OnPaint` 或使用 `ButtonRenderer`）。
- 平滑进度条、动画过渡（使用 `Timer` 简单实现）。
- 手型光标在 PDF 区域、可点击的朗读图标上出现。
- 操作反馈：状态栏消息、短暂的通知弹窗（`ToolTip` 或 `MessageBox` 风格变化）。
- 支持键盘快捷键：`Ctrl+O` 打开 PDF，`Ctrl+F` 查找文本（学习模式下查找单词），`Ctrl+S` 保存进度，`F1` 帮助等。

### 五、数据持久化细节
- 合并原有 `config.json` 和 `appsettings.json` 为统一的 `AppConfig.json`，包含 AI、TTS、翻译、界面字体等所有配置。
- 用户进度文件：`Users/{UserName}/progress.json`（存储学习统计、已掌握/未掌握列表）。
- PDF 标注文件：`Annotations/{PdfFileName}_{PageIndex}.json`（存储线条、高亮坐标）。
- 会话记忆：`session.json`（记录上次打开的用户、标签页、PDF 路径、页码等）。

### 六、开发顺序（供 AI 逐步生成代码）
1. **创建解决方案**和项目文件，配置依赖注入容器（`Program.cs` 中注册所有服务、Presenters、View 实现）。
2. **公共层**：`Common` 工具类，`Models` 基础模型。
3. **持久化服务**：`IDataPersistenceService` 及实现，完成配置与用户数据的读写。
4. **TTS 服务**：`QwenTtsService` + `AudioPlayer`，单独测试语音输出。
5. **AI 服务**：`SiliconFlowAIService`，实现释义和问答两个接口，加入缓存。
6. **学习引擎**：`StudyEngine` 和 `ContentLoaderService`，加载 JSON 词库，支持进度追踪。
7. **学习模块 UI**：`LearningForm` 和 `LearningPresenter`，实现完整的学习流程（快速/学习模式）。
8. **PDF 核心服务**：`PdfiumPdfService`，实现渲染、文本提取；`TesseractOcrService` 和 `BaiduTranslationService`。
9. **PDF 模块 UI**：`PdfReaderForm` 和 `PdfPresenter`，完成翻页、缩放、OCR 框选、翻译、标注持久化。
10. **AI 提问面板**：嵌入 `PdfReaderForm`，调用 `IAiQuestionService` 并显示结果。
11. **主窗体**：`MainForm`，整合两个模块，实现 Tab 切换，状态栏显示统一状态。
12. **设置窗体**：`SettingForm`，允许配置 API Key、TTS 参数、字体大小等。
13. **联动功能**：实现事件聚合器，让 PDF 划词可以添加至学习模块的生词本。
14. **全局自适应优化**：检查所有窗体的布局，应用 `TableLayoutPanel` 和 `Anchor` 调整。
15. **最终测试**：针对窗口缩放、不同分辨率、触摸模拟进行调试。

### 七、代码生成要求（避免返工）
- 每个类文件必须包含完整的 `using`、命名空间和 XML 注释。
- 所有异步方法命名为 `XxxAsync`，并在调用时使用 `await`，避免 `.Result` 阻塞。
- 依赖注入的注册统一放在 `Program.cs` 的 `ConfigureServices` 方法中。
- View 和 Presenter 之间通过接口通信，不直接依赖具体窗体。
- 对于 PDF 渲染，使用双缓冲（`DoubleBuffered = true`）和后台 `Task` 生成位图，避免卡顿。
- 错误处理：所有网络调用和文件操作需 `try-catch`，并向用户显示友好信息（通过 `IMainView.ShowMessage` 等接口方法）。
- 提供 `appsettings.json` 模板，包含必要的占位 API Key 和默认路径。

**功能细节**：
- **左侧树**：展示用户指定文件夹下的PDF（支持递归），带最近阅读标记。
- **中央阅读区**：
  - 异步渲染，支持鼠标滚轮翻页，Ctrl+滚轮缩放。
  - 手型光标（手形），模拟“手指点读”。

- **右侧工具面板**：

  - 翻译结果区：显示原文+译文，并提供“朗读译文”按钮（调用TTS）。
  - 标注工具：红色自由线/黄色高亮画笔，支持擦除和保存（每页独立存储）。
- **底部状态栏**：显示当前TTS服务（QwenTTS/Coqui等），音频播放状态。

## 数据持久化与交互说明（不写代码但提供原型逻辑）

- 主窗体启动时自动加载 `config.json` 和 `settings.json`，同时读取所有 `user_*.json` 并显示在玩家列表中。
- **学习窗体**的进度条刷新会实时保存至当前用户的 JSON 文件（自动保存间隔或点击按钮时触发）。
- 设置窗体的所有选项立即生效并写回 config/settings。
- PDF 标注保存为每页一个独立 XML/JSON 文件，存储在 `%AppData%\KidWinApp\Annotations`。
- OCR 识别结果支持一键复制和语音朗读，调用百度翻译 API 时自动使用本地缓存减少请求。
