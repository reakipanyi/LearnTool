② 二级选项浮层（不占工具栏高度）

  • 矩形 / 椭圆 / 箭头：虚实线 + 粗细滑块（1–20px）+ 实色颜色面板。
  • 画笔 / 临时画笔：粗细 + 实色颜色面板 + 笔型（铅笔 ✎ / 钢笔 ✒ / 马克笔 ▮）。
  • 高亮：粗细 + 5 个半透明荧光色（黄 / 绿 / 蓝 / 粉 / 橙），预览色与落笔色一致。
  • 文字：仅颜色面板。
  • 橡皮 / 马赛克 / 选择等无选项工具：不弹出浮层。

浮层锚点：矩形/椭圆/箭头/画笔/文字/高亮 → 各自按钮；删除线、临时画笔（在「更多」里）→ 锚定 ⋯ 按钮。 浮层图元尺寸（28×31 按钮、1px 浅灰边框、选中态 2px 蓝边框）与真实控件一致，色板颜色为预览近似取色。

③ 本次改动要点

  • 二级选项改按需浮层：虚线/粗细/颜色/笔型不再常驻工具栏第二行，改为选中带选项的工具时贴在该按钮下方弹出（与「更多」同一套交互）。
  • 工具栏回到单行高度：二级选项移出后不再为其预留高度，画布可用高度随之增加。
  • 隐藏折叠/展开按钮：右侧的 ▾/▴ 按钮及配套的折叠逻辑一并移除。
  • 一级图标条分组重排：绘制工具 → 橡皮 → 撤销 → ⋯ → 视图与智能，并消除了原有按钮重叠（临时画笔/撤销、放大镜/夜间模式）。
  • 低频工具收进「更多」：删除线、标注图层显隐、导出标注为图片、检查清单、插入图片、聚光灯、放大镜、临时画笔。一级条只留高频操作。图标取自对应工具的符号，用 GDI 现场绘制成 16×16 位图，无需图标资源文件。
  • 颜色体系统一：高亮用 5 个半透明荧光色，线条用实色色板；高亮预览色不再硬编码为黄色。
  • 翻页行为统一：按钮 / 方向键 / 空格 / 滚轮在单页与双页模式下都只前进 1 页。
