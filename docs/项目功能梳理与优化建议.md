## 四、剩余优化建议

### 4.1 P1优先级（可选）

#### 合并导出服务

**现状**: `IExportService` + `ILearningExportService` 功能重叠

**建议**: 将 `ILearningExportService` 的UI交互功能合并到 `IExportService`

**改动范围**:
- 修改 `IExportService` 添加 `ExportErrorBookWithDialog()` 方法
- 删除 `ILearningExportService` 和 `LearningExportService`
- 更新 `LearningFlowHandler` 直接使用 `IExportService`

**预期收益**: 减少服务数量，简化依赖

---

### 4.2 P2优先级（建议延后）

#### 统一事件系统

**现状**: `IEventBus`（应用级）+ `ILearningEventMediator`（模块级）

**评估**:
- 两者职责明确，无功能重叠
- 改动风险高，可能影响学习流程稳定性
- 当前实现已满足需求

**建议**: 暂缓执行，待学习模块稳定后再评估

```

├── AI/
│   ├── IUnifiedAIService.cs      # 统一AI接口

│   │   ├── ContentLoaderService.cs

│   │
│   ├── Analytics/
│   │   ├── ILearningAnalyticsService.cs

│   │
│   └── Features/
│       ├── ISpacedRepetitionService.cs

│
├── Pdf/
│   ├── IPdfService.cs

│
└── Common/
    ├── IEventBus.cs
    ├── ICacheService.cs
    └── IDataPersistenceService.cs
```

### 5.2 设计原则

| 原则 | 说明 |
|------|------|
| **单一职责** | 每个服务只负责一个功能领域 |
| **依赖倒置** | 依赖抽象而非具体实现 |
| **接口隔离** | 客户端不应依赖不需要的接口 |
| **开闭原则** | 对扩展开放，对修改关闭 |
