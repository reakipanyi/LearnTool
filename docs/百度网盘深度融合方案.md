## 三、融合方案详细设计

### 方案一：WebView2 百度网盘增强工作台

#### 1.1 功能描述

在现有 [WebView2BrowserForm](file:///e:/Github/LearnTool/LearningAssistant/Forms/WebView2BrowserForm.cs) 基础上，构建专属「百度网盘学习工作台」，针对学习场景优化交互。

#### 1.2 核心功能点

| 功能 | 实现思路 | 优先级 |
|------|----------|--------|
| **一键打开学习目录** | 左侧工具栏增加「我的课程」「学习资料」快捷导航按钮，通过API `ListFilesAsync` 列出常用目录，点击直接在WebView中导航到对应路径 | P0 |
| **视频学习模式切换** | 检测到当前页面是视频播放页时，自动切换为「沉浸式学习模式」：隐藏浏览器工具栏、右侧弹出笔记面板、开启番茄钟 | P0 |
| **智能书签同步** | 将网盘内的学习视频/文档自动同步为浏览器书签，支持按课程分类 | P1 |
| **播放进度记录** | 通过JS注入监控视频播放器 `currentTime`，定时上报，与学习会话关联，下次打开自动跳转 | P1 |
| **快捷键增强** | `Ctrl+Shift+N` 快速新建关联笔记、`Ctrl+Shift+H` 标记当前时间点为重点、`Ctrl+Shift+S` 一键截图保存 | P1 |

#### 1.3 技术实现要点

```csharp
// 1. 检测视频播放页面并注入监控脚本
private async void WebView_NavigationCompleted(object sender, CoreWebView2NavigationCompletedEventArgs e)
{
    if (CurrentWebView?.Source?.Host == "pan.baidu.com")
    {
        // 检测是否包含video元素
        var hasVideo = await CurrentWebView.CoreWebView2.ExecuteScriptAsync(
            "document.querySelector('video') ? true : false");
        
        if (hasVideo == "true")
        {
            await EnableVideoLearningModeAsync();
        }
    }
}

// 2. 注入视频进度监控脚本
private async Task EnableVideoLearningModeAsync()
{
    string script = @"
        (function() {
            const video = document.querySelector('video');
            if (!video) return;
            
            // 定时上报进度
            setInterval(() => {
                window.chrome.webview.postMessage({
                    type: 'video_progress',
                    currentTime: video.currentTime,
                    duration: video.duration,
                    src: video.currentSrc
                });
            }, 5000);
            
            // 监听重点标记快捷键
            document.addEventListener('keydown', (e) => {
                if (e.ctrlKey && e.shiftKey && e.key === 'H') {
                    window.chrome.webview.postMessage({
                        type: 'mark_timestamp',
                        time: video.currentTime,
                        title: document.title
                    });
                }
            });
        })();
    ";
    await CurrentWebView.CoreWebView2.ExecuteScriptAsync(script);
    
    // 订阅WebMessage
    CurrentWebView.CoreWebView2.WebMessageReceived += VideoProgress_Received;
}
```

### 方案二：百度网盘视频 AI 解析 + 自动笔记生成

#### 2.1 功能描述

用户在网盘选择视频课程，系统调用 AI 能力自动生成结构化学习笔记，包含：视频摘要、章节划分、知识点提取、思维导图、问答卡片。

#### 2.2 实现路径（三种方案对比）

| 方案 | 实现方式 | 优点 | 缺点 | 推荐度 |
|------|----------|------|------|--------|
| **A: 网盘AI解析结果提取** | WebView2中打开网盘「视频智能笔记」功能，通过DOM解析提取AI生成的摘要 | 无需额外AI调用、结果质量高 | 依赖网盘会员功能、DOM可能变更 | ⭐⭐⭐⭐ |
| **B: 本地语音转写 + AI摘要** | 下载视频音频 → 本地/云端ASR转文字 → AI生成笔记 | 可控性强、不依赖会员 | 耗时较长、需ASR服务 | ⭐⭐⭐ |
| **C: 元数据 + 用户标注增强** | 利用视频元信息（时长/标题）+ 用户手动标记的时间点 → AI整理结构化笔记 | 轻量高效、精准度高 | 需要用户配合标记 | ⭐⭐⭐⭐⭐ |

#### 2.3 推荐方案 C 详细设计（元数据+标注增强）

##### 2.3.1 流程设计

```
用户在WebView中浏览网盘视频
        │
        ▼
  点击「生成学习笔记」按钮
        │
        ▼
  1. 通过API获取视频元信息
     ├─ 视频标题、时长、分辨率
     └─ 所在目录（用于课程分类）
        │
        ▼
  2. 提示用户可选操作：
     ├─ 自动播放并提取字幕（如有）
     ├─ 手动标记重点时间点
     └─ 粘贴已有讲义/大纲
        │
        ▼
  3. 调用 AI 生成结构化笔记
     ├─ 视频简介（根据标题+元信息）
     ├─ 章节建议（按时长分段）
     ├─ 知识点提取大纲
     ├─ 关键概念卡片
     └─ 复习思考题
        │
        ▼
  4. 保存到笔记服务 + 关联网盘文件
        │
        ▼
  5. 用户编辑补充 → 导出
```

#### 2.4 方案A 补充：网盘AI解析结果提取

如果用户有百度网盘会员，可直接提取网盘内置「视频笔记」功能结果：

```csharp
/// <summary>
/// 通过WebView2提取百度网盘AI视频解析结果
/// </summary>
private async Task<string?> ExtractBaiduAINotesAsync()
{
    if (CurrentWebView?.CoreWebView2 == null) return null;
    
    // 等待AI面板加载
    await Task.Delay(2000);
    
    // 尝试提取AI摘要（DOM选择器需根据实际页面调整）
    string script = @"
        (function() {
            // 尝试多种可能的选择器
            const selectors = [
                '.ai-summary-content',
                '.video-notes-content',
                '[class*=summary]',
                '[class*=note] article'
            ];
            
            for (const sel of selectors) {
                const el = document.querySelector(sel);
                if (el && el.innerText.length > 50) {
                    return JSON.stringify({
                        content: el.innerText,
                        selector: sel,
                        timestamp: Date.now()
                    });
                }
            }
            return null;
        })();
    ";
    
    var result = await CurrentWebView.CoreWebView2.ExecuteScriptAsync(script);
    return result;
}
```

### 方案四：语义搜索 + 知识关联

#### 4.1 功能描述

利用百度网盘已有的 `unisearch`（语义搜索接口），实现「网盘内容 → 学习笔记 → AI问答」的跨域检索。

#### 4.2 搜索场景设计

| 场景 | 用户输入 | 搜索策略 | 返回结果 |
|------|----------|----------|----------|
| **跨源关联** | "线性代数 特征值" | 同时搜：网盘文档内容(11)+文档向量(7)+本地笔记 | 网盘文件 + 相关笔记卡片 |
| **视频找片段** | "老师讲梯度下降的那段" | 网盘视频向量搜索(8) | 视频文件+建议时间点 |
| **图片找讲义** | "那张有决策树的图" | 图片OCR(5)+图片语义(14) | 图片所在文档/页码 |
| **知识点串联** | "贝叶斯定理的应用" | 以上全部sources + AI生成关联图 | 多维结果+思维导图 |

## 五、关键技术点与注意事项

### 5.1 百度网盘API 调用频率限制

根据 [BaiduPanFileManager.cs](file:///e:/Github/LearnTool/LearningAssistant/Services/Cloud/BaiduPanFileManager.cs#L459-L462) 已有实现：
- GET请求限流：间隔 ≥ 7秒
- POST请求限流：间隔 ≥ 10秒
- 429状态码自动重试，指数退避

**建议补充**：
- 全局共享 `_lastRequestTime`（目前为方法内部变量）
- 批量操作增加任务队列，后台线程渐进执行

### 5.2 WebView2 DOM 注入稳定性

- 百度网盘前端可能随时变更DOM结构，需：
  - 准备多套选择器fallback
  - 关键操作增加用户手动触发选项
  - 记录失败日志，便于更新选择器

### 5.3 视频学习隐私与合规

- 视频转文字功能需明确告知用户数据流向
- AI生成内容需标注「AI辅助生成」，用户确认后保存
- 不存储用户网盘中的原始视频，仅存元数据和笔记

### 5.4 Token 安全性

- [CloudStorageConfig](file:///e:/Github/LearnTool/LearningAssistant/Models/Config/CloudStorageConfig.cs) 中的 AccessToken/RefreshToken 建议加密存储
- 已有 `ConfigEncryptionHelper`，可在此处应用
