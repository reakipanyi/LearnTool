# LearningAssistant 产品UI/UX优化提示词（优化版）


## 一、前置说明

### 1.1 角色定位

你是一位资深EdTech产品设计师，专精于将学习科学理论（间隔重复、主动回忆、费曼学习法）转化为直观的界面体验。你擅长通过"事件驱动"设计，让孤立的功能模块产生化学反应。

### 1.2 核心约束

- 不新增功能模块，仅优化已有功能
- 必须基于 .NET 10.0 + WinForms 技术栈实现
- 优化后需保持对Windows 7+的兼容性
- AI相关功能需保持"离线优先"原则——核心CRUD不依赖网络

### 1.3 三大核心问题

| 问题 | 表现 |
|------|------|
| 功能孤岛 | 成就/挑战/复习/联想/费曼各自独立，数据不互通 |
| 交互断裂 | 教学闭环不完整，用户操作后无反馈、无引导 |
| 体验割裂 | AI能力分散在4+页面，需频繁跳转 |

在逐模块优化前，先建立全产品统一的设计语言。

### 2.1 设计令牌

| 设计元素 | 规范值 |

### 2.2 组件规范

**空状态组件**（统一四要素）：

| 要素 | 规范 |
|------|------|
| 插图 | 160×160px SVG插画（灰色调） |
| 标题 | 16px Bold 主文字色 |
| 描述 | 14px 二级文字色 |
| 行动按钮 | 主色填充 + 箭头图标（如"去学习新知识 →"） |

**进度展示组件**：

| 使用场景 | 推荐组件 |
|----------|----------|
| 学习项进度（12/409） | 线性进度条 + 百分比 |
| 成就/等级进度 | 环形进度条（圆端头） |

**适用空状态页面**：复习模块（待复习为0）、首页推荐（无数据）、错题本为空、收藏夹为空。


## 三、各模块优化需求

### 3.1 成就系统

**问题**：纯文字展示（"42%"、"3/7"、"✅已解锁"），缺乏仪式感和视觉激励。

**优化清单**：

| 序号 | 优化项 | 具体方案 |
|------|--------|----------|
| 1 | 徽章卡片化 | 每项成就展示：48×48px图标 + 名称 + 描述 + 环形进度；未解锁=灰色剪影+🔒，已解锁=彩色渐变+光晕边框 |
| 2 | 解锁动画 | 解锁时触发撒花/飘星粒子动画，持续1.5秒 |
| 3 | 进度可视化 | "42%"→环形进度条（直径40px）；"3/7"→星级显示（★☆☆☆☆☆） |
| 4 | 隐藏成就彩蛋 | 设计3-5个隐藏成就（如"凌晨学者"），达成时全屏祝贺弹窗 |
| 5 | Tab增强 | 选中态加下划线（4px主色）或背景色块；每个tab显示分类解锁数量角标（如"学习 3"） |


### 3.2 每日挑战

**问题**：任务卡片无跳转入口，奖励领取交互不清晰，无倒计时紧迫感。

**优化清单**：

| 序号 | 优化项 | 具体方案 |
|------|--------|----------|
| 1 | 任务即入口 | 卡片整体可点击；"答对10道题"→跳转快速学习模式；"今天至少学习一次"→跳转首页推荐；"收藏5个内容"→跳转PDF阅读器并弹出收藏引导 |
| 2 | 奖励领取动效 | 点击"领取奖励"→XP数字从按钮位置飘向左上角XP总数位置 + 金币入袋音效；领取后变为"已领取 ✓"不可再点 |
| 3 | 刷新倒计时 | 显示距离下次刷新（每日6:00）的倒计时："剩余 8小时32分"；刷新时自动更新任务列表 |
| 4 | 奖励视觉强化 | XP数字旁加🪙小图标；已完成任务透明度降至60% + "已完成 ✓"标记 |


### 3.3 间隔重复复习

**问题**：空状态（0待复习）无引导；趋势图仅有数据，无洞察和行动建议。

**优化清单**：

| 序号 | 优化项 | 具体方案 |
|------|--------|----------|
| 1 | 空状态改造 | 插画 + "今日复习已清空！" + "学习新内容将自动填充明天的复习队列" + 【立即学习新内容 →】按钮 |
| 2 | 数据洞察区 | 趋势图下方显示三条洞察之一：①保持率高时提醒具体将遗忘的词；②有积压时按紧急排序；③新用户时引导首次学习 |
| 3 | 统计卡片视觉 | 今日待复习/已复习/保持率 改为图标卡片（📋/✅/📈），每个加迷你环形进度或较昨日变化的箭头指标 |


### 3.4 联想学习

**问题**：纯文字列表浪费"联想"的视觉潜力；用户无法自定义关联。

**优化清单**：

| 序号 | 优化项 | 具体方案 |
|------|--------|----------|
| 1 | 力导向气泡图 | 中心词=大球（80px主色渐变）；一级联想=中球（48px同色系）；二级=小球（32px灰色）；连线粗细=关联强度 |
| 2 | 手动关联 | 点击两词→弹出"这两个词有什么关系？"→用户输入描述→存入数据库；用户建立的关联用虚线彩色连线区分 |
| 3 | 详情面板联动 | 点击气泡节点→右侧面板实时显示该词详情；面板底部增加【📝补充笔记】【➕添加至复习队列】 |


### 3.5 渐进提示

**问题**：提交猜测后无正误反馈；教学闭环断裂。

**优化清单**：

| 序号 | 优化项 | 具体方案 |
|------|--------|----------|
| 1 | 正误判定反馈 | 语义模糊匹配：接近→绿色边框+"接近！看看提示2"；正确→全屏绿色闪动；错误→红色边框+自动展开提示1 |
| 2 | 提示按钮状态 | 已查看→灰色+✓；当前可查看→主色高亮；不可查看→🔒；"提示等级0/4"→圆点步进器 ●○○○ |
| 3 | 状态持久化 | 关闭页面后重新打开，恢复到上次提示进度 |


### 3.6 费曼学习法

**问题**：回答内容无法保存，无历史对比，无法体现"简化"进步。

**优化清单**：

| 序号 | 优化项 | 具体方案 |
|------|--------|----------|
| 1 | 步骤导航 | 面包屑步进器：①学习→②教学→③复习巩固◀→④简化；已完成✓，当前高亮，未完成灰色 |
| 2 | 回答保存 | 每个问题下方增加多行文本框+保存按钮；支持语音输入（🎙️录音转文字） |
| 3 | 历史对比 | 第4步完成后展示对比视图："第一次解释（3天前）：..." vs "最终解释（今天）：..." + "简化了47%的字数" |


### 3.7 测试报告

**问题**：仅展示结果无下一步引导；数据展示重复。

**优化清单**：

| 序号 | 优化项 | 具体方案 |
|------|--------|----------|
| 1 | 去重 | 删除列表区冗余的"已掌握"展示，统一为：总题数\|已掌握（%)\|未掌握（%) |
| 2 | 智能处方 | 有错题→"错误集中在「部首」类，推荐前往【语文→识字→部首专项】→[立即前往]"；无错题→🎉鼓励语+【下一单元】 |
| 3 | 错题联动 | 点击未掌握数字→展开错题列表（题目+用户错误答案+正确答案+【立即重练】）；重练正确后自动移出错题本 |


### 3.8 WebView2浏览器

**问题**：与学习体系完全割裂，仅为普通浏览器。

**优化清单**：

| 序号 | 优化项 | 具体方案 |
|------|--------|----------|
| 1 | 划词剪藏 | 右键菜单增加"📥保存为学习卡片"→弹窗自动填入内容+来源（网页标题+URL），用户选择学科/分类/标签后保存 |
| 2 | AI摘要侧栏 | 点击AI按钮→右侧滑出320px面板显示当前网页摘要；底部【📌保存摘要为笔记】 |
| 3 | 书签分类 | 增加分类功能：学习类/参考类/待读类/已完成+用户自定义；记录访问次数和时间 |


## 四、系统级"化学融合"优化

### 4.1 统一"AI工具箱"悬浮入口

**问题**：AI问答、联想、渐进提示、费曼分布在4个不同页面。

**方案**：
- 学习项展示页面右下角增加固定悬浮按钮 🧠 **AI教练**（主色渐变+微光晕）
- 点击后从右侧滑出统一侧栏（360px），整合四个标签页：

| 标签 | 功能 | 上下文 |
|------|------|--------|
| 💬 问答 | 随时向AI提问 | 自动将当前学习项作为上下文 |
| 🧠 费曼 | 用白话解释当前概念 | 展示引导问题 |
| 💡 提示 | 自我测试 | 已输入猜测后可查看渐进提示 |
| 🔗 联想 | 查看关联图 | 力导向气泡图 |

- 侧栏底部显示当前上下文："正在学习：霜（语文·识字）"


### 4.2 数据流转闭环（事件驱动）

**问题**：成就、挑战、错题本、复习之间无数据联动。

**全局事件定义**：

| 事件 | 触发源 | 自动触发动作 |
|------|--------|-------------|
| `ItemLearned` | 学习页点击"会了" | ①每日挑战进度+1 ②XP+10 ③检查成就条件 ④加入间隔重复队列 |
| `ItemWrong` | 学习页点击"不会" | ①记入错题本 ②挑战进度暂停 ③错题达10道→解锁"屡败屡战"成就 |
| `PDFHighlight` | PDF创建高亮 | ①弹出"是否生成复习卡？" ②确认后自动创建学习项 ③加入间隔重复队列 |
| `ChallengeCompleted` | 完成1项挑战 | ①XP飘字动画 ②检查全部完成→"本周达人"成就进度+1 |
| `ReviewDone` | 复习完成1项 | ①更新保持率趋势 ②错题本中对应项自动移除 |

**技术实现**：使用事件总线模式（EventBus），各模块订阅/发布事件，低耦合。


### 4.3 全局快捷键

| 快捷键 | 功能 | 适用页面 |
|--------|------|----------|
| `Space` | 发音/显示答案 | 学习页、复习页 |
| `K` / `1` | 标记"会了" | 学习页、渐进提示页 |
| `U` / `2` | 标记"不会" | 学习页、渐进提示页 |
| `F` | 收藏/取消收藏 | 学习页、PDF页 |
| `N` | 打开笔记编辑器 | 学习页 |
| `←` `→` | 上一项/下一项 | 学习页、PDF页 |
| `Esc` | 关闭当前弹窗/侧栏 | 全局 |
