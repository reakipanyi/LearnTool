# 优化改进方案 · 05 · 报告模块

> **对应问题**：问题二 · 报告 —— 报告停留在纯文本，无图形化界面、无统一导出、无 AI 增值能力。
> **对应优化项**：O-005（报告结构化 + 导出 + AI 总结 + 日报提醒），**P2**（可与 P0 并行）。
> **关联问题编号**：W-004（部分，报告维度）。
> **依赖**：数据来自 **02 统计底座**（聚合 DTO）；渲染消费方为 **04 学习数据中心** 的“报告”Tab。

---

## 一、现状分析

- `LearningReportService`（`Services/Learning/LearningReportService.cs`）产出 `DailyReport/WeeklyReport/MonthlyReport`，仅生成字符串文本，无图形化报告界面。
- 现有导出能力分散且有限：
  - `LearningDataExportService` —— CSV/Excel 复习日志；
  - `WrongAnswerService.ExportToMarkdown` —— 错题 Markdown。
  - **报告本身无统一导出**。
- 报告为纯规则文案，无 AI 自然语言总结。
- 无日报自动提醒触达（虽有 `ILearningReminderService` 提醒服务可复用）。

## 三、优化方案

### 3.1 报告结构化

- 保留 `LearningReportService` 的日/周/月计算逻辑，但升级输出：从纯文本 `GenerateReportText` 扩展为**结构化报告模型**（指标卡 + 趋势图 + 分类分布 + 建议列表），由“报告”Tab 渲染为卡片式页面。
- 建议由聚合层统一喂数，`LearningReportService` 不再直接依赖 `ILearningAnalyticsService`（改依赖聚合 DTO）。

### 3.2 导出能力

- 复用/扩展 `LearningDataExportService`，支持报告导出为 **Markdown / HTML / TXT**。
- 复用现有 `ExportService` 的 Excel 能力，补 **PDF/Excel** 导出（HTML 内嵌 ScottPlot 生成的图片或 SVG 简单图表）。

### 3.3 AI 报告（增值）

- 复用已集成的 Deepseek/Doubao AI 服务（`DeepseekAIService`/`DoubaoAIService`），由 AI 生成周报/月报的**自然语言总结与个性化建议**，替代纯规则文案。
- 无网络或调用失败时**回退到现有规则文案**（不阻塞）。

### 3.4 日报自动提醒

- 复用 `ILearningReminderService`，每日定时推送“昨日学习小结”（时长/数量/正确率/连击），让统计被动触达用户。

## 五、验收标准

1. 日/周/月报告渲染为卡片式页面（指标卡 + 趋势图 + 分类分布 + 建议列表）。
2. 报告可导出 Markdown / HTML / TXT，以及 PDF/Excel。
3. AI 周报/月报总结可用；无网络/失败时回退规则文案，报告不中断。
4. 日报自动提醒定时推送“昨日学习小结”。
5. `LearningReportService` 依赖聚合 DTO，不再直连 `ILearningAnalyticsService`。

---

## 六、风险与注意事项

1. **AI 报告成本与可用性**：AI 调用需限频、缓存结果；无网络/失败时回退规则文案，保证报告不因 AI 不可用而中断。
2. **导出依赖**：PDF 导出依赖 HTML 渲染（内嵌 ScottPlot 图片/SVG），需保证中文与图表字体正确。
3. **依赖就绪**：报告升级依赖 02 聚合服务就绪，需按阶段顺序落地。
