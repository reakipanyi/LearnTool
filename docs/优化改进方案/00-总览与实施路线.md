## 一、优化背景

当前两大优化主题：

1. **问题一 · 首页用户切换不灵活**：顶部用户切换为下拉框，交互呆板；顶部 ➕ 新增按钮与设置窗体用户管理功能重复；旧布局死代码遗留。
2. **问题二 · 学习统计/图表/报告停留在初始版本**：统计数据多源口径不一、学习时长未记录（`TimeSpentMinutes` 无赋值点）、统计界面多套并存、统计入口失效、图表实现重复、报告为纯文本。

## 四、全局风险与注意事项

1. **数据迁移安全**：JSON→DB 迁移需先备份 `AppData/`；采用"迁移标记 + 幂等 upsert"；迁移失败不影响启动。
2. **聚合服务回归风险**：涉及 `StudyEngine`、`GamificationService`、`MainPresenter` 多处调用，需跑 `LearningAssistant.Tests`（`LearningAnalyticsServiceTests`、`StudyEngineTests`、`UserSessionServiceTests` 等）。
3. **`RecordActivity` 高频调用**：若改为同步写 DB 注意性能，建议异步/批量落库。
4. **迁移与写入并发**：迁移期间避免与日常写入冲突，防止丢数据。
5. **缓存失效遗漏**：失效触发器需覆盖全部写入路径，并保留"打开统计中心强制刷新"兜底。
6. **移除旧组件影响面**：删除 `LearningChartService`、`LearningStatsForm`、`buttonOpenStatistics` 前先全局检索引用。
7. **AI 报告成本与可用性**：AI 调用需限频、缓存结果，失败回退规则文案。
8. **行为兼容与回滚**：用户切换改造保持 `UserChanged`/`SelectedUser` 接口不变；统计中心重构期间用灰度开关保留旧入口。

## 五、模块间接口契约（先行定义）

> 各模块分工前**先定契约**，避免各模块各写各的、互相对不上。以下清单是**契约草案**，实施时先在 `00` 维护为准，任何变更走评审。

### 5.1 聚合 DTO 契约（02 产出，03/04/05/06 消费）

| DTO | 关键字段（草案） | 消费方 |
| --- | --- | --- |
| `DailyOverview` | Date、TimeSpentMinutes、ItemsStudied、CorrectCount、WrongCount、Accuracy、StreakDays、XP、Level、GoalCompleted | 04 概览 Tab、06 首页 |
| `WeeklyOverview` / `MonthlyOverview` | 在 Daily 基础上 + 环比 Delta、TopCategory、WeakCategory | 04 概览、05 报告 |
| `TrendSeries` | 点集 `(Date, Value)`、SeriesType(Trend/Accuracy/Category) | 03 趋势图、04/05 |
| `CategoryBreakdown` | Category 维度汇总（时长/数量/正确率） | 03 分类图、04/05 |
| `MemoryInsights` | RetentionRate、ForgettingCurve、MaturityDistribution(新生/学习中/已掌握)、ReviewDistribution | 03 记忆图、04 记忆 Tab |
| `WrongAnswerSummary` | 错题数量/难度分布/高频错因 | 04 错题 Tab |
| `GoalProgress` | GoalId、Target、Progress、DueDate、DaysRemaining | 03 目标图、04 目标 Tab |
| `EfficiencyReport` | 时长/正确率/连击/效率分（报告专用） | 05 报告 |

### 5.2 EventBus 事件契约（02/04/06 联动）

| 事件 | 触发方 | 消费方 | 用途 |
| --- | --- | --- | --- |
| `StudySessionCompleted` | StudyEngine | 聚合缓存失效、Dashboard 刷新、数据中心刷新 | 学习会话结束 |
| `ReviewCompleted` | 复习链路 | 同上 | 复习完成 |
| `PomodoroCompleted` | PomodoroService | 同上 | 番茄钟完成 |
| `StatsCacheInvalidated` | 聚合层 | 数据中心/首页 | 缓存失效通知 |
| `UserChanged` | 用户切换 | Dashboard、数据中心、聚合层 | 切换统计上下文 |

### 5.3 导航 Key 契约（06 侧边栏 → 04）

`statistics`（📊 学习数据）→ `WindowManager.OpenStatisticsCenter`；`home/study/content/pdf/browser/settings` 保持不变。

## 六、可量化验收指标（KPI）

> 每个模块"验收标准"之外，补充**可度量目标**，避免只做"能用"不做"好用"。

| 指标 | 目标值 | 相关模块 |
| --- | --- | --- |
| 统计中心打开首屏响应 | ≤ 200ms（聚合走缓存/预聚合） | 02、04 |
| 首页 Dashboard 渲染 | ≤ 300ms（懒加载聚合） | 06 |
| 聚合口径测试通过率 | 100%（时长=会话+番茄、正确率、连击） | 02 |
| 迁移对账一致率 | 100%（JSON 旧值 vs DB 新值） | 02 |
| 统计入口可用性 | 侧边栏"📊 学习数据"可点击直达，无死路径 | 04、06 |
| 用户切换体验 | 面板内 ≤ 2 次点击完成切换；键盘可达 | 01 |
| 报告导出成功率 | 日/周/月均可导出 5 种格式无异常 | 05 |
| 图表主题一致性 | 明暗主题切换后全部图表无配色丢失 | 03 |

### 8.2 关键决策记录（ADR）

| 决策 | 理由 | 备选 |
| --- | --- | --- |
| 统一以 DB + 聚合服务为唯一数据真相 | 消除多源口径不一致 | 继续 JSON 并存（否：无法根治） |
| 图表统一 ScottPlot，删除 Bitmap | 风格/主题统一、可维护 | 双栈并存（否：冗余） |
| 统计中心以 `LearningManagementForm` 为基座 | 功能最全、改动最小 | 新建独立窗体（否：重复造轮子） |
| 时长口径可配置（设置开关） | 三来源时长易对不上，需用户可调 | 写死单一口径（否：不灵活） |
