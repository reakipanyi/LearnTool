# 优化改进方案 · 03 · 图表可视化模块

> **对应问题**：问题二 · 图表 —— 图表实现重复（Bitmap 旧版 vs ScottPlot 新版），风格/主题不统一。
> **对应优化项**：O-004（统一 ScottPlot 图表层，删除 Bitmap 旧图表），**P1**。
> **关联问题编号**：W-009（需求挖掘）；C-008（需求冲突）。
> **依赖**：数据来自 **02 统计底座模块**（聚合 DTO）；供 **04 学习数据中心** 与 **06 首页仪表盘** 消费。

---

## 一、现状分析

当前图表存在两套实现并存：

| 实现 | 位置 | 说明 |
| --- | --- | --- |
| `LearningChartService`（旧） | `Services/Learning/LearningChartService.cs` | Bitmap 手绘，风格老旧，与主题脱节 |
| `LearningCharts`（新） | `Forms/UserControls/Charts/LearningCharts.cs` | ScottPlot，含 `LearningTrendChart`、`ForgettingCurveChart`、`CategoryProgressChart`、`ReviewDistributionChart` |

两套实现功能重叠、样式不统一、主题联动不一致，代码冗余（W-009 / C-008）。

## 三、优化方案

### 3.1 保留（ScottPlot 图表，完善主题联动）

`Forms/UserControls/Charts/LearningCharts.cs`：
- `LearningTrendChart`（学习趋势）
- `ForgettingCurveChart`（遗忘曲线）
- `CategoryProgressChart`（分类进度）
- `ReviewDistributionChart`（复习评分分布）

### 3.2 新增（补齐可视化能力）

- **`WeeklyHeatmapChart`**：学习热力图（周视图，颜色深浅 = 学习强度），替代/增强现有热力图能力。
- **`GoalProgressChart`**：目标达成进度图（或复用现有 `GoalCalendarView`）补齐目标可视化。
- **`MemoryMaturityChart`**：基于 FSRS `Stability/Difficulty` 的“新生/学习中/已掌握”记忆成熟度分布，比单一保留率更直观。

### 3.3 删除（旧 Bitmap 图表）

- 删除 `Services/Learning/LearningChartService.cs` 及其接口 `ILearningChartService`，图表统一走 ScottPlot。
- 删除前先全局检索引用（已有 `ServiceCollectionExtensions.cs` L235 注册等）。

### 3.4 统一规范

- 所有图表控件实现 `IThemeable`，跟随明暗主题；统一配色（沿用现有 `_chartColors` 或主题色板）。
- 图表数据统一来自聚合 DTO（`TrendSeries`/`CategoryBreakdown`/`MemoryInsights`），不再各自查 JSON/DB。
- 空数据状态：图表显示占位提示而非空白/假数据。

## 五、验收标准

1. 全库不再引用 `LearningChartService`/`ILearningChartService`，编译通过。
2. 所有图表统一 ScottPlot，数据来自聚合 DTO，无独立 JSON/DB 查询。
3. 热力图、目标进度、记忆成熟度三类新图表在数据中心可用。
4. 明暗主题切换时全部图表颜色正确联动。
5. 空数据时显示占位引导，不展示假数值。

---

## 六、风险与注意事项

1. **删除影响面**：删除 `LearningChartService` 前先全局检索（`ServiceCollectionExtensions.cs`、各 Form 引用），避免残留编译错误。
2. **数据源切换**：图表改吃聚合 DTO 后，需等 **02 统计底座** 就绪后再替换，避免出现空数据回归。
3. **主题一致性**：新图表需实现 `IThemeable`，与现有主题色板保持一致，避免深浅色下看不清。
