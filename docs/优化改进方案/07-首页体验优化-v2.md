## 一、目标与边界

### 目标

1. 首页数据反映**当前用户、当前时刻**的真实状态（不再只在启动/切用户时刷新）。
2. 首页给出**下一步可执行动作**（到期复习、今日目标进度）。
3. 视觉与主界面、完整版首页保持同一套卡片语言与自适应布局。

### 本轮不做

| 项 | 原因 |
| --- | --- |
| “继续上次学习”（最近文档） | “最近打开”目前是 `PdfReaderForm` 私有逻辑，需要抽共享服务 + 用户隔离持久化，属独立需求 |
| 全局 DPI 缩放调整 | 影响全应用回归面，先记录为已知问题 |
| 首页推荐区 | 简洁版定位是做减法，推荐保留给完整版/学习数据页 |
| 立即删除 `DashboardView` | 先保留 `HomeStyle` 开关一个版本做回退，下版本再删 |

## 三、架构设计

### 3.1 HomeSnapshot：一次性聚合 DTO

```csharp
public sealed record HomeSnapshot(
    int TodayStudyMinutes, int StreakDays, int TotalXp,
    int Level, int XpToNextLevel,
    int CompletedChallenges, int TotalChallenges,
    int NoteCount, int TodayNewNotes,
    int DueReviewCount, int GoalCompleted, int GoalTarget);
```

- 新增 `LearningAssistant.Core/Models/Home/HomeSnapshot.cs`，附带 `IsBrandNew` 判定（供空状态使用）。
- 视图接口只保留一个方法：`IMainView.UpdateHomeSnapshot(HomeSnapshot snapshot)`，删除 `UpdateDashboardStats`。

### 3.2 聚合服务

- 新增 `IHomeSnapshotService` / `HomeSnapshotService`（Core）。
- 数据来源与降级顺序：

| 字段 | 主来源 | 降级 |
| --- | --- | --- |
| 今日分钟 / 连续天数 / XP / 等级 | `ILearningStatsAggregator.GetDailyOverview` | `IDataPersistenceService.LoadUserProfile` |
| 挑战完成数 | `IGamificationService.GetDailyChallenges` | 0 |
| 笔记数 / 今日新增 | `INoteService.GetNoteCount` / `GetNotes(userId)` 按 `CreatedAt` 过滤 | 0 |
| 待复习数 | `ISpacedRepetitionService.GetItemsDueForReview(userId)` | 0 |
| 今日目标 | `ILearningGoalService.GetDailyGoal` | 0 / 20 |

- 每个数据源独立 try/catch，单个源失败不拖垮整页，只记日志。

### 3.3 刷新协调器（MainPresenter）

- 订阅 `IEventBus` 的 `ItemLearnedEvent`、`ItemWrongEvent`、`ReviewDoneEvent`、`PomodoroCompletedEvent`。
- 300ms 防抖（`System.Threading.Timer`），后台线程聚合，`Interlocked` 防止重入。
- 视图更新统一走 `IMainView.UpdateHomeSnapshot`，`MainForm` 内部用 `InvokeRequired + BeginInvoke` 切回 UI 线程。
- `Dispose` / `SetView` 时退订事件并释放 Timer。

### 3.4 视图适配

- `SimpleHomeView` 新增 `ApplySnapshot(HomeSnapshot)`，并新增第 7 张统计卡“待复习”。
- `MainForm.UpdateHomeSnapshot` 同时喂给 `DashboardView`（保持完整版可用）。
- `UpdateRecommendations` 在简洁版首页激活时直接忽略，避免无意义后台请求。

## 五、验收标准（批次 A）

1. 有笔记的用户首页“笔记数”显示真实值，且今日新增正确。
2. “待复习”显示当前待复习项数量，与复习窗口首屏数量一致。
3. 完成一次学习/复习/番茄钟后，返回首页 ≤1s 数据更新，无需重启。
4. 切换用户后，首页数据为该用户数据（不串号）。
5. 简洁版首页激活时不再请求每日推荐。
6. `dotnet build` 通过，新增单元测试通过。

## 六、风险

| 风险 | 应对 |
| --- | --- |
| 聚合在后台线程访问 EF/SQLite，与 UI 线程并发读 | 聚合服务只读、短查询；失败降级为 0；后续可加缓存 |
| 事件高频触发导致刷新抖动 | 300ms 防抖 + `Interlocked` 防重入 |
| 两套首页数据口径漂移 | 统一由 `HomeSnapshot` 喂入，两套视图只做展示 |
| 接口替换影响其它实现 | 全库仅 `MainForm` 实现 `IMainView`，已确认 |
