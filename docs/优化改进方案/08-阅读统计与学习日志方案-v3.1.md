# 阅读统计与学习日志方案 v3.1

> 状态：设计定稿（P0 未实施）
> 日期：2026-11-04
> 范围：PDF 阅读行为统计、每日学习日志、阅读打卡与书籍进度
> 原则：结果指标优先、复用现有统计底座、P0 最小可用、不做虚荣指标

---

## 1. 背景与目标

原始想法：

- 记录每天看了哪个 PDF
- 听了多久音频
- 跟读了多少句
- 连续打卡多少天
- 累计读了多少本

经多轮收敛后，方案从“记录行为量”调整为“记录学习效果”。核心目标不是展示更多数字，而是回答三个问题：

1. 今天到底学了什么？
2. 阅读有没有产生学习结果？
3. 是否形成了可持续的习惯？

因此最终方案遵循：

- **结果指标优先**：新增学习项、已复习学习项、完成进度
- **行为指标降级**：阅读时长、收听时长、跟读句次只作为辅助
- **习惯指标稳健化**：连续打卡 + 本周达标天数，避免断签焦虑
- **统计必须可行动**：一个指标如果不能帮助用户做决定，就不放首页

## 2. 最终指标集

### 2.1 北极星指标

- 首页主指标：**本周学习达标天数**
- 阅读详情指标：**本周阅读达标天数**
- 辅助结果指标：本周新增学习项、已复习学习项、阅读进度增量

### 2.2 首页只放 3 张卡

1. **今日阅读**
   - 约 30 分钟 · 进度 68%（最远第 138/203 页）
   - “进度”按最远页计算，必须标注口径，不能叫“完成度”
2. **本周学习达标**
   - 5/7 天
   - 沿用现有 `DailyRollup` 的学习行为口径，不改变现有连击规则
3. **今日学习产出**
   - 新增学习项 5 · 已复习 3
   - 只统计去重后的学习项，不把高亮、生词、学习项相加

有音频的文档额外展示：

```text
今日跟读   9 句 · 覆盖率 24%
```

无音频文档不显示跟读/听力指标，不显示 0。

### 2.3 指标口径

| 指标 | 最终口径 | 说明 |
|---|---|---|
| 阅读时长 | PDF 前台活跃时长，60 秒心跳，90 秒无输入暂停 | 展示为“约 X 分钟”，不追求假精确 |
| 阅读进度 | `FurthestPage / PageCount` | 只代表最远页，不代表全书覆盖率 |
| 阅读覆盖率 | 去重已读页 / 总页数 | P1 再做；P0 不展示 |
| 收听时长 | 音频处于 Playing 且音量 > 0 的墙钟时长 | 仅作辅助，不单独作为成就依据 |
| 跟读句数 | 当天有 PracticeRecord 的去重 SentenceId 数 | 主指标用“已跟读句数” |
| 有效跟读句数 | 被采用，或评分达到阈值的句子数 | 评分缺失时隐藏“有效”，不虚构 |
| 跟读覆盖率 | 已跟读句 / 有音频且已切片的句子 | 分母只算可跟读片段，不用全书句子 |
| 跟读句次 | PracticeRecord 行数 | 只做明细，不上首页 |
| 本周学习达标 | 沿用现有 DailyRollup 规则 | 全应用口径 |
| 本周阅读达标 | 当天阅读 ≥ 5 分钟，或有效跟读 ≥ 5 句 | 阅读页内独立口径 |
| 当前连续 / 最长连续 | 当前连续沿用现有数据；最长连续从 DailyRollup 历史计算 | 不新增字段 |
| 在读书 | 有有效阅读或手动加入书架的文档 | 不把“打开过”算成在读 |
| 读完本数 | 用户手动确认；自动只做建议 | 不自动改状态，避免跳到最后一页误判 |
| 阅读产出 | P0 只统计新增学习项；高亮/笔记/生词 P1 | 不把不同单位相加 |

### 2.4 明确删除

- 累计打开本数
- 跟读句次作为首页指标
- 收听时长单独作为成就依据
- 阅读页数作为首页指标
- 按分钟发 XP
- 全书已读页位图作为用户指标
- 小于 1 分钟且无产出的会话日志
- “总学习时长”单一数字（改为分项展示）

### 2.5 每日日志

```text
2026-10-26 周日
📖 《新概念英语 2》 09:10–09:52 · 约 42 分钟 · 第 12–18 页 · 进度 68%
   产出：新增学习项 5 · 已复习 3
🎧 音频：完成 3/5 轨 · 重复听 2 次
🗣 跟读：12 句 · 有效 9 句 · 覆盖率 24%
📚 本周学习达标 5/7 天 · 连续 7 天（最长 12 天）
```

日志规则：

- 日志是视图，不建日志表
- 按“日期 + DocumentId”聚合 `ReadingActivity` 与 `PracticeRecord`
- 合并间隔小于 5 分钟的同一文档会话
- 小于 1 分钟且无产出的会话不展示，但底层保留
- 高亮、笔记、生词、学习项分列展示，不做“产出总数”

## 3. 数据模型

### 3.1 新增 `ReadingDocument`

文档/书籍身份账本。

| 字段 | 说明 |
|---|---|
| `QuickId` | 文档快速指纹，主键；避免大 PDF 首开卡顿 |
| `PdfHash` | 可空；异步补全，用于关联现有高亮/学习项 |
| `UserId` | 用户隔离 |
| `Title` | 展示标题，默认文件名/文件夹名 |
| `CurrentPath` | 当前路径，允许移动/改名后更新 |
| `PageCount` | PDF 页数或图片张数 |
| `Kind` | Pdf / ImageFolder |
| `FirstOpenedAt` / `LastOpenedAt` | 首次/最近打开 |
| `LastPageIndex` / `FurthestPage` | 最近页 / 最远页 |
| `Status` | Reading / Finished / Archived |
| `FinishedAt` / `FinishSource` | 读完时间 / 手动或自动建议 |
| `TotalReadingSeconds` | 可选冗余 |
| `TotalListeningSeconds` | 可选冗余 |
| `TotalShadowingSentences` | 可选冗余 |

### 3.2 新增 `ReadingActivity`

阅读与收听活动账本。

| 字段 | 说明 |
|---|---|
| `Id` | 主键 |
| `UserId` | 用户隔离 |
| `DocumentId` | 可空；独立音频允许为空 |
| `Kind` | Read / Listen |
| `StartedAt` / `EndedAt` | 活动起止时间 |
| `DurationSeconds` | 有效秒数 |
| `PageFrom` / `PageTo` | 阅读起止页 |
| `PagesSeen` | 本次访问去重页数 |
| `AudioTrackId` | 可空；音频活动关联轨道 |
| `MetadataJson` | 扩展信息，如倍速、播放来源、完成度 |
| `IdempotencyKey` | 唯一索引，防崩溃恢复重复计数 |

### 3.3 复用 `PracticeRecord`

不新建跟读统计表，只增加 3 个可空列：

- `DocumentId`
- `PageIndex`
- `SentenceId`

跟读继续走现有 `PracticeRecordService` 和 `PracticeCompletedEvent`。`SentenceId` 使用切片指纹，不使用句子序号，避免切片重新生成后句数虚增。

### 3.4 不新增

- `ReadingSession` 独立表
- `ReadingDailyRollup` 物化表
- `ReadingLog` 日志表
- 第二套目标/XP 系统

日志、进度、趋势都由账本实时聚合；查询变慢再加索引或物化，不提前优化。

### 3.5 文档身份与哈希

- PDF `QuickId`：文件大小 + 首尾分块哈希 + 页数，避免每次全量 SHA256
- `PdfHash`：后台异步补全；高亮/学习项按 `PdfHash` 关联
- 哈希未完成时，产出统计按路径兜底；完成后切换到哈希关联
- 同一本书出现两个文档时，按 `PdfHash` 合并并重关联活动
- 图片文件夹 P0 使用规范化路径作为身份；文件夹移动会视为新书，P1 再优化
- 现有高亮 `PdfHighlight.PdfHash`、学习项 `StudyEntry.SourcePdfHash` 可直接复用

### 3.6 索引

- `ReadingDocument(UserId, LastOpenedAt)`
- `ReadingDocument(UserId, PdfHash)`（PdfHash 非空时唯一）
- `ReadingActivity(UserId, StartedAt)`
- `ReadingActivity(UserId, DocumentId, StartedAt)`
- `ReadingActivity(IdempotencyKey)` 唯一
- `PracticeRecord(UserId, DocumentId, CreatedAt)`
- 现有高亮/学习项的 Hash 索引需确认可用

### 3.7 迁移与备份

- 新增表使用幂等建表
- `PracticeRecord` 三列使用幂等 `ALTER TABLE`
- 迁移前自动备份数据库
- 备份/导出必须包含阅读相关表
- 提供“清除阅读历史”入口，默认只清统计不删 PDF

## 4. 计时模型

### 4.1 主活动状态机

不做时间区间并集，使用单主活动状态机。

| 优先级 | 状态 | 规则 |
|---|---|---|
| 1 | 跟读 | 跟读窗口激活/录音中 |
| 2 | 阅读 | PDF 窗口激活且 90 秒内有输入 |
| 3 | 收听 | 音频 Playing 且音量 > 0，且无更高优先级活动 |
| 4 | 空闲 | 最小化、切后台、无输入、睡眠 |

### 4.2 计时规则

- 只有主活动计入 `DailyRollup` 总学习时长
- 阅读 + 听音频同时发生：阅读为主，总时长只计阅读；收听单独记录，不相加
- 只听音频不阅读：收听为主，计入总学习时长
- 60 秒心跳；90 秒无输入暂停阅读计时
- 睡眠/挂起超过 2 分钟的间隔直接丢弃
- 跨午夜按 00:00 切分到两天
- 多窗口只计焦点窗口
- 切换用户先结算旧会话，防止串数据

### 4.3 音频规则

- `Playing` 才累计；暂停、停止、跳转不累计
- 倍速按真实墙钟时长
- AB 循环每轮都算
- 播放器需要增加 `PlaybackSource`：Original / Shadowing / TTS
- TTS 不计入听力时长；没有 `PlaybackSource` 时该规则无法可靠实现
- 音频归属在播放开始时绑定当前文档；无文档则记为独立音频
- 音量检测以应用音量为主，不依赖系统静音状态

### 4.4 跟读规则

- 每句以切片指纹去重
- 同一天同一句练 5 次：跟读句数 1，跟读句次 5
- “有效”优先用“被采用”；无采用数据时用评分阈值
- 评分缺失时隐藏“有效句数”，不显示假数据
- 覆盖率只在有音频/切片时展示

### 4.5 持久化

- 每个连续活动段落写一行 `ReadingActivity`
- 心跳只更新内存，不每分钟写库
- 每 60 秒或会话结束时批量落盘
- 关闭/崩溃恢复使用 `IdempotencyKey` 幂等

## 5. 数据流与现有链路复用

```text
PDF 打开/翻页/关闭
  -> ReadingSessionTracker（Core）
  -> ReadingActivity
  -> LearningStatsAggregator.RecordStudyTime（仅主活动）
  -> DailyRollup（总时长/连击）

跟读 take 保存
  -> PracticeRecordService
  -> PracticeCompletedEvent
  -> 聚合器订阅（句数/时长）+ 阅读日志

学习项
  -> StudyEntry.SourcePdfHash
  -> 按 PdfHash 关联 ReadingDocument
```

## 9. 验收用例

1. 打开 PDF 20 秒 → 不产生日志，但原始数据保留
2. 阅读 30 分钟，切后台 20 分钟 → 只记约 10 分钟
3. 听音频 10 分钟，暂停 5 分钟 → 只记 10 分钟；TTS 不计
4. 同一句跟读 5 次 → 跟读句数 1、句次 5、有效句数按采用/评分计算
5. PDF 移动/改名 → 仍算同一本；学习项产出仍能关联
6. 23:50 读到 00:10 → 两天各记各的
7. 两个 PDF 窗口切换 → 不重复计时
8. 切换用户 → 不串阅读记录
9. 进程被杀后重开 → 已结算时长不重复
10. 空数据 → 首页和详情显示空状态，不显示假数字
11. 本周有休息日 → “本周学习达标 5/7”正确，不清空最长连续
12. 30 天日志首屏目标 < 200ms（本地库）
13. 无音频文档 → 不显示跟读/听力指标
14. 图片文件夹移动 → P0 视为新书，行为符合文档说明

## 10. 边界与默认决策

| 场景 | 默认决策 |
|---|---|
| “读完” | 只手动确认；自动建议 P1 |
| 收听计入主学习时长 | 仅当收听为主活动时计入；边读边听不重复计入 |
| 本周学习达标 | 沿用现有 DailyRollup 口径，不改变现有连击 |
| 本周阅读达标 | 阅读 ≥ 5 分钟，或有效跟读 ≥ 5 句 |
| P0 阅读产出 | 只统计新增学习项；其他产出 P1 |
| TTS | 不计入听力时长 |
| 独立音频 | `DocumentId` 允许为空 |
| 图片文件夹身份 | P0 用规范化路径；P1 再做内容指纹 |
| XP | 不按分钟发放；P1 只对读完、达标、有效跟读发奖励 |
| 数据隐私 | 文件名、路径、阅读记录只存本地；可清除；备份包含新表 |

## 11. 版本演进结论

- v1：4 张新表 + 完整统计体系，偏重
- v2：收敛为 2 张新表 + 复用 PracticeRecord
- v3：从行为统计转向学习效果，删除虚荣指标
- v3.1：进一步收敛 P0，明确“进度/覆盖率/完成”口径，产出只算学习项，首页降为 3 张卡

**最终原则：继续优化时应加“目标、对比、行动建议”，而不是继续增加指标。**
