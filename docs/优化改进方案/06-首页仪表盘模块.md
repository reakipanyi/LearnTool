# 优化改进方案 · 06 · 首页仪表盘模块

> **对应问题**：问题二 · 集成 —— 首页 Dashboard 写死假数据、统计入口失效、与统计中心未打通。
> **对应优化项**：O-002（首页 Dashboard 真实数据 + 空状态），**P0**；含侧边栏统计入口恢复（与 O-003 配合）。
> **关联问题编号**：W-008（部分）/ W-010（需求挖掘）；B-010（边界场景）。
> **依赖**：数据来自 **02 统计底座**；入口跳转 **04 学习数据中心**。

---

## 一、现状分析

- 首页 StatCard（`Forms/UserControls/Dashboard/DashboardView.cs`）构造时**写死初始值**（25分钟/7天/120/Lv.5/0/0），仅部分被 `UpdateDashboardStats` 覆盖（W-010）。
- 统计入口失效：侧边栏“统计”项被注释（L212）；`buttonOpenStatistics`（L792）未挂接 Click 事件（W-008）。
- 首页与统计中心未打通：StatCard 不可点击下钻，无空状态引导（B-010）。

---

## 二、问题清单

| 编号 | 问题 | 影响 |
| --- | --- | --- |
| W-008 | 统计入口失效：侧边栏“统计”被注释、`buttonOpenStatistics` 无 Click 事件 | 用户无法从首页进入统计 |
| W-010 | 首页 Dashboard StatCard 构造写死初始值（25分钟/7天/120/Lv.5 等） | 空数据展示假数值，体验差 |

---

## 三、优化方案

### 3.1 首页真实数据

- 移除 `DashboardView` 构造时的写死初始值（L122-L133），改为统一聚合服务返回**真实数据**。
- `UpdateDashboardStats`（`MainPresenter`）改由 `LearningStatsAggregator` 汇总（时长/连击/经验/等级/挑战/笔记）后下发。

### 3.2 空状态引导

- 无数据显示占位（“暂无数据，开始学习吧”）而非假数值；提供“去学习 / 导入内容”引导入口。

### 3.3 恢复侧边栏“统计”入口

- 新增 `NavigationItem { Key="statistics", Text="📊 学习数据" }`，点击打开统一学习数据中心。
- 修复/移除 `buttonOpenStatistics` 死路径，统一改走 `WindowManager.OpenLearningManagementWindow`（或新方法 `OpenStatisticsCenter`）。

### 3.4 卡片下钻

- 首页 StatCard 可点击跳转到学习数据中心对应 Tab（今日时长→概览趋势、正确率→错题、保留率→记忆），形成“首页看概览 → 中心看明细”闭环。

## 五、验收标准

1. 首页 StatCard 显示真实聚合数据（时长/连击/经验/等级/挑战/笔记），无写死假值。
2. 新用户无数据显示空状态引导（“暂无数据，开始学习吧” + 去学习/导入入口）。
3. 侧边栏出现“📊 学习数据”入口，点击打开学习数据中心。
4. 首页 StatCard 可点击下钻到数据中心对应 Tab。
5. 学习/复习/番茄完成后，返回首页 Dashboard 数据自动刷新（配合 EventBus）。

---

## 六、风险与注意事项

1. **依赖就绪**：首页真实数据依赖 02 聚合服务就绪，P0 阶段先保证数据底座落地。
2. **死路径清理**：移除 `buttonOpenStatistics` 前先全局检索引用，避免残留编译错误。
3. **刷新时机**：首页 Dashboard 需订阅 EventBus 学习事件实时刷新，避免展示过期数据。
