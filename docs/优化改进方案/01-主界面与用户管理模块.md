> **对应问题**：问题一 —— 首页用户切换不灵活、顶部 ➕ 新增按钮功能重复、旧布局死代码遗留。
> **对应优化项**：O-006（首页用户切换改版，P2，可并行实施）。
> **关联问题编号**：W-001 / W-002 / W-003（需求挖掘）；C-007（需求冲突）；B-003（边界场景）。

## 一、现状分析

首页（新布局 `useNewLayout`）顶部栏布局（见 `Forms/MainForm.cs` 的 `PanelTopBar_Resize`，约 L400-L412）：

```
[logo][标题]                     [🌙 主题切换][➕ 新增用户][用户下拉框 comboBoxNewLayoutUser]
```

- **用户切换**：`comboBoxNewLayoutUser`（`ComboBoxStyle.DropDownList` 下拉框），切换事件 `ComboBoxNewLayoutUser_SelectedIndexChanged`（L1211-L1222）同步旧下拉框、刷新 Dashboard 欢迎语并触发 `UserChanged`。
- **新增按钮**：`buttonNewUser`（➕，`ButtonNewUser_Click`，L1224）触发 `NewUserClicked` → `MainPresenter.CreateNewUser()`。
- **遗留旧代码**：老布局 `comboBoxUser` + `groupBoxUser`（L784-L786、L956、L1206）仍与新版下拉框双向同步，属于死代码，增加维护与误同步风险。

**用户数据链路（保持复用，不改动）**：
- `MainForm.RefreshUserList` / `MainPresenter.RefreshUsers` → 加载用户列表；
- 切换用户走 `SelectedUser` 设置 → `UserChanged` 事件 → Dashboard 欢迎语/统计刷新；
- 设置窗体关闭后刷新用户列表（MainForm L591-L592 已有该逻辑）。

## 三、优化方案

**方案：头像 + 昵称的可点击入口 + 弹出式用户切换面板（替代下拉框）**

### 3.1 入口形态

将顶部“用户下拉框”替换为一个“用户入口”控件：

- 左侧**圆形头像**（按用户生成默认底色 + 首字，已有头像则显示头像图）。
- 右侧显示**昵称**（可含小三角指示符，示意可展开）。
- 整体作为单个按钮：`Cursor.Hand`，hover 有浅色背景反馈，与主题联动（`ApplyTheme` / 实现 `IThemeable`）。
- 点击后弹出**浮层面板**（Pop-up Panel / `ContextMenuStrip` 均可，**推荐自定义浮层**以支持自定义样式与统计预览）。

### 3.2 浮层面板内容（自上而下）

1. **当前用户信息区**：头像、昵称、等级徽章、连续学习天数等一行概览。
2. **用户列表区**：每个用户一行（头像 + 昵称 + 简短统计，如“连续 N 天”），**高亮当前用户**，点击即切换（复用现有 `SelectedUser` 设置逻辑与 `UserChanged` 事件）。
3. **底部操作区**：两个入口项 —— **“➕ 添加用户”** 与 **“⚙️ 管理用户”**，点击后统一跳转到设置窗体的用户管理分组（`OpenSettingsClicked`），**不在首页内联新增**，消除重复。

### 3.3 行为细节

- 切换后关闭浮层，刷新首页欢迎语与统计（现有 `dashboardView.UserName`、`UserChanged` 链路保持）。
- 支持键盘：焦点在入口上按 `Enter/Space` 打开、`Esc` 关闭、`↑/↓` 选择用户。
- 用户列表数据复用 `RefreshUserList` / `MainPresenter.RefreshUsers`；设置窗体关闭后刷新（MainForm L591-L592 已有此逻辑，保持）。
- 面板点击外部区域自动关闭（失焦处理）。

### 3.4 删除项

- 删除顶部 ➕ `buttonNewUser`（含 `ButtonNewUser_Click`；`NewUserClicked` 事件订阅链 `View_NewUserClicked` → `CreateNewUser` 可一并移除，或保留事件但入口只在设置中）。
- 清理旧布局 `comboBoxUser`、`groupBoxUser`、`labelUser` 及其同步逻辑（`ComboBoxUser_SelectedIndexChanged`、`RefreshNewLayoutUserList` 中同步旧框的代码）。
- 移除 `buttonNewUser` 相关主题设置（MainForm L99-L102）与顶部布局代码（L1141-L1154）。

### 3.5 可访问性 / 扩展

入口控件独立成 `UserSwitcherControl`（UserControl），便于后续接入“用户对比”“最近用户”等扩展。

### 3.6 补充增强（按优先级）

| 补充点 | 优先级 | 说明 |
| --- | --- | --- |
| **最近/上次用户** | 🔴 高 | 启动自动选中上次登录用户；面板顶部加“最近使用”区（最近 N 个） |
| 用户条目**统计预览** | 🟡 中 | 每条展示今日进度/正确率/连续天数（非仅“连续 N 天”），数据来自 02 聚合 DTO |
| **头像管理增强** | 🟡 中 | 支持从文件选图、截图生成；丰富默认头像（表情/配色主题，按用户名哈希） |
| **用户归档/冻结** | 🟡 中 | 可隐藏不再使用的用户（保留数据、可恢复），避免只能删除；设置窗体补“归档/恢复”入口 |
| 用户列表**搜索/过滤** | 🟠 中低 | 用户较多时按昵称过滤 |
| 面板内**编辑当前用户资料** | 🟢 低 | 改名/换头像直改，减少跳设置（可选，MVP 可不做） |
| **快捷键切换用户** | 🟢 低 | `Ctrl+1/2/3` 或全局热键（复用 `HotkeyService`） |

> 补充点与 02 聚合服务有数据依赖的（统计预览），在 02 就绪后接入。

## 五、验收标准

1. 顶部不再有下拉框与 ➕ 按钮，替换为头像 + 昵称入口，hover 有反馈、主题联动。
2. 点击入口弹出浮层面板：含当前用户概览、用户列表（高亮当前）、添加/管理入口。
3. 面板内点击用户即切换，Dashboard 欢迎语与统计随之刷新，`UserChanged`/`SelectedUser` 对外接口行为不变。
4. “添加用户 / 管理用户”统一跳转设置窗体用户管理分组，首页不再内联新增。
5. 全库检索确认无 `comboBoxNewLayoutUser` / `buttonNewUser` / `comboBoxUser` / `groupBoxUser` 残留引用（编译通过）。
6. 键盘可达（Enter/Space/Esc/↑↓），点击外部关闭面板。
7. （增强）启动自动选中上次用户；面板含“最近使用”区与用户统计预览。
8. （增强）用户可归档/恢复，归档用户不再出现在切换列表但数据保留。
9. （增强）用户切换整体 ≤ 2 次点击完成，KPI 达标（见 00 六）。

## 六、风险与注意事项

1. **接口兼容**：保持 `UserChanged`/`SelectedUser` 对外接口与设置窗体刷新逻辑不变，避免破坏现有用户会话链路（`UserSessionService`）。
2. **死代码清理影响面**：删除前先全局检索 `comboBoxNewLayoutUser`/`buttonNewUser`/`comboBoxUser`/`groupBoxUser` 引用，防止残留编译错误。
3. **头像资源**：默认头像底色按用户名哈希生成，避免额外头像文件依赖；已有 `AvatarPath` 的优先使用。
