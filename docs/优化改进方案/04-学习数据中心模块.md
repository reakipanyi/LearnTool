# 优化改进方案 · 04 · 学习数据中心模块

> **对应问题**：问题二 · UI —— 统计界面多套并存、语义混乱、统计入口失效。
> **对应优化项**：O-003（统一“学习数据中心” Tab 化 + 恢复统计入口），**P1**。
> **关联问题编号**：W-007 / W-008（需求挖掘）；C-006（需求冲突）。
> **依赖**：数据来自 **02 统计底座**，图表来自 **03 图表可视化**，报告页来自 **05 报告模块**。

---

## 一、现状分析

当前统计界面多套并存、语义混乱：

| 界面 | 位置 | 定位 |
| --- | --- | --- |
| `LearningStatsForm` | `Forms/LearningHubForm.cs` 内嵌 | 最早的初版，MiniLineChart，JSON 统计 |
| `LearningManagementForm` | `Forms/LearningManagementForm.cs` | 功能较全：ScottPlot 趋势/遗忘曲线/分类/评分分布图、热力图、目标日历、错题统计、算法切换 —— **当前实际承载统计的主力** |
| `ResultForm` 的“学习统计图表” | `Forms/ResultForm.cs`（`groupBoxChart` + `ChartControl`） | 由 `WindowManager.OpenStatisticsWindow`（L263）→ `ResultPresenter`/`IResultView` 打开，与“统计”语义不符（结果页充当统计页） |

**统计入口失效**：`MainForm` 侧边栏已把“统计”项注释掉（L212）；`buttonOpenStatistics`（L792）**未挂接 Click 事件**，`PerformClick()`（L440/L537）为空操作。当前侧边栏仅 6 项（首页/学习/内容编辑/PDF阅读/浏览器/设置），**没有统计入口**。

## 三、优化方案

### 3.1 以 `LearningManagementForm` 为基座重构为 Tab 布局（`TabControl`）

| Tab | 内容 |
| --- | --- |
| 概览 | StatCard 组（今日时长/数量/正确率/连续/等级/目标达成）+ 趋势图（`LearningTrendChart`） |
| 记忆 | 遗忘曲线（`ForgettingCurveChart`）+ 保留率 + 记忆成熟度（`MemoryMaturityChart`）+ 复习效率（评分分布 `ReviewDistributionChart`）+ 学习热力图 |
| 错题 | 复用 `WrongAnswerStatsPanel`/`WrongAnswerCard`，支持导出 Markdown |
| 目标 | `GoalCalendarView` + 目标达成进度图 |
| 报告 | 图形化报告卡片（见 05 报告模块） |
| 对比 | 多用户数据对比（复用 `MainPresenter.LoadUserComparison` 遗留逻辑，支持切换/新增对比用户） |

### 3.2 废弃旧统计角色

- **废弃** `LearningHubForm` 内嵌的 `LearningStatsForm`。
- **`ResultForm` 恢复为纯“学习结果”用途**：从 `WindowManager.OpenStatisticsWindow` 解耦，统计统一走学习数据中心。

### 3.3 交互增强

- **实时刷新**：订阅 `EventBus` 学习事件，学习/复习/番茄完成后自动刷新当前统计 Tab 与首页 Dashboard，避免返回时数据仍是旧的（配合 02 的缓存失效）。
- **卡片下钻**：概览 StatCard 可点击进入对应 Tab（今日时长→趋势、正确率→错题、保留率→记忆），而非只看数字。
- **时间范围与筛选**：提供“今天/本周/本月/自定义”范围切换 + 科目/分类筛选，趋势、分类、报告联动。
- **空状态引导**：新用户无数据时显示引导（去学习 / 导入内容），而非满屏 0。
- **灰度切换**：统计中心重构期间保留旧入口，通过功能开关（设置项）平滑切换，便于回滚。

## 五、验收标准

1. 侧边栏恢复“统计”入口（📊 学习数据），点击打开统一学习数据中心。
2. 学习数据中心 Tab 化完成：概览/记忆/错题/目标/报告/对比 6 个 Tab 均可访问。
3. `LearningStatsForm` 已移除，`ResultForm` 不再承担统计角色（编译通过、无残留引用）。
4. 实时刷新：学习/复习/番茄完成后返回统计中心数据为最新。
5. 时间范围 + 科目/分类筛选生效，联动趋势/分类/报告。
6. 新用户无数据显示空状态引导（去学习 / 导入内容），无满屏 0。
7. 灰度开关：重构期间旧入口并存，可回滚。

## 六、风险与注意事项

1. **移除旧组件影响面**：删除 `LearningStatsForm`、`buttonOpenStatistics` 前先全局检索引用（已有 `WindowManager` L263、`LearningHubForm` 等），避免残留编译错误。
2. **行为兼容与回滚**：统计中心重构期间通过灰度开关保留旧入口，便于回滚。
3. **依赖就绪**：Tab 化重构依赖 02 聚合服务与 03 图表层就绪，需按阶段顺序落地。
