## 重点测试用例

### 🔴 重点1: AI问答功能（核心功能）

```
测试场景: PDF中选中文字进行AI问答
操作步骤:
1. 打开PDF阅读器
2. 打开一个包含英文的PDF
3. 选中一段英文文字
4. 点击"AI问答"或输入问题
5. 观察AI返回的回答

验收标准:
- [ ] AI服务正常响应
- [ ] 回答内容与问题相关
- [ ] 无异常或报错
```

### 🔴 重点2: 错题导出功能（本次重构重点）

```
测试场景: 导出学习过程中的错题
操作步骤:
1. 打开学习界面
2. 开始学习（标记不认识的内容）
3. 学习10个以上生词
4. 点击"导出错题"按钮
5. 在弹出的对话框中选择保存位置
6. 确认保存

验收标准:
- [ ] 弹出保存文件对话框
- [ ] 保存成功后显示提示
- [ ] 文件内容包含错题
- [ ] 文件编码正确（中文显示正常）
```

### 🔴 重点3: 学习进度保存与恢复（本次重构影响）

```
测试场景: 学习后关闭，次日继续
操作步骤:
1. 打开学习界面
2. 开始学习
3. 标记若干单词为"认识/不认识"
4. 完成一轮学习后关闭界面
5. 重新打开学习界面
6. 选择继续学习

验收标准:
- [ ] 进度正常保存
- [ ] 重新打开后显示之前进度
- [ ] 不认识的单词仍在列表中
```
