# 文字游戏 设计方案

> 项目：LearningAssistant（WinForms + WebView2）
> 目标：新增一款 **"文字奇境"（Word Wonderland）** 游戏集合：包含「猜词字谜」「词语接龙」「填字游戏（Crossword）」「成语消消乐」四种子模式，覆盖汉字构形、词汇量、语义联想与成语积累；深度复用语文/英语科目词库，错题闭环复习。
> 本文档只做方案设计，不涉及代码实现。

---

## 1. 背景与目标

现有配对游戏（消消乐/翻牌/连连看/打地鼠/拼写）均围绕「词 ↔ 释义」的**双向映射**展开，缺少：
- 「根据线索猜词」的**语义推理**玩法；
- 「接龙/Crossword」的**词与词组合网络**玩法；
- 「成语专项」的**四字结构/典故**玩法。

本方案设计 **"文字奇境"**：
- 复用 WebView2 静态页 + `WebView2GameFormBase` + 词库/错题服务；
- 四款子模式覆盖中文/英文：
  1. **猜词字谜（Hangman 变体）**：释义/拼音/偏旁做线索，逐字/逐字母猜词；
  2. **词语接龙**：前一词尾字 = 后一词首字（同音可放宽），训练词汇量与反应；
  3. **填字游戏（Crossword 迷你版）**：5×5 / 7×7 网格，根据纵横线索填字；
  4. **成语消消乐**：打散四字成语的字卡，按顺序拼合成完整成语即消除。
- 与科目联动：英语=单词/短语，语文=词语/成语/古诗词句；错题入本。

## 2. 玩法设计

### 2.1 主模式选择页
启动进入「文字奇境大厅」，四张模式卡；顶栏含「科目（中文/英文）」+「子类别（词语/成语/诗词）」+「难度」下拉。

| # | 子模式 | 图标 | 核心能力 | 适用科目 |
|---|---|---|---|---|
| 1 | 猜词字谜 | 🪢 | 线索推理 + 拼写（字/字母） | 中文 + 英文 |
| 2 | 词语接龙 | 🔗 | 尾字衔接 + 词汇检索速度 | 中文为主（英文可做 Word Chain） |
| 3 | 迷你填字 | 📜 | 纵横线索 + 字/字母组合 | 中文 + 英文 |
| 4 | 成语消消乐 | 🈶 | 成语结构识别 + 字序拼合 | 中文（成语专项） |

---

### 2.2 子模式一：猜词字谜（Word Detective — Hangman 变体）
**经典"吊死鬼"变体，不限错误次数，改用**「线索预算」**：每开一条线索消耗 1 点，开得越少星级越高。**

- **题干结构**：每个词给出**多种线索**，玩家可按顺序解锁：
  - 中文：① 字数提示 + 词性 → ② 拼音/部首 → ③ 释义 → ④ 例句 → ⑤ 首字提示；
  - 英文：① 字母数 + 词性 → ② 音标 → ③ 释义（英/中） → ④ 例句 → ⑤ 首字母提示。
- **输入**：
  - 中文：按格输入整词（拼音输入法友好，WebView2 支持 IME）；
  - 英文：可逐字母猜（保留传统 Hangman 体验）或整词输入。
- **线索预算机制**（替代"吊死鬼"死亡惩罚，更适合儿童）：
  - 开局预算 = 5 颗 ★；
  - 每解锁一条线索 = −1 ★；
  - 一次猜中（未开/少开线索）→ 剩余 ★ 越多得分越高，最高保留 5 ★；
  - 猜错 1 次 = −0.5 ★（折算），不终止。
- **词库联动**：从中文/英文科目抽词（`MainContent` = 词，`Meaning` = 释义，`Example` = 例句，`Pronunciation` = 拼音/音标）；错题优先。
- **限时**：每词 30s；整局 60s/90s 多词冲量模式。
- **反馈**：
  - 对：🎉 + 释义/例句展开巩固；
  - 错：红闪 + 字形/字母对比提示；
  - 线索：星星消耗飘字 `−1 ★`。

---

### 2.3 子模式二：词语接龙（Word Chain）
**开局给出起始词，玩家输入的新词首字必须等于上一词尾字（同音可放宽为规则选项）。**

- **起始词**：从词库随机抽取（成语 / 常用二字词），展示在最顶。
- **输入**：玩家输入下一个词 → 系统判定：
  - **首字匹配**（严格）：newWord[0] == lastWord[-1]；
  - **同音匹配**（可选）：`拼音相同` 但字不同，给 0.8 倍分；
  - **重复词 / 不存在词**：失误提示，允许重来。
- **校验词是否存在**：
  - 优先查当前子类别词库；
  - 未命中则查**内置常用词白名单**（`Common/ChineseWordDictionary.txt` / `EnglishWordDictionary.txt`，启动时加载到 HashSet），避免因词库覆盖不全误判"不存在"。
- **限时**：
  - **持续模式**：总时长 90s，每成功一词奖励 +3s，看能接多长；
  - **回合模式**：20 回合目标，看用多少时间。
- **AI 对手（可选进阶）**：单人模式下，玩家答一词 → AI 用白名单 + 词库自动接回一词，形成"人机对战接龙"。
- **词库联动**：玩家输入且判定合法的词，若命中词库词条 → 做一次"快速复习标记"；答错/超时的词（系统给出的接词）若词库有 → 记错题。

---

### 2.4 子模式三：迷你填字（Mini Crossword）
**5×5 或 7×7 方格迷你填字，纵横各 5–7 条线索，填中文单字或英文单字母。**

- **盘面生成**：
  - 用**预生成题库**（每盘一个 JSON：格子坐标 + 线索 + 答案），避免前端实时生成合法填字网格的 NP 复杂度；
  - 内置 20 盘初版题库：中文 5×5 / 英文 5×5 各 10 盘；后续服务端可按词库模板化生成（`FillCrosswordPuzzle(words, size)` 启发式回溯，做离线生成工具而不是线上生成）。
- **线索结构**：
  - 每条线索编号「横/纵 + 序号」；
  - 内容 = 释义/拼音/首字母提示；
  - 玩家点编号 → 高亮整行/列 → 逐个格输入。
- **校验**：
  - 「逐格实时校验」（可选开关）：输入后立刻绿/红显示；
  - 「整盘提交」：点「检查」按钮一次性判定，错误标红。
- **难度**：
  - **简单**：5×5，中文填成语格 / 英文填简单单词，逐格实时校验；
  - **普通**：5×5 或 6×6，无实时校验；
  - **困难**：7×7，中英文混合（纵横不同语言）。
- **提示**：消耗 1 次提示机会 = 自动填 1 个空白格（从词库答案中随机挑最需要的）。
- **词库联动**：每盘的横纵词/字若命中学习词条 → 完成时做复习标记；多次提示仍错的词条记错题。

---

### 2.5 子模式四：成语消消乐（Idiom Crush）
**盘面上散落若干"字卡"，每 4 张按正确顺序可拼成一句成语，拼对即可消除。**

- **盘面**：6×5 = 30 张字卡（约 7–8 条成语混合打散）；
- **字卡内容**：单字（中文）；每条成语 4 字 × 8 条 = 32 字，略多于盘面积时先铺一部分，消除后补入剩余字卡。
- **操作**：依次点击 4 张字卡 → 若能拼成一条成语（**字序必须正确**，也可放宽"字对就行不管顺序"的简单档）→ 消除 + 高亮展示该成语的"释义 + 典故"。
- **成语词库联动**：从「语文/成语」子类别抽 `LearningItem`：
  - `MainContent` = 成语本身（如"画蛇添足"）→ 拆成 4 张字；
  - `Meaning.Content` = 释义，消除后展示；
  - `Example` = 典故/例句（可选展示）。
- **难度**：
  - **简单**：一次只铺 2 条成语 8 字 + 不要求字序（4 字全对就消）；
  - **普通**：6–8 条成语混合 + 必须字序；
  - **困难**：10+ 条成语 + 干扰字（故意混入非成语的字）。
- **死局**：若剩余字无法拼成任何一条 → 自动补入新字卡 / 重排。
- **发音**：点字卡用系统 TTS 读字；消除后整句成语连读。

---

### 2.6 通用计分与结算
- **计分**：
  - 猜词字谜：基础分 × 剩余线索星数；
  - 接龙：每成功一词基础分 × 连击 + 连续严格匹配加成；
  - 迷你填字：每填对 1 格基础分，整盘全部正确大加分；
  - 成语消消乐：每消一条基础分，附展示释义 + 连击；
- **星级**：得分 → ★★★ / ★★ / ★ / 加油。
- **结算页**：得分、正确词数、失误、最高连击、用时、成语消消乐=学会的成语列表、接龙=链长。
- **再来一局 / 换一组 / 回大厅**。

## 3. 数据接入方案

### 3.1 词库取词
- **通用取词**：复用 `WordMatchGameService.BuildItems(context, N, WordSelection.WrongFirst)`，科目支持 `Chinese` / `English`。
- **成语专项取词**：在 `BuildItems` 基础上，过滤 `SubCategoryType.ChineseIdiom`（若存在）；若词库成语不足 → 回退到**内置成语白名单**（`Common/IdiomDictionary.txt`，约 500–1000 条常用成语 + 释义，启动加载为只读 DTO 列表）。
- **接龙校验词白名单**：同上，`ChineseWordDictionary.txt`（二字/三字/四字常用词）、`EnglishWordDictionary.txt`（CET-4/6）。

### 3.2 新增服务：`TextGameService`
轻量服务，封装「白名单加载 + 接龙合法性校验 + 填字题库 + 成语拆字工具」：

```csharp
public class TextGameService
{
    // 加载：成语白名单 + 接龙词白名单 + 填字题库
    void EnsureDictionariesLoaded();

    // 接龙校验：词是否存在 + 首字是否等于 lastTail
    ChainValidateResult ValidateChain(string lastTail, string newWord, bool allowHomophone);

    // AI 接龙：给定尾字，返回一个合法下一词（从白名单 + 词库中随机）
    string? AiChainNext(string tail);

    // 成语拆字：把成语 MainContent 拆成 4 个字卡 DTO
    List<IdiomCharDto> SplitIdiom(LearningItem item);

    // 从填字题库拿一盘（按难度/语言）
    CrosswordPuzzleDto GetCrossword(string language, Difficulty diff);

    // 结果回写：答错/未完成的词条 + 猜词字谜线索消耗记录
    void ApplyTextResults(string userId, LearningContext ctx, IReadOnlyList<TextResult> results);
}
```

### 3.3 BuildData 返回结构
```jsonc
{
  "modes": [/* 四款元信息 */],
  "language": "zh|en",
  "libraryItems": [/* 词库抽的 N 条 */],
  "idiomPool": [/* 成语白名单（仅成语消消乐用） */],
  "wordChainDictCount": 12345, // 接龙词典条目数，前端展示
  "crosswordPuzzle": {/* 当前盘线索+答案 */},
  "difficulty": "easy|normal|hard"
}
```

### 3.4 宿主窗体
新增 `TextGameForm`：
- 继承 `WebView2GameFormBase`；
- `FormTitle` → "📝 文字奇境"；
- `HtmlFileRelativePath` → `Resources/TextGame/index.html`；
- 顶栏保留科目（中/英）+ 子类别 + 难度下拉；
- `BuildData` → `WordMatchGameService.BuildItems(...)` + `TextGameService` 组合返回。

## 4. 前端页面设计（静态 HTML）

### 4.1 文件组织
```
Resources/TextGame/
  index.html                # 大厅 + 四模式容器
  style.css                 # 四模式样式、动效、主题
  game.js                   # 路由、计分结算、通信、通用工具

    hangman.js              # 猜词字谜：线索解锁、输入、星级评分
    wordChain.js            # 词语接龙：输入校验、AI 对手（可选）
    crossword.js            # 迷你填字：网格渲染、线索、输入校验
    idiomCrush.js           # 成语消消乐：字卡、拼合成语、消除动效
  utils/
    pinyin.js               # 纯函数：同音判定（白名单字→拼音表，静态加载）
```
- 纯原生 JS，`?mock=1` 内置示例数据。
- 拼音同音字判定：预加载一份 `{汉字→拼音首字母/完整拼音}` 的小型 JSON 表（约 7000 常用字即可），避免调用宿主。

### 4.2 页面结构
- **大厅层**：四张模式卡 + 顶栏。
- **猜词字谜层**：
  - 左侧：线索面板（5 条，锁🔒→开），每条消耗 ★；
  - 中央：输入框 + 提交按钮 + 词格（单词用占位下划线条纹）；
  - 右/底：剩余 ★ 进度条。
- **接龙层**：
  - 顶部：链长 + 计时 + 得分；
  - 中部：已接词列表气泡流（横向滚动），最新高亮；
  - 底部：输入框 + 提交 + 跳过（−0.5★）。
- **填字层**：
  - 左：格盘（CSS grid，每格可聚焦输入）+ 编号；
  - 右：横纵线索面板（点编号 → 高亮行/列）；
  - 底：检查 / 提示 / 重置 按钮。
- **成语消消乐层**：
  - 顶：目标进度（已消 / 总数）+ 连击；
  - 中：字卡格盘（每张字卡可点）；
  - 底：已选 4 字槽（显示选择顺序）+ 取消按钮。

### 4.3 IME 友好（中文输入）
- 所有输入框设置 `ime-mode: active`（WebView2 内 Chromium 支持）；
- 判定触发：`keydown Enter` 提交，不用 `input` 事件实时判定，避免 IME 组合过程误触发。

## 7. 与现有游戏差异与复用点

| 维度 | 现有单词配对/拼写游戏 | 文字奇境（本方案） |
|---|---|---|
| 核心玩法 | 词↔释义双项映射 / 拼写 | **猜词推理 / 接龙网络 / 填字网格 / 成语四字组合** |
| 科目覆盖 | 英语为主，语文有限 | **中文专项（成语/接龙/填字）+ 英文猜词** |

| 数据服务 | `WordMatchGameService` | **新增 `TextGameService`（校验/拆字/题库） + 复用 `WordMatchGameService.BuildItems`** |

| 输入交互 | 按钮/点击为主 | **中文 IME 输入（接龙/猜词/填字）+ 点击** |

## 8. 技术要点与风险

1. **接龙"词是否存在"校验**：只用学习词库会 90% 报错（学习词库通常只几百～几千条）——**必须配白名单词典**（2–5 万条常用词），否则玩家体验极差。白名单启动时 `File.ReadAllLines` 进 `HashSet<string>`，O(1) 判定。
2. **同音判定**：放宽"接龙允许同音字"需要 `汉字→拼音` 表；内置 7000 常用字 JSON（约 50–100KB）即可覆盖日常；多音字取首个拼音即可（不必过于严格）。
3. **填字网格生成**：在线生成合法 Crossword 是计算密集问题——**首版只做 20 盘人工审核的内置题库**，体验稳定；后续再做"离线生成器"把生成的 JSON 入库。
4. **成语消消乐字序判定**：
   - 简单档：集合匹配（4 字对就消），用 `sort` 对比；
   - 普通档：顺序匹配，玩家按"点击顺序"作为字序；
   - 要给玩家"取消最后一张"按钮，避免误点顺序。
5. **Hangman 线索解锁顺序**：要保证线索从弱→强（字数→词性→拼音→释义→首字），越弱的线索越便宜（消耗少/不消耗）；不能反过来剧透。
6. **IME 组合过程事件**：中文输入法在组合期间会持续触发 `input`，提交判定必须等 `keydown Enter` 或 `compositionend`。
7. **成语白名单词库互补**：玩家可能的成语远超用户录入的学习词条 → 即使未命中 `LearningItem`，仍允许消除，只在消除后展示"可加入学习库？"提示（后续可一键导入）。
8. **动画 fill 覆盖（老坑）**：消除/答对动画注意 fill 终态。
9. **中文 JSON 编码**：UTF-8（接龙/成语/填字全中文）。
10. **`?mock=1`**：内置示例词库 + 成语 + 1 盘填字 JSON + 拼音表样例。

## 11. 已采纳优化

### 文字游戏专有
1. **成语消消乐消除后展示释义**：每消一条，不仅动画，还在底部展开该成语的"释义 + 典故小卡片"——边玩边学，避免纯"字卡匹配"变成无意义的图形搜索。
2. **接龙 AI 对手**：单人模式下人机对答，解决"一个人接不长就无聊"的冷启动问题；AI 难度可按词频/词长调节。
3. **填字"逐格实时校验开关"**：默认开启（儿童友好，不怕错），熟练玩家可关掉追求整盘一次对的挑战感。
4. **Hangman"首字免费提示"**：如果玩家 10s 没输入，自动免费展示首字（不扣 ★），降低卡住的挫败感。
5. **白名单词"可导入学习库"**：玩家在接龙/成语模式答对的词若不在用户学习库，弹窗提示"一键加入学习"，长期越玩词库越富。
6. **成语消消乐"干扰字降级"**：困难档加干扰字，但 3 次错选后，干扰字自动淡出（视觉弱化），避免死局。
7. **接龙超时奖励 AI 一词**：玩家 15s 没输入 → AI 自动接一词并高亮"你也可以试试这个词"——既保游戏节奏，又教新词。

### 共用
8. **前端公共件复用**：bridge/toast/confetti/theme/`{type,payload}` 协议继续抽 Shared。
9. **通用成绩上报模板**：`{id, correct, word, mode, hits, timeMs}` 统一结构，词库词和白名单词都能装下。
