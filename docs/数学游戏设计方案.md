# 数学游戏 设计方案

> 项目：LearningAssistant（WinForms + WebView2）
> 目标：新增一款 **"数学大冒险"（Math Adventure）** 游戏集合：包含「速算风暴」「数字消消乐」「算式配对」「数学 24 点」四种子模式，覆盖口算、逻辑、运算顺序与组合分解能力；并复用内容编辑器中的「数学」科目词条做题干/错题闭环。
> 本文档只做方案设计，不涉及代码实现。

---

## 1. 背景与目标

学习助手已有「英语/语文」的丰富配对游戏，但「数学」科目长期缺少专属玩法；用户也反馈"数学练习只有卡片/错题，不够有趣"。

本方案设计 **"数学大冒险"**：
- 复用 WebView2 静态页技术路径 + `WebView2GameFormBase` 宿主基类；
- 四款子模式覆盖不同数学能力：
  1. **速算风暴**：限时口算（加减乘除），训练反应速度；
  2. **数字消消乐**：两两数字之和/差/积等于目标值即消除，训练组合数感；
  3. **算式配对**：「算式 ↔ 结果」配对，训练运算准确性；
  4. **24 点**：4 个数用 + − × ÷ 凑 24，训练组合分解与逻辑；
- 与科目系统联动：
  - 顶部可选「数学」科目与子类别（如「口算」「乘法表」「应用题算式」），从词库抽题；
  - 答错写入数学科目的错题本，形成复习闭环；
- 纯静态网页（HTML + CSS + JS），无第三方框架。

## 2. 玩法设计

### 2.1 主模式选择页
启动进入「数学大冒险大厅」，四张卡片对应四款子模式；顶栏含「数学子类别」下拉（如「10 以内加减」「乘法口诀」「两位数加减」）。

| # | 子模式 | 图标 | 核心能力 | 数据来源 |
|---|---|---|---|---|
| 1 | 速算风暴 | ⚡ | 口算速度 + 准确性 | 词库抽题 或 按参数动态生成 |
| 2 | 数字消消乐 | 🔢 | 组合数感（凑目标值） | 动态生成数字盘面 |
| 3 | 算式配对 | 🧩 | 算式 ↔ 结果识别 | 词库抽题 + 动态生成干扰项 |
| 4 | 24 点 | 🎲 | 四则运算组合分解 | 动态生成合法 4 数 |

---

### 2.2 子模式一：速算风暴（Math Sprint）
**限时连续做口算题，答对连击，答错不中断但扣分。**

- **出题形式**：中央横式算式，如 `27 + 15 = ?`；底部 4 个选项按钮（1 对 3 错，干扰项为"差一位/进位错/乘错"的常见错误）。
- **限时**：
  - **总时长**：60s / 90s / 120s 三档；
  - **单题超时**：每题 5–8s（按难度），超时记失误并自动跳下一题。
- **难度**：
  - **简单**：10 以内加减、数字 1–20，4 选项，单题 8s；
  - **普通**：100 以内加减 / 九九乘法，4 选项，单题 6s；
  - **困难**：三位数加减 / 两位数乘法 / 简单除法，6 选项，单题 5s。
- **词库联动**：若顶部子类别下有可用词条（`MainContent` 为算式，`Meaning.Content` 为答案），优先用**错题优先**抽题；不足时由前端动态生成算式补齐。
- **反馈**：
  - 正确：绿圈 + 连击系数加分 + 飘字 `+20 × 1.5`；
  - 错误：红闪 + 显示正确答案 + 连击清零，该算式记为错题；
  - 超时：黄灰提示 + 记失误。

---

### 2.3 子模式二：数字消消乐（Number Match）
**盘面展示若干数字卡片，两张卡片按规则运算后等于目标值即可消除。**

- **盘面**：6×4 = 24 张卡（12 对可消），每张卡是一个正整数（或简单小数/分数，困难档）。
- **目标**：顶部给出"目标数 T"，玩家点击两张卡：
  - 若 `a + b == T`（默认加法规则） → 消除；
  - 或顶部可切换规则：`a − b`、`a × b`、`|a − b|`（每局固定一种规则）。
- **注意**：不是"两两配对同数字"，而是"两两组合凑 T"——盘面必须有解，可多次组合同一数字卡用不同 T 消（但每张卡只能被消一次）。
- **难度**：
  - **简单**：规则=加法，T=20，数字 1–19，无干扰项；
  - **普通**：规则=和/差/积随机选一种，T=50，数字 1–49；
  - **困难**：规则=混合（玩家要同时判断哪种运算可凑 T），加入简单分数/小数。
- **死局处理**：每消一步后检查"剩余卡中是否还有满足规则的两张"，否则自动洗牌（重排剩余卡的位置但不改数值）。
- **词库联动**：此模式以动态生成为主（锻炼纯粹数感），不抽词库词条；结算时正确率作为数学科目的通用统计。

---

### 2.4 子模式三：算式配对（Formula Match）
**「算式卡」与「结果卡」两两配对（类似单词消消乐，只是对象换成算式）。**

- **盘面**：N 对（默认 N=10，5×4=20 张卡），一半是算式（如 `8 × 7`），一半是结果（如 `56`），全部正面朝上。
- **规则**：玩家依次点击两张卡；若一张是算式、另一张是它的正确结果 → 配对成功消除。
- **词库联动**：从数学科目子类别抽词条，`MainContent` 做算式卡，`Meaning.Content` 做结果卡；不足时动态生成；错题优先。
- **干扰策略**：可加入"近似结果干扰"（如 `8×7=56` 的干扰结果 = `54` `58` `63`），强化区分度。
- **难度**：
  - **简单**：N=8，同屏较少，无干扰近似；
  - **普通**：N=10，近似干扰；
  - **困难**：N=12，6×4，加入带括号的两步运算（如 `(3+5)×2`）。
- **反馈**：同单词消消乐——消除动画 + 连击；不配对抖动。

---

### 2.5 子模式四：24 点（Make 24）
**给出 4 个 1–13 的整数，用 + − × ÷ 与括号组合运算，使结果恰好为 24。**

- **出题**：4 张数字卡（1–13，允许重复），保证**至少存在一组合法解**（用回溯验证后再下发）。
- **操作**：底部数字按钮按顺序点选，配合运算符按钮 `+ − × ÷ ( )` 组成算式，点「提交」判定。
- **规则**：每个数字必须且只能用一次；允许除法整除/非整除（非整除按浮点精确 == 24 判）。
- **限时**：每题 60s，超时自动跳过并展示参考答案。
- **难度**：
  - **简单**：4 个数中含多个相同数 / 经典组合（如 3 8 3 8 = 24），每题 90s，可点"提示"；
  - **普通**：标准 4 数随机合法解，每题 60s；
  - **困难**：5 个数凑 30 / 60（可扩展），每题 90s，无提示。
- **反馈**：
  - 正确：🎉 彩带 + 跳题；
  - 错误：提示「结果 = X，不是 24」，可继续编辑；
  - 提示：分步显示"第一步 = a op b"。
- **词库联动**：以动态生成为主（每局后端/前端回溯生成合法 4 数），正确率作为数学统计。
- **可选**：每题记录玩家输入的算式，作为数学科目的答题痕迹。

---

### 2.6 通用计分与结算
- **计分**：
  - 速算风暴：`答对基础分 × 连击系数`，连击 1.0→1.2→1.5→2.0；
  - 数字消消乐：每消一对基础分，剩余越少 + 用时越短加分；
  - 算式配对：每对基础分 × 连击；
  - 24 点：每题基础分，用时越短 + 不提示加成。
- **星级**：按得分 ★★★ / ★★ / ★ / 加油。
- **结算页**：得分、正确数/总题、正确率、失误数、最高连击、用时、24 点=通过题数。
- **再来一局** / **回大厅** / **换一组**（重新抽题或重新生成数字）。

## 3. 数据接入方案

### 3.1 词库联动（数学科目）
- **取词**：复用 `WordMatchGameService.BuildItems(context, N, WordSelection.WrongFirst)`，限制 `context.Subject = Math`。
- **数据适配**：`LearningItem.MainContent` → 算式，`LearningItem.Meaning.Content` → 结果。
- **不足补齐**：词库词条不足时，由**前端动态生成**合法算式 + 干扰结果（后端也提供 `MathGameService.GenerateArithmetic(count, difficulty)` 辅助函数，详见 3.3）。
- **成绩回写**：
  - 速算风暴 / 算式配对 → 答错的词条写数学错题本（复用 `ApplyResults` 语义，id 用数学词条 id；动态生成的题目生成**临时 id**，写错题时附带算式文本但不关联 `LearningItem`）；
  - 数字消消乐 / 24 点 → 统计正确率即可，不写具体错题。

### 3.2 BuildData 返回结构
`BuildData` 返回四款模式所需数据 + 参数：
```jsonc
{
  "modes": [/* 四款元信息 */],
  "libraryItems": [/* 从数学词库抽的 N 条：{id, formula, answer, category}，可为空表示全动态生成 */],
  "difficulty": "easy|normal|hard",
  "arithmeticParams": { /* 速算/配对 动态生成参数 */
    "addRange": [1, 100],
    "mulRange": [2, 9],
    "includeDivision": true
  }
}
```

### 3.3 后端新增服务（轻量）
新增 `MathGameService`（只负责纯计算的"题目工厂 + 合法性校验 + 错题回写包装"，不含 UI）：

```csharp
public class MathGameService
{
    // 动态生成 N 道口算题
    List<ArithmeticItemDto> GenerateArithmetic(int count, Difficulty diff, bool includeMulDiv);

    // 生成 24 点：返回一组"保证有解"的 4 个数，以及一个参考解
    Make24ItemDto GenerateMake24(int count = 1);

    // 验证玩家 24 点算式（防注入：用表达式解析器或手写 AST，禁 eval）
    MathEvalResult EvaluateFormula(string formula, int[] expectedNumbers);

    // 回写数学通用结果（答错的写入错题本 + 复习状态）
    void ApplyMathResults(string userId, LearningContext ctx, IReadOnlyList<MathResult> results);
}
```

> **表达式安全**：EvaluateFormula **禁止 `eval`**，用手写的分词 + 递归下降或 `System.Data.Compute`（限定输入为数字 + 运算符 + 括号），避免代码注入。

### 3.4 宿主窗体
新增 `MathGameForm`：
- 继承 `WebView2GameFormBase`；
- `FormTitle` → "🧮 数学大冒险"；
- `HtmlFileRelativePath` → `Resources/MathGame/index.html`；
- 顶栏：保留「科目=数学锁定」+「子类别」下拉 + 「难度」下拉；
- `BuildData` → 调 `_contentLoaderService` + `MathGameService` 组合返回。

## 4. 前端页面设计（静态 HTML）

### 4.1 文件组织
```
Resources/MathGame/
  index.html            # 大厅 + 四款模式容器
  style.css             # 四款模式样式、动效、主题
  game.js               # 路由、通用计分结算、通信、通用工具
  modes/
    sprint.js           # 速算风暴：出题、选项、倒计时、判定
    numberMatch.js      # 数字消消乐：盘面生成、可消判定、死局洗牌
    formulaMatch.js     # 算式配对：洗牌、配对、动效（可复用消消乐逻辑）
    make24.js           # 24 点：表达式输入、校验、提示、解法回溯
  utils/
    formulaEval.js      # 纯函数：表达式解析 + 求值（安全，不用 eval）
    make24Solver.js     # 纯函数：24 点所有解枚举（用于题目校验 + 提示）
```
- 纯原生 JS，`?mock=1` 内置示例数据。

### 4.2 页面结构
- 大厅层：四张模式卡；
- 游戏层：
  - 速算风暴：顶部计时 → 算式大字 → 4/6 选项按钮；
  - 数字消消乐：顶部目标 T + 规则说明 → 格盘；
  - 算式配对：格盘 5×4；
  - 24 点：4 张数字卡 → 运算符面板 + 表达式输入框 → 提交/提示/跳过。
- 结算层：通用弹窗，展示指标 + 星级。

### 4.3 24 点表达式输入
两种输入方式（同屏并存，玩家任选）：
1. **按钮点击**：4 张数字卡 + `+ − × ÷ ( )` + `⌫` + `=` → 拼算式；
2. **键盘输入**（聚焦输入框）：直接敲 `3*(8-3+8/...` → 按 Enter 提交。
输入框实时用 `formulaEval.js` 做**语法高亮**（合法数字=蓝，运算符=橙，括号错=红），降低挫败。

### 4.4 动效
- 消除类：同消消乐的缩放 + 粒子；
- 速算：正确时选项爆炸 + 下一题淡入；
- 24 点通过：彩纸（复用 Shared `confetti()`）。

## 8. 技术要点与风险

1. **表达式安全（重点）**：绝对禁止 `eval()`；自写解析器（数字 + `+-×÷()` + 左结合 + 括号优先级）或用 `DataTable.Compute`（限定输入字符集）；前端和宿主双重校验。
2. **24 点题目生成**：随机 4 数后必须用求解器验证"至少 1 个解"，无解就丢弃重抽，避免卡关；求解器枚举所有 `(a op b) op (c op d)` 与 `((a op b) op c) op d` 形式，复杂度可接受（4!×4³×卡特兰数≈10 万级别，秒出）。
3. **除不尽判定**：`8 ÷ 3 × (3 + 3 + ...)` 场景用浮点容差（`Math.abs(result - 24) < 1e-6`），避免 `23.999999` 误判错误。
4. **速算干扰项**：错误选项必须是**常见错误结果**（如进位忘加、乘法错位），而不是纯随机数——更真实地暴露薄弱点。
5. **数字消消乐可解性**：开局 / 每消一步后做可消检查，无解自动洗牌（重排位置不改数值）或给"提示"。
6. **动态生成题的错题回写**：生成题无 `LearningItem.Id`，错题本用临时 id（如 `gen:md5(formula)`） + 文本字段存算式与答案，后续可在错题本中直接标记复习。
7. **动画 fill 覆盖（老坑）**：消除/答对动效用类切换，注意 fill 不覆盖终态。
8. **主题一致**：`body[data-theme]`；数字卡片延续多彩渐变方案（与消消乐一致）。
9. **词库不足**：数学词库初期可能为空，前端/C# 双重回退到 100% 动态生成，不提示"无可玩数据"。
10. **`?mock=1`**：内置速算/配对题库样例 + 24 点合法样例。

## 11. 已采纳优化

### 数学游戏专有
1. **词库 + 生成双轨**：数学词库初期内容少，`BuildData` 词库优先 + 动态补齐，保证"随时可玩不空盘"。
2. **24 点求解器复用**：既用于**题目合法性校验**（避免下发无解），又用于**提示功能**（分步展示解法），一份代码两份价值。
3. **速算干扰项 = 常见错误**：错误选项不是随机数，而是"算错一步"的结果（如 `27+38` 的错误干扰 = `55`（忘进位）/ `66`（重复加）/ `64`（多加 1）），直击薄弱点。
4. **动态生成题写错题本**：用 `gen:md5(formula)` 做临时 id + 文本字段，保证错题闭环不被"无 LearningItem"阻断。
5. **数字消消乐"规则每局固定"**：同一局内只允许加法或只允许乘法，不混规则——避免儿童用户混淆"到底按什么凑目标"。
6. **24 点浮点容差**：`1e-6` 浮点判定，不因为除不尽的中间步骤误判。

### 共用
7. **前端公共件复用**：bridge/toast/confetti/theme/协议继续抽 Shared。
8. **通用成绩上报模板**：`{id, correct, formula, userAnswer, timeMs}` 统一结构，词库题和生成题都能装下。
