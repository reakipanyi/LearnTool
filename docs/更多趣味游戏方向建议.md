# 更多趣味游戏方向与建议（完整版）

> 项目：LearningAssistant（WinForms + WebView2）
> 目标：在「专注力训练 / 数学 / 文字」三大游戏集之外，再梳理 **15 款可落地的趣味游戏方向**，覆盖知识积累、专注力锻炼、思维激发三大能力维度；每款均结合现有 WebView2 + 科目系统 + 词库/错题闭环能力给出适配建议。
> 版本：v2.0（补充 MVP 定义、三维矩阵、成就接入、数据闭环、季度路线图、技术速查、用户分层、已有游戏进阶方案）

## 一、知识积累类（紧密对接科目词库 / 错题本）

### 1. 🧠 知识卡片翻牌问答（Quiz Flashcard）
- **玩法**：卡片正面是问题（释义 / 作者 / 公式 / 年代），点击翻面看答案，自评为「记得 / 模糊 / 不会」；系统根据自评自动调度下次出现（类 Anki SM-2）。
- **适用科目**：全科目（英语释义、语文作者朝代、历史年代、地理省会、数理公式）。
- **训练价值**：把现有「学习卡片」游戏化，加入翻牌手感 + 进度条 + 连续「记得」解锁成就，让复习更有正反馈。
- **复用点**：完全复用 `WordMatchGameService.BuildItems` + 现有卡片 UI / 动画。
- **MVP 范围**：仅做「翻面 + 三按钮自评 + 进度条」；SM-2 调度可第 2 版接。

### 2. 🗺️ 知识地图连线（Concept Map Link）
- **玩法**：左侧一组「概念」，右侧一组「描述 / 定义 / 实例」，用画线连连（类似连连看，但不是消除而是匹配关系网）。如：作者 → 作品 / 器官 → 功能 / 定理 → 适用条件。
- **训练价值**：把「单向孤立记忆」升级为「关联记忆」，帮助形成知识网络；比简单配对更强调多对一 / 一对多的结构感。
- **复用点**：连线渲染可借鉴连连看的路径高亮；配对判定复用消消乐局内 key。
- **MVP 范围**：先做一对一匹配（不做一对多）；连线用 SVG 折线 + 简单吸附。

### 3. 🎭 场景对话完形填空（Cloze Dialogue）
- **玩法**：给出一段英语短对话 / 语文段落 / 古诗词上下文，挖空 5–8 处关键词（全部来自词库词条），四选一滴入或直接键盘输入填空。
- **适用科目**：英语情景对话、古文诗词、语文课文、完型填空真题片段。
- **训练价值**：在真实语境中记词，比孤立背词记得更牢；答错词自动回写错题本。
- **复用点**：挖空词从 `WordMatchGameService.BuildItems(WrongFirst)` 优先选薄弱词。
- **MVP 范围**：四选一滴入（不做键盘输入）；内置 10 段中英文模板段落。

### 4. 🏷️ 多标签分类擂台（Tag Sort Arena）
- **玩法**：顶部出现 3–6 个「分类桶」（如「动物 / 植物 / 矿物」「动词 / 名词 / 形容词」「唐 / 宋 / 元 / 明 / 清」），下方词卡随机掉落或滚动出现，玩家拖入正确桶。限时 60s，分类正确越多得分越高。
- **训练价值**：训练**分类思维**与**概念辨析**，特别适合生物分类、语法词性、历史分期等易混概念。
- **复用点**：词卡复用消消乐多彩渐变卡片风格；拖拽用 HTML5 Drag & Drop + 移动端触摸适配。
- **MVP 范围**：3 个分类桶 + 点选式（非拖拽，先点桶再点卡），兼容触屏。

### 5. 📚 百科知识闯关（Trivia Quest）
- **玩法**：类似《开心辞典》闯关结构，10 关层层递进，每关 1 题（单选 / 判断），答对过关上楼梯，答不对退一级；配 3 条「求助锦囊」= 50/50 去两个错选项 / 跳题 / AI 提示思路。
- **适用科目**：综合百科、历史、地理、科学常识；也可抽成语典故、英语文化背景题。
- **训练价值**：把零散常识做成「爬楼梯」叙事，自带目标感，激发通关欲与持续闯关的动机。
- **复用点**：错题意入错题本；AI 提示可调用 `IAiQuestionService`（Deepseek / Doubao）。
- **MVP 范围**：内置 50 题百科题库 JSON（含 4 选项 + 答案 + 解析）；不做 AI 提示。

## 二、专注力锻炼类（纯能力 + 轻知识结合）

### 6. 🎯 双重任务挑战（Dual N-Back Lite）
- **玩法**：屏幕上下两行，同时呈现两个信息流——
  - 上排：几何图形序列，判断「与 n 步前是否相同」；
  - 下排：字母 / 数字 / 颜色序列，判断「与 n 步前是否相同」。
  n 从 1 起步，答对 n 递增（最多到 4），答错 n 回退。
- **科学依据**：经典 N-Back 训练与流体智力正相关研究；Lite 版降低挫败，适合儿童/新手。
- **训练价值**：专注力 + 工作记忆双练，比舒尔特方格更硬核，能力天花板更高。
- **复用点**：与专注力训练营共用大厅 / 难度 / 计分框架。
- **MVP 范围**：只做**单通道 N-Back**（不是双通道），图形或字母单通道，n 最大 3。

### 7. 👂 听声辨位 / 听写大师（Audio Focus）
- **玩法（A 版·听声辨位）**：Web Audio 生成 8 方位（上/下/左/右/四斜角）的声源，玩家点击对应方向箭头；方位随难度加入时间压缩与噪声干扰。
- **玩法（B 版·听写大师）**：宿主 TTS（`SpeechSynthesizer`）播报英语词 / 成语 / 数字串（3 位起，逐步加到 7–9 位），播报后屏幕清空，玩家键盘输入。
- **训练价值**：补足现有游戏全部是「视觉型」的盲区，训练**听觉专注通道** + 语音短时记忆。
- **复用点**：直接调用宿主 `SpeakHost()` 朗读接口（已在 `WebView2GameFormBase` 内）。
- **MVP 范围**：只做 B 版听写大师（数字串听写），Web Audio 后补。

### 8. 🧘 正念呼吸引导 + 保持点击节拍（Breath Beats）
- **玩法**：界面中央呼吸圆环按节律动画：4s 吸气（扩张）/ 4s 屏息（停留）/ 6s 呼气（收缩）；玩家在每段的特定节奏点（如吸气 4 拍、呼气 6 拍）点击屏幕或按空格键，命中节奏越精准得分越高。
- **训练价值**：5 分钟短局，适合番茄钟休息阶段做「注意力复位」；对 ADHD 倾向儿童有临床级辅助效果。
- **复用点**：可与 PomodoroTimer 番茄钟休息阶段自动联动触发。
- **MVP 范围**：纯呼吸引导 + 圆环动画（不计节拍得分），作为番茄钟休息阶段的「强制休息」入口。

### 9. 🔢 数字广度复述（Digit Span）
- **玩法**：屏幕依次闪现 3–9 位数字串（1 位 / 秒），闪完消失，玩家键盘正向复述；正向通过进入反向复述（如 3871 → 玩家输入 1783）。
- **科学依据**：韦氏智力量表（WISC/WAIS）经典子测验，直接测量**短时记忆广度**。
- **知识联动扩展**：数字 → 成语 4 字 → 诗句 7 字/词牌长短句，与语文词库联动。
- **训练价值**：是专注力训练的「基础体能测试」，也常作为神经可塑性训练的基线指标。
- **MVP 范围**：正向数字复述，3–7 位；反向复述放到 V2。

### 10. 🎨 镜像绘画 / 对称涂色（Mirror Draw）
- **玩法**：画布左右两半，左半给定简单图形 / 汉字部首 / 几何线条，玩家用鼠标或触屏在右半同步镜像绘制；程序按重合度、对称性、闭合度三围打分。
- **变体**：上下对称 / 四象限对称。
- **训练价值**：训练左右脑协同 + 空间注意力 + 精细动作控制，完全不依赖词库，即开即练。
- **MVP 范围**：只做左右镜像 + 简单 6–10 组几何模板；打分算法只算重合度（不判对称性 / 闭合度）。

## 三、思维激发类（逻辑 / 创新 / 发散）

### 11. 🧩 拉管子 / 接管道（Pipe Connect）
- **玩法**：给一张格盘 + 起点（水源 ⭕）+ 终点（花朵 🌸 / 气球 🎈），格盘上放置直管 / L 管 / T 管，玩家点击旋转，把水从起点连通到终点。限定时间或最少步数获得三星。
- **变体**：换成「电线亮灯」「水渠灌溉」「地铁线路连通」。
- **训练价值**：空间推理 + 假设验证思维（转一下不对就回退，再换方案）。
- **复用点**：格盘复用连连看 grid 布局；旋转动效用 CSS transform。
- **MVP 范围**：4×4 盘 + 只有直管和 L 管（无 T 管），5 关内置。

### 12. 🤔 数字逻辑推理（Number Series & Mini Sudoku）
- **模式 A·数列推理**：给出 `2, 4, 8, 16, ?` 等差 / 等比 / 斐波那契 / 奇偶分组 / 隔位规律，四选一或直接输入答案。
- **模式 B·迷你数独 4×4 / 6×6**：标准数独规则（每行/列/宫不重复）缩小版，适合 5–10 分钟一局；内置 30–50 盘 JSON 题库分难度下发。
- **训练价值**：归纳推理（数列）+ 约束满足（数独），是数理逻辑的基础功。
- **复用点**：题库下发机制同迷你填字；校验算法自写 O(n)。
- **MVP 范围**：只做迷你数独 4×4，内置 20 盘 JSON 题库 + 简单回溯校验。

### 13. 💡 发散思维雪球（Alternative Uses）
- **玩法**：给出一个日常物品（如「砖头」「回形针」「纸杯」「报纸」），限时 90s 内尽可能多地输入「不同用途」；系统按**三围打分**：
  - 流畅性（数量）；
  - 变通性（覆盖多少不同类别，如「砸/垫/压/建材/工具/艺术」）；
  - 独创性（与常见回答差异度）。
- **AI 辅助打分**：调用 `IAiQuestionService`（Doubao / Deepseek）把用途归类到 6–10 个通用类别，并给出创意点评；避免纯人工打分的主观。
- **训练价值**：经典「吉尔福特发散思维」训练法，打破功能固着，激发创造力。
- **MVP 范围**：只算流畅性（纯数量）；不接 AI 分类，物品列 10 个内置对象。

### 14. 🔀 故事接龙 / 词语联想链（Story Chain）
- **玩法（单人版）**：随机给出 3 个异质词（如「雨伞 / 熊猫 / 火箭」），2 分钟内写一段把三个词全部用上的 200 字内微型故事，AI 点评「情节完整度 + 创意评分 + 改写建议」。
- **玩法（人机对战版）**：AI 写第一句，玩家写第二句，交替 5 回合，最后 AI 总结故事线 + 打分。
- **训练价值**：想象力 + 叙事逻辑 + 快速写作练习，最能体现「AI 赋能的差异化体验」。
- **复用点**：AI 接口直接走 `IAIHubService` / `MentorAIPanel` 已有的调用链。
- **MVP 范围**：只做单人版 + 内置 50 组三异质词；AI 点评改为本地"三词全部出现即通过"的规则判定。

### 15. 🎯 Raven 渐进矩阵迷你版（Raven-like Matrices）
- **玩法**：3×3 图形矩阵，右下角缺一格，从 6–8 候选中选符合规律的一个填入；规律维度包括「行方向旋转、列方向叠加、颜色递进、数量变化、线条消长」等。
- **科学依据**：最经典的**流体智力 / 抽象推理**测验（瑞文标准推理测验），不依赖语言和文化，跨年龄段通用。
- **落地方式**：首版内置 20–30 题分难度的题库 JSON（像填字游戏那样），后续可扩展到 100+。
- **训练价值**：被广泛用于「训练后推理能力迁移」的学术研究，是思维激发类的黄金标杆玩法。
- **MVP 范围**：内置 15 题 3×3 纯 SVG 绘制的瑞文风格题库，分简单 / 普通两档。

## 五、学习数据闭环：每类游戏如何写回复习系统

游戏不止是"好玩"，必须写回学习数据形成**复习闭环**。以下是 15 款游戏的数据回写策略：

| 游戏 | 写回 LearningItem.Review() | 写错题本 WrongAnswerService | 写通用统计 StudyStatsManager | 写 FSRS/SM2 调度 |
|---|---|---|---|---|
| 🧠 翻牌问答 | ✅「记得」= Correct=true；「模糊/不会」= false | ✅ 「不会」直接入错题 | ✅ 自评分布统计 | ✅ 自评直接映射 SM-2 难度因子 |
| 🗺️ 知识连线 | ✅ 配对成功 = true；三次未配对成功 = false | ✅ 多次连线失败入错题 | ✅ 正确率 | ⭕ 可接（按配对次数） |
| 🎭 完形填空 | ✅ 填对 = true；填错 = false | ✅ 填错空的词入错题 | ✅ 语境正确率 | ⭕ 可接 |
| 🏷️ 分类擂台 | ✅ 分类正确的所有词卡 = true；错桶的词 = false | ✅ 分错的词入错题 | ✅ 分类正确率 | ⭕ 可接 |
| 📚 百科闯关 | ✅ 答对 = true；答错 = false | ✅ 答错入错题（含解析） | ✅ 闯关楼层分布 | ❌ 不需要（百科题非词库） |
| 🎯 N-Back Lite | ❌（纯能力） | ❌ | ✅ n 水平、命中率 | ❌ |
| 👂 听写大师 | ✅ 听写正确的词库词 = true；错的 = false | ✅ 听写错词入错题 | ✅ 数字广度位数、听写准确率 | ⭕ 可接（听写版 SM-2） |
| 🧘 正念呼吸 | ❌ | ❌ | ✅ 完成次数、总时长 | ❌ |
| 🔢 数字广度 | ❌ | ❌ | ✅ 正向/反向广度位数 | ❌ |
| 🎨 镜像绘画 | ❌ | ❌ | ✅ 重合度得分、完成数 | ❌ |

## 七、技术选型速查表（每款游戏的关键难点 + 解决方案）

| 游戏 | 关键技术难点 | 推荐解决方案 | 避坑提示 |
|---|---|---|---|
| 🧠 翻牌问答 | SM-2 调度算法参数 | 直接复用项目已实现的 `SM2Algorithm.cs` | 不要自己重写调度；首版可以不用 SM-2，只用简单线性调度 |
| 🗺️ 知识连线 | SVG 折线吸附到卡片锚点 | `<svg><polyline>` 动态计算卡片左右边界锚点 | 移动端 SVG click 区域要加大 `pointer-events: all` |
| 🎭 完形填空 | 段落挖空不破坏语法/语境 | 先拿 5–10 篇人工审核模板，词库词仅在模板空位处替换 | 不要 AI/算法自动挖空——容易把冠词/虚词挖出来变成错题 |
| 🏷️ 分类擂台 | 触屏拖拽体验 | pointerdown/move/up 统一封装，不用 HTML5 Drag API（移动端不友好） | 掉落边界判定用矩形碰撞 `getBoundingClientRect()` |
| 📚 百科闯关 | 楼梯层视觉叙事 | CSS 阶梯 + 角色图标（🐢→🐰→🦊→🦁）上下移动 | 每关切换用 transform translateY，不用 display 切换 |
| 🎯 N-Back Lite | 双通道时间同步精度 | 单个 `requestAnimationFrame` 驱动两条信息流 | 不准用两个 `setInterval`，否则累积误差导致不同步 |
| 👂 听写大师 | TTS 朗读速度随难度变化 | 宿主 `SpeechSynthesizer.Rate = -2..2` 直接调 | 朗读后要清屏——不要在播报时提前显示答案 |
| 🧘 正念呼吸 | 呼吸圆环无卡顿动画 | `@keyframes` + `animation-duration` 精确 4/4/6s | 用 CSS 动画不要用 JS setInterval 驱动尺寸变化 |
| 🔢 数字广度 | 闪现节奏精确控制 | `setTimeout` 链，1 位 = 1000ms ± 10ms | 闪现时禁用输入框聚焦，避免玩家边看边打 |
| 🎨 镜像绘画 | 画布绘制 + 实时镜像 | `<canvas>`，左边 `ctx.getImageData` → 水平翻转后画到右半边 | 重合度比对走 **降采样 8×8 像素哈希**（PHash），别逐像素比 |
| 🧩 接管道 | 连通性判定 | 每旋转一块后做 BFS：从起点四向扩展，能否到达终点 | T 管的三个出口方向数组要仔细枚举（最容易出 bug） |
| 🤔 数列+数独 | 数独校验 & 生成 | 校验 O(n²) 行列宫；生成走"挖洞法"（从满盘随机挖 n 个，保持唯一解） | 4×4 唯一解校验很快，6×6 注意超时（限制挖洞次数） |
| 💡 发散思维 | AI 归类打分成本 | 一局只调用 AI 一次（90s 结束时批量归类） | 不要每个用途都调 AI，成本会爆；首版直接按纯数量 |
| 🔀 故事接龙 | AI 对话上下文长度 | 每 3 句做一次压缩摘要，保持 prompt < 2k tokens | 把历史存在前端 `sessionStorage`，每回合拼上，别让宿主全量托管 |
| 🎯 Raven 矩阵 | 图形绘制（不用图片） | 全部用内联 SVG `<path>` / `<circle>` + CSS 变换 | 不要用 PNG/JPG 图片——题库打包后会变几十 MB |
