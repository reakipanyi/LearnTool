# 统一学习助手 - 使用说明

## 📖 概述

**统一学习助手**是一款基于 .NET Windows Forms 开发的综合性学习工具，旨在帮助用户高效学习汉字、英语单词、成语、诗词等内容。通过结合主动回忆、渐进式提示、联想学习等科学学习方法，帮助用户从被动浏览转变为主动思考，实现深度学习。

---

## 🚀 快速开始

### 系统要求
- Windows 10/11 操作系统
- .NET 6.0 或更高版本
- 建议分辨率：1280x720 及以上

### 启动方式
1. 双击运行 `LearningAssistant.exe`
2. 程序会自动初始化服务容器并加载数据
3. 首次启动可能需要进行数据迁移（从 JSON 到 SQLite）

### 主界面布局

主界面包含以下主要区域：

| 区域 | 功能 | 说明 |
|------|------|------|
| 👤 多玩家选择 | 切换不同用户 | 支持多用户学习进度独立管理 |
| 🔥 连续学习天数 | 显示学习连续天数 | 连续7天以上显示特殊标识 |
| 📊 学习统计摘要 | 显示学习进度概览 | 包含今日学习量、正确率等 |
| 🎮 功能按钮区 | 各功能入口 | 学习、PDF阅读、听写等 |

## 📚 核心功能

### 1. 学习模式

学习模式是核心功能，支持多种学习内容和方式：

#### 学习内容类型
- **识字**：汉字学习，包含拼音、释义、例句
- **英语单词**：英文单词学习，包含音标、释义、例句
- **英语短语**：常用短语和搭配
- **英语句子**：实用句型学习
- **成语**：成语学习，包含典故、用法
- **短语**：汉语短语学习
- **诗词**：古诗词学习
- **语文综合**：综合语文知识
- **英语综合**：综合英语知识

#### 学习模式设置
- **📚 学习模式**：完整学习流程，包含详细释义和AI解释
- **⚡ 快速模式**：快速浏览，适合复习
- **🔢 顺序学习**：按顺序学习列表内容
- **🎲 随机学习**：随机打乱学习顺序

#### 操作说明
| 快捷键 | 按钮 | 功能 |
|--------|------|------|
| `空格` | 🔊 发音 | 播放当前内容的语音朗读 |
| `回车` | ➡ 下一个 | 跳转到下一个学习项目 |
| `1` / `K` | ✅ 会了 | 标记当前项目已掌握 |
| `2` / `U` | ❌ 不会 | 标记当前项目需复习 |
| `Esc` | 🏠 返回 | 返回主界面 |

#### 学习界面功能
- **AI释义面板**：开启后自动获取AI生成的详细解释
- **自动朗读**：自动播放学习内容的发音
- **发音范围**：可选择朗读原文、释义或两者都读
- **笔记功能**：为当前学习内容添加个人笔记
- **收藏功能**：收藏重要内容以便复习

### 2. 渐进式提示系统 (💡 渐进提示)

渐进式提示系统帮助用户主动思考，避免直接查看答案：

**工作原理**：
1. 用户先尝试猜测答案
2. 如果不确定，可逐级获取提示（由弱到强）
3. 系统使用相似度算法判断答案正确性
4. 最终展示完整答案

**提示级别示例**：
- 第1级（最弱）："这个词有3个字"
- 第2级："第一个字是'学'"
- 第3级："可以组词：学习、学会"
- 第4级（最强）："想想在学校的事..."

**使用场景**：
- 遇到难词需要提示时
- 训练主动回忆能力
- 加深对知识点的理解

---

### 3. 联想学习系统 (🔗 联想学习)

联想学习系统帮助用户建立知识网络，增强记忆：

**五类联想**：
- 🔗 **同类词**：相同类别或领域的词汇
- 🔄 **反义词**：意义相反的词汇
- 📝 **相关词**：语义相关的词汇
- 📖 **例句**：包含该词的典型例句
- 🧠 **知识点**：相关的背景知识

**功能特点**：
- 可视化展示知识关联
- 主动发现知识点间的联系
- 关联记忆比孤立记忆更牢固

**使用场景**：
- 学习新词汇时建立关联
- 复习时扩展知识网络
- 加深对概念的理解

### 4. 主动回忆训练器 (🧠 主动回忆)

基于艾宾浩斯遗忘曲线的科学复习系统：

**核心功能**：
- ✏️ **主动回忆**：用户先写出答案再检查
- 📊 **即时反馈**：显示正确率和进步统计
- 🔄 **间隔复习**：科学安排复习时间间隔
- 📈 **学习曲线**：展示学习进度和记忆状态

**复习策略**：
| 记忆强度 | 复习间隔 |
|----------|----------|
| 新学习 | 1天后 |
| 较弱 | 3天后 |
| 中等 | 7天后 |
| 较强 | 14天后 |
| 牢固 | 30天后 |

**功能包括**：

- 🗑️ 删除不需要的内容

---

### 8. 百度网盘集成 (☁️ 百度网盘)

支持将学习数据同步到百度网盘：

**使用步骤**：
1. 在设置中配置百度网盘 Client ID 和 Client Secret
2. 点击"百度网盘"按钮进行授权
3. 授权成功后即可上传/下载学习数据

**注意事项**：
- 需要网络连接
- 首次使用需要授权登录
- 建议定期备份重要数据

### 9. 学习浏览器

用于访问在线学习资源和网页内容。

## ❓ 常见问题

### 1. 程序启动失败
**可能原因**：
- .NET 运行时未安装
- 数据目录权限不足
- 配置文件损坏

**解决方法**：
- 安装 .NET 6.0 Desktop Runtime
- 确保程序目录有读写权限
- 删除损坏的配置文件重新启动

### 2. 语音朗读不工作
**可能原因**：
- TTS服务未配置
- 网络连接问题（在线TTS）
- 音频设备问题

**解决方法**：
- 检查TTS设置
- 确保网络连接正常
- 检查音频设备

### 3. AI释义不显示
**可能原因**：
- AI服务未配置
- API密钥无效
- 网络连接问题

**解决方法**：
- 在设置中配置AI服务
- 检查API密钥是否正确
- 确保网络连接正常

### 4. 学习进度丢失
**可能原因**：
- 用户切换错误
- 数据库文件损坏
- 异常退出

**解决方法**：
- 确认选择正确的用户
- 从备份恢复数据库
- 正常退出程序
