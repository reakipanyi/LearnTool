## WorkBuddy 学习工作台功能概览

WorkBuddy 是腾讯出品的全场景 AI 办公智能体工作台，其核心理念是**"说出要求 → AI 规划执行 → 交付完整成果"**。用户可以通过自然语言对话，让 AI 从零搭建个性化的学习工作台。

---

### 一、工作台自定义搭建能力（核心特色）

用户只需用一句话描述需求，WorkBuddy 就能自动生成一个**单文件 HTML 工作台**，双击即可在浏览器打开使用，无需安装任何软件。例如：

> *"我是一个大专高数老师，请帮我搭建一个备课题库工作台"*

WorkBuddy 会提供多种方向选择（如教学管理台、备课题库台、学情分析台等），用户选定后即可生成成品。

---

### 二、典型学习工作台模块组成

#### 📝 **1. 题库/学习内容管理模块**
- 按章节/分类精确整理内容（支持多级分类）
- 每条内容可标注：章节、题型、难度（易/中/难）、掌握度（未练习/了解/熟悉/掌握）、自定义标签
- 支持搜索和筛选：按分类、难度、关键词快速查找
- 顶部统计卡片：总题目数、各难度分布统计

#### 📁 **2. 学习素材库模块**
- 支持多种素材类型：教案、课件、参考链接、学习视频、其他
- **关联本地文件**：填入本地文件路径，提供「复制路径」按钮快速打开
- 网页链接可直接点击跳转
- 按章节/主题归类，一键筛选某主题下的所有素材

#### 📅 **3. 学习计划/进度追踪模块**
- 按日期分组显示任务，自动标注"今天/逾期/周X"
- 支持优先级设置（P0紧急/P1重要/P2一般）和状态（未开始/进行中/已完成）
- **进度条横幅**：实时显示整体完成百分比
- 逾期任务自动飘红提醒
- "今日待办"区域：把今天和逾期任务置顶展示

### 三、WorkBuddy 五大核心能力（支撑学习场景）

| 模块 | 功能说明 | 学习场景应用 |
|---|---|---|
| **专家（Experts）** | 内置 29 个专业方向、100+ AI 专家，可自动分配协作 | 内容创作、数据分析、知识咨询等 |
| **技能（Skills）** | 技能市场含海量插件（PDF处理、Excel、PPT生成、网页抓取等） | 文档摘要、资料整理、格式转换 |
| **自动化（Automation）** | 定时任务（如"每天早上9点背单词"、"每周生成周报"） | 学习提醒、周期性复习、进度追踪 |
| **连接器（Connectors）** | 基于 MCP 协议连接腾讯文档、邮箱、飞书、钉钉等 | 同步学习笔记、邮件提醒、协作共享 |
| **远程控制（Claw）** | 手机微信小程序遥控电脑端执行任务 | 外出时发指令让电脑整理资料、生成报告 |

### 四、三种工作模式（按需切换）

| 模式 | 定位 | 适用学习场景 | 消耗积分 |
|---|---|---|---|
| **Ask 模式** | 只问不动，不修改文件 | 知识查询、翻译、答疑、头脑风暴 | 最低 |
| **Plan 模式** | 先出方案再执行，需确认 | 学习计划制定、项目大纲设计 | 中等 |
| **Craft 模式** | 立即执行，直接交付成品 | 读取PDF、批量处理文件、生成完整PPT/代码 | 最高 |

> **实战技巧**：复杂内容先用 **Plan** 确认方向，再切 **Craft** 生成成品，避免返工浪费积分。

### 五、数据安全与跨设备

- **本地存储**：所有数据存在浏览器 `localStorage` 中，关闭页面不丢失
- **导出/导入备份**：一键导出 JSON 备份文件，支持随时恢复
- **多模型支持**：可切换混元（Hy3）、DeepSeek、KIMI（长文本）、智谱等模型，或接入自定义 OpenAI/Anthropic API
- **腾讯生态打通**：无缝连接腾讯文档、腾讯会议、QQ邮箱、微信、企业微信、ima 知识库
