# PDF 双面板工作台方案（v5）

> 目标：让「高亮（摘录）」与「翻译」各自成为完整、可独立使用的模块，需要时再显式关联；同时把自动高亮按钮放回摘录面板一级可见。

## 1. 已确认的决策

| 项 | 决策 |
| --- | --- |
| 工作台位置 | 放在右侧栏「🤖 学习」页签内，不新增顶层页签 |
| 默认状态 | 只开「摘录」，翻译按需开启 |
| 联动 | 默认关闭，需要时手动打开 `🔗` |
| 列表组织 | 不按页分组；按 `PageIndex`、页面纵向位置排序 |
| 自动框 | 不折叠，仅在行内加 `自动` 标记 |
| 学习工具 | 底部 3 个入口：`✂ 跟读`、`🎧 音频`、`✨ AI` |
| 闪卡 / AI 总结 | 收进「✨ AI」菜单，后续再扩展 |
| P5 | 翻译面板弹出为独立工具窗口，后续再做 |

## 2. 界面结构

```text
学习页签
┌──────────────────────────────────────────┐
│ [✍️ 摘录 ✓] [🌐 翻译]        [🔗 联动]  │  ← 模块开关（一级可见）
├──────────────────────────────────────────┤
│  📑 摘录   自动高亮 🖍  导出 ⬇  …        │
│  ┌────────────────────────────────────┐  │
│  │ 自动 · 第 3 页 · 已译        [译]  │  │
│  │ 摘录正文……                          │  │
│  └────────────────────────────────────┘  │
│  …（按页排序，不分组）                    │
├══════════════════════════════════════════┤  ← 可拖动分隔条（双开时）
│  🌐 翻译    [📄 整页] [✍ 摘录]           │
│  原文 / 译文 双卡（窄宽自动上下堆叠）     │
├──────────────────────────────────────────┤
│  [✂ 跟读]   [🎧 音频]   [✨ AI]          │  ← 固定底部 3 入口
└──────────────────────────────────────────┘
```

### 三种布局状态

1. **仅摘录**（默认）：翻译模块收起，摘录占满。
2. **仅翻译**：摘录模块收起，翻译占满。
3. **双开**：上下分屏，摘录在上、翻译在下；分隔条可拖动。
   - 至少保留一个模块可见，关闭最后一个模块时给出提示。

## 3. 模块独立性与显式关联

### 3.1 独立

- 摘录面板：列表、自动高亮、导出、删除、编辑、批量清理，全部自行完成。
- 翻译面板：整页原文/译文、OCR、译至、术语表、重译、播放、跟读、加入学习，全部自行完成。
- 联动关闭时，选中摘录**不会**改写翻译面板内容。

### 3.2 显式关联

| 入口 | 行为 |
| --- | --- |
| `🔗 联动` 开关 | 开启后，选中摘录自动送入翻译面板「摘录」槽；单向（摘录 → 翻译），避免选中循环 |
| 列表行内 `译` | 一次性关联：把该条摘录送入翻译面板并触发翻译；之后仍各自独立 |
| 自动高亮框被点击 | 与行内 `译` 相同，送入摘录槽 |

### 3.3 翻译面板双槽位

- **整页槽**：整页原文/译文、OCR、译至、术语表、重译。
- **摘录槽**：当前选中摘录的原文/译文。
- 两个槽位分别保存文本，切换来源不互相覆盖。
- 来源切换条：`📄 整页` / `✍ 摘录`。
- 页级操作（OCR、整页翻译）会自动切回「整页」槽。

## 4. 自动高亮入口（P1）

- 自动高亮按钮从翻译面板迁到**摘录面板工具条**，与导出/批量清理同级。
- 单页：切换本页自动框选/清除。
- 右键菜单保留：整本文本层、整本含扫描页 OCR、取消整本、清除整本。
- 进度直接显示在按钮上：`⏳ 12/180`、`⏳ 12/180 OCR`。
- 列表行补充元信息：`自动` 标记、页码、`已译` 状态。

## 5. 学习工具（底部 3 入口）

| 入口 | 内容 |
| --- | --- |
| `✂ 跟读` | 本页跟读、整本跟读 |
| `🎧 音频` | 打开配套音频抽屉 |
| `✨ AI` | AI 总结、全文问答、生成大纲、导出笔记、批量 OCR；并收纳 `闪卡`、`加入学习` |

原先学习页的概览卡、固定行高卡片全部移除；统计信息收敛到摘录面板副标题（`本页 N · 全书 M`）。

## 6. 分阶段实施

### P1：自动高亮入口回归摘录面板

- `PdfHighlightPanel` 工具条新增 `🖍` 按钮，暴露 `AutoHighlightButton` 与 `UpdateAutoHighlightState`。
- `PdfReaderForm` 把点击、右键菜单、进度、清除状态改接到该按钮。
- 高亮列表按页排序；行内增加自动标记与译文状态。
- 验收：单页/双页/整本三种框选状态与按钮文案一致；构建通过。

### P2：工作台宿主与模块开关

- 新增 `PdfWorkbenchPanel`：模块开关、上下 `SplitContainer`、底部 3 入口、跟读/AI 菜单。
- 学习页签改为挂载工作台，摘录/翻译面板从音频抽屉迁入工作台。
- 音频抽屉只保留「配套音频 / 整页录音」。
- 原学习页卡片功能迁移：加入学习、闪卡、AI、跟读、音频。
- 验收：三种布局状态可切换；翻译面板可独立使用；旧入口全部可达；构建通过。

### P3：双槽翻译与显式联动

- `PdfTranslatePanel` 增加来源切换与双槽缓存。
- 新增 `ShowHighlightSource` / `ShowPageSource`；页级流程自动回到整页槽。
- `🔗` 联动：选中摘录单向送入翻译面板。
- 行内 `译` 与自动框点击：一次性关联并触发翻译。
- 译文回写高亮实体，列表刷新后显示 `已译`。
- 验收：联动关闭时两者互不影响；开启时选中即联动；切换来源不丢内容。

### P4：桌面细节与回归

- 双开时分隔条可拖动、最小高度约束、默认比例记忆。
- 窄宽度紧凑翻译布局（宽度 < 420 或高度不足时上下堆叠）。
- 模块可见性与联动状态写入侧栏状态文件。
- 键盘入口：`Ctrl+Shift+T` 切换翻译模块，`Ctrl+Shift+L` 切换联动。
- 深色模式：模块开关、分隔条、底部入口跟随主题。
- 回归：构建 + Core 测试全绿；手动验证扫描版 PDF 自动高亮、整本进度、联动、跟读。

### P5（后续可选）

- 翻译面板 `⧉ 弹出` 为独立工具窗口，供多显示器/宽屏用户使用。

## 7. 风险与约束

| 风险 | 处理 |
| --- | --- |
| 侧栏 322px 双开时翻译拥挤 | 紧凑布局 + 最小高度 + `AutoScroll` |
| 双槽状态互相覆盖 | 槽位字段独立，切换时保存/恢复，程序写入带抑制标志 |
| 面板重复挂载 | 工作台只 `AttachContent` 一次；从抽屉移除父级 |
| 选中联动死循环 | 仅单向联动 + 选中事件抑制标志 |
| 旧学习页功能丢失 | P2 逐项迁移到底部菜单；验收逐项点击 |
| 未提交的并行改动 | 保留原改动，只在其上增量修改 |

## 8. 不在本轮范围

- 弹窗式翻译面板（P5）。
- 分组/折叠摘录列表。
- 自动高亮双语覆盖、批量翻译。
- 学习页概览统计卡与动态行高卡片。
