# PDF 阅读器 · UI 重构方案

> 范围：`PdfReaderForm` 右侧信息侧栏（约 567px）+ 画布底部配套音频条
> 目标：减少页签层级与点击次数、合并被拆散的功能、让音频条只在有配套音频时出现
> 本文是设计方案，不包含代码改动。文末附完整功能入口对照表，确保重构不丢功能。

---

## 0. 设计上下文

| 项目 | 内容 |
| --- | --- |
| 用户 | 以 PDF 为主的学习者：一边阅读，一边翻译、标注、听配套音频、做跟读 |
| 核心任务链 | 找文件 → 阅读定位 → 标注 → 翻译/OCR → 沉淀到学习/AI → 听音频/跟读 |
| 使用环境 | Windows 桌面，鼠标 + 键盘，窗口可缩放，DPI 100%~200% |
| 技术约束 | WinForms 自绘 `TabControl`、侧栏固定 567px、播放条固定 64px |
| 视觉约束 | 沿用现有 `PdfSidebarTheme` 的紫色品牌色与浅色/夜间双主题，不重做配色体系 |
| 成功标准 | 侧栏只有一层导航；每个能力只有一个主入口；无音频文档不损失 64px 高度；全程可键盘操作 |

设计方法采用「先审计结构与任务流，再收敛表达与细节」的顺序，不先做装饰。

### 1.3 问题清单（按严重度）

| 级别 | 问题 | 影响 |
| --- | --- | --- |
| **P0** | 底部音频条无条件占据 64px | 没有配套音频的 PDF 也损失约 6% 的可视高度；阅读区变矮，长文档更明显 |
| **P0** | 导航最多三层 | 用户位置感丢失，返回/切换成本高 |
| **P1** | 顶层纯图标，含义依赖 320ms 悬停提示 | 每次找功能都先"猜图标"，违反识别优先于回忆 |
| **P1** | 功能解离、重复入口 | 跟读 3 个入口、OCR 2 个、加入学习 2 个，用户要先判断"从哪进" |
| **P1** | 跨页签强制跳转 | 音频页切书会跳到文件页，打断当前任务 |
| **P2** | 无页签快捷键、无页签记忆 | 高频切换只能反复点鼠标 |
| **P2** | 侧栏固定 567px、不可折叠 | 沉浸阅读时无法让出空间 |
| **P2** | 悬停切换会触发隐藏副作用 | 缩略图生成、学习统计刷新可能被误触发 |

### 1.4 功能解离地图

| 能力 | 当前散落位置 | 问题 |
| --- | --- | --- |
| 句子跟读 | 翻译操作条、学习「一键操作」、音频「句子跟读」子页 | 3 个入口，上下文不一致 |
| 音频播放 | 底部播放条、音频子页、翻译页朗读、跟读窗口 | 播放入口不唯一，用户不知道"哪个才是主播放器" |
| OCR | 翻译「整页识别」、学习「批量 OCR」 | 名称相近，范围不同，缺少说明 |
| 加入学习 | 翻译「加入学习」、学习「本页高亮全部加入学习」 | 名称近似，实际一个加译文、一个加高亮 |
| 音频配置 | 音频子页、书籍菜单、文件页切换 | 配置过程中被要求离开当前页 |
| AI 能力 | 学习页、翻译页（AI 润色） | 同为 AI 但分属不同页签，缺少统一入口 |

结论：问题不是"页签多"本身，而是**导航层、任务层、配置层混在一起**。重构应分层，而不是继续在现有页签上加折叠。

## 2. 设计方向

> 把侧栏从「5 个图标抽屉」改成「4 个工作阶段 + 1 个常驻媒体层」。

### 2.1 三层模型

| 层 | 职责 | 表现 |
| --- | --- | --- |
| L1 全局媒体层 | 只要有配套音频就出现，跨页签常驻 | 底部播放条（条件显示，64px） |
| L2 工作阶段层 | 用户当前在做什么 | 4 个带文字页签：目录 / 标注 / 翻译 / 学习 |
| L3 渐进配置层 | 低频设置与深度操作 | 卡片 + 右侧抽屉（音频绑定、规则、录音、跟读） |

判断规则：**每天用多次的放 L2，每周用一次的放 L3，持续存在的状态放 L1。**

### 2.2 设计原则

1. **一层导航**：侧栏内不再出现二级/三级导航页签；模式开关（如"按页/整篇"）不算导航。
2. **一个能力一个家**：跟读、OCR、加入学习各有唯一主入口，其他位置只做"跳转"不做"第二套 UI"。
3. **识别优先于回忆**：页签显示图标 + 2~3 字名称，不依赖悬停。
4. **空间随内容**：没有音频就不显示播放条；低频配置收进抽屉，不占常驻面积。
5. **桌面效率**：`Ctrl+1..4`、`Esc`、可见焦点、右键菜单；悬停只做预览不做默认切换。
6. **不打断任务**：配置音频、切换书籍等操作在当前上下文完成，不强制跳页签。

## 3. 信息架构

### 3.1 新顶层页签

| 页签 | 关键词 | 主要内容 | 原归属 |
| --- | --- | --- | --- |
| **目录** | 找 | 文件搜索、文件树、重命名/删除、缩略图（页头切换） | 阅读与视图 |
| **标注** | 记 | 5 色高亮、标注列表、编辑/删除/批量、导出 | 标注工具 |
| **翻译** | 懂 | 原文/译文双栏、翻译、整页 OCR、语言/术语表/语速、朗读 | 翻译与 OCR |
| **学习** | 沉淀 | 本页概览、快捷操作、AI 工具、本页学习项、配套音频卡片、录音与跟读 | AI 与文件工具 + 音频与录音 |

顺序对应工作流：定位 → 标记 → 理解 → 沉淀，用户可以用一句话记住侧栏。

### 3.2 旧 → 新映射

| 旧位置 | 新位置 | 处理方式 |
| --- | --- | --- |
| 阅读 → 文件/页面 | 目录 | 直接作为默认内容 |
| 阅读 → 缩略图 | 目录 → 页头「列表 / 缩略图」双图标切换 | 取消分段条；首次切换时才生成缩略图 |
| 标注工具 | 标注 | 原样保留，页头补「本页 N 条」 |
| 翻译与 OCR | 翻译 | 保留双栏与全部操作；移除「句子跟读」按钮 |
| 翻译「加入学习」 | 翻译 | 保留，改名「加入本页译文」，与学习页"加入高亮"区分 |
| 翻译「整页识别」 | 翻译 | 保留，作为 OCR 页级入口 |
| 学习「批量 OCR」 | 学习 | 保留，改名「批量识别导出」 |
| AI 与文件工具 | 学习 | 卡片保留并重排，AI 相关集中为「AI 工具」组 |
| 音频 → 配套音频 | 学习 → 配套音频卡片 + 音频抽屉 | 播放走底部播放条；绑定/曲目/规则/档案进抽屉 |
| 音频 → 整页录音 | 学习 → 录音与跟读卡片 → 抽屉模式 | 录音管理器改为挂载到抽屉内容宿主 |
| 音频 → 句子跟读 | 学习 → 一键操作「开始本页跟读」 | 删除独立子页，直接打开跟读窗口 |
| 音频 → 按页听/整篇听 | 音频抽屉顶部模式开关 | 仅抽屉内出现，作为播放模式而非导航 |
| 音频「在文件页切换书籍」 | 音频抽屉内书籍弹窗 | 不再强制跳到目录页 |

### 3.3 唯一入口规则

| 能力 | 唯一主入口 | 其他位置的允许行为 |
| --- | --- | --- |
| 句子跟读 | 学习 → 开始本页跟读 | 翻译/音频若保留按钮，只能调用同一入口并切到学习页，不复制 UI |
| 页级 OCR | 翻译 → 整页识别 | 学习页不重复提供单页 OCR |
| 批量 OCR | 学习 → 批量识别导出 | 明确标注"批处理"，与页级 OCR 区分 |
| 音频播放 | 底部播放条 | 抽屉内只做绑定/曲目管理，不复制播放控制 |
| 音频配置 | 学习 → 配套音频卡片 → 抽屉 | 目录/翻译页不再出现音频配置 |
| AI 总结/问答/大纲/导出 | 学习 → AI 工具组 | 翻译页的「AI 润色」保留为翻译动作 |

## 5. 底部配套音频条：只在有音频时出现

### 5.1 现状问题

播放条在音频管理器初始化后就创建并常驻，高度固定 64px（[PdfAudioPlayerBar.cs](../LearningAssistant.WinApp/Forms/Pdf/PdfAudioPlayerBar.cs#L77-L78)），而创建条件只检查音频侧栏是否存在（[PdfReaderForm.cs](../LearningAssistant.WinApp/Forms/Pdf/PdfReaderForm.cs#L509-L525)）。结果是：**没有配套音频的 PDF 也永久损失 64px 阅读高度**；有音频的文档在档案异步加载完成前又会先出现空条，随后内容再跳变。

### 5.2 显示判定

```
应显示 = 管理器存在
        && 档案已加载完成
        && Result 存在
        && Result.Tracks.Count > 0
```

补充规则：

- `Result == null`（加载中）→ 隐藏，不显示加载占位。
- `Tracks.Count == 0`（扫描不到音频）→ 隐藏。
- 有曲目但当前页未匹配 → **仍显示**，用于提示"本页未绑定"并提供绑定入口。
- 档案加载失败 → 隐藏，错误提示放在学习页的配套音频卡片里，不占用画布。
- 文档关闭/切换 → 立即隐藏，避免上一本文档的曲目残留。

### 5.3 状态矩阵

| 场景 | `Result` | 播放条 | 画布底部表现 |
| --- | --- | --- | --- |
| 无音频管理器 | - | 隐藏 | 仅状态栏 24px |
| 档案加载中 | null | 隐藏 | 无占位、无跳动 |
| 扫描到 0 首 | 0 首 | 隐藏 | 学习页卡片显示「未检测到配套音频」 |
| 有曲目、当前页未匹配 | >0 | 显示 | 曲名 + 「本页未绑定」+「绑定本页」 |
| 有曲目、当前页已匹配 | >0 | 显示 | 曲名 + 页码徽标 + 播放控件 |
| 正在播放 | >0 | 显示 | 进度、倍速、音量、AB 复读等保持现状 |
| 档案加载失败 | null | 隐藏 | 学习页卡片显示错误 + 重试/管理 |
| 用户手动收起（可选） | >0 | 隐藏 | 底部出现 24px「音频」小胶囊，可恢复 |

### 5.4 布局与动效

- 保持 `Dock = Bottom`、`Height = 64`；隐藏时设置 `Visible = false`，画布自动回收 64px。
- 显示/隐藏后调用 `_panelPdf.PerformLayout()`，刷新当前页位置，避免页码与滚动锚点错位。
- 推荐 120ms 高度过渡（可选）；若担心 WinForms 抖动，直接显隐也可以。**不做淡入淡出**，避免阅读时闪烁。
- 播放条始终位于状态栏之上；隐藏时状态栏不下移。
- 媒体快捷键（空格、方向键）仅在播放条可见且焦点在播放器/音频区域时生效，避免全局抢占。
- 重新显示时若正在播放，进度立即同步，不重置曲目。

### 5.5 无音频时的入口

不要用"灰色禁用的播放条"告诉用户没有音频，这会制造噪音。统一放在：

- 学习 → 配套音频卡片：`未检测到配套音频` + `[管理音频]`（打开抽屉，可添加目录/重新扫描）。
- 目录 → 文件右键菜单不新增音频项，保持目录只负责文件管理。

### 5.6 异步加载导致的晚出现

`LoadProfileAsync` 是异步且未等待完成的（[PdfReaderForm.cs](../LearningAssistant.WinApp/Forms/Pdf/PdfReaderForm.cs#L1663-L1668)），因此必须：

1. 文档打开时先隐藏播放条；
2. 订阅 `ProfileLoaded` / `SettingsChanged` / `TrackChanged`，统一调用 `UpdateAudioPlayerBarVisibility()`；
3. 绑定、手动匹配、重新扫描、导入档案后同样刷新；
4. 加载完成后只在"首次获得音频"时做一次 120ms 过渡，后续切页不重复动画。

### 5.7 实现草图（伪代码）

```csharp
private void UpdateAudioPlayerBarVisibility()
{
    if (_audioPlayerBar == null || _audioTrackManager == null) return;

    bool hasTracks = _audioTrackManager.Result?.Tracks.Count > 0;
    bool shouldShow = hasTracks && !_audioBarManuallyCollapsed;

    if (_audioPlayerBar.Visible == shouldShow) return;

    _audioPlayerBar.Visible = shouldShow;
    _panelPdf.PerformLayout();
    _audioPlayerBar.RefreshPage();
}

// 文档切换：先隐藏，等档案加载结果
public void SetCurrentPdfPath(string pdfPath, int pageCount = -1)
{
    _audioPlayerBar?.HideForDocumentSwitch();   // 内部 Visible = false
    // ...原有加载逻辑
}

// 事件
_audioTrackManager.ProfileLoaded += (_, _) => UpdateAudioPlayerBarVisibility();
_audioTrackManager.SettingsChanged += (_, _) => UpdateAudioPlayerBarVisibility();
_audioTrackManager.TrackChanged += (_, _) => UpdateAudioPlayerBarVisibility();
```

## 6. 交互与视觉规范

### 6.1 顶层页签

- 尺寸：宽度 `ClientSize.Width / 4`（下限 96px），高度 40px。
- 内容：图标 + 名称，水平居中；选中态为品牌色文字/图标 + 2px 下划线 + 浅底色。
- 快捷键：`Ctrl+1` 目录、`Ctrl+2` 标注、`Ctrl+3` 翻译、`Ctrl+4` 学习。
- 会话内记忆上次页签；文档切换保留。旧索引越界时回落「目录」。
- 无障碍：`AccessibleName` 使用完整中文名；`Tab` 可聚焦，左右方向键切换。

### 6.2 悬停策略

**默认不做"悬停即切换"。** 原因：

- 鼠标横向扫过页签会误切，阅读流程被打断；
- 切到目录可能触发缩略图生成，切到学习会刷新统计，悬停变成副作用触发器；
- 悬停不是键盘/辅助技术的可达路径；
- 内容面板切换若丢失滚动位置，用户会以为自己点错了。

若需要"悬停加速"，作为**可选开关，默认关闭**，并满足：

1. 只作用于顶层 4 个页签；
2. 稳定悬停 400ms 才切换，鼠标每次移动都重置计时；
3. 仅从侧栏外进入页签时启动；
4. 缩略图页排除在悬停切换之外；
5. 文本框聚焦、标注拖拽、抽屉打开、模态窗口打开时禁用；
6. 点击始终可用，悬停只是加速。

### 6.3 抽屉

- 宽 420px，右侧滑入 150ms；非模态，不遮画布。
- `Esc` 关闭；点击页签自动关闭；焦点进入抽屉首个控件，关闭后回到触发按钮。
- 抽屉内 `Tab` 顺序：关闭按钮 → 模式开关 → 当前曲目操作 → 书籍 → 列表。

### 6.4 主题、空状态与文案

- 新增控件全部接入 `ISidebarThemeAware.ApplyTheme`；浅色品牌色 `#7C3AED`，夜间 `#A78BFA`。
- 空状态沿用现有文案；新增：
  - 目录无文件：「还没有添加 PDF 文件」
  - 配套音频卡片无音频：「未检测到配套音频，点此添加目录或重新扫描」
  - 音频抽屉无曲目：「当前目录没有可识别的音频文件」
  - 翻译无原文：「本页还没有识别到原文，先执行整页识别」
- 所有图标按钮必须有 ToolTip，但不得只靠 ToolTip 传达核心含义。

### 6.5 视觉密度

- 侧栏保持 567px，用于翻译双栏；新增控件不提高整体密度。
- 卡片间距统一 8px，页头 44px，卡片圆角与现有 `SidebarCard` 一致。
- 支持 320~720px 拖动调整（可选）；双击分隔条恢复 567px。

## 7. 分阶段实施

### 阶段 0 · 音频条按需显示（优先做，收益最高、风险最低）

- `PdfReaderForm` 初始化后默认隐藏播放条。
- 新增 `UpdateAudioPlayerBarVisibility()`，接入 `ProfileLoaded` / `SettingsChanged` / `TrackChanged` 与文档切换。
- `SetCurrentPdfPath` 先隐藏，加载完成后再决定是否显示。
- 验收：无音频 PDF 的画布高度增加 64px；有音频 PDF 的播放、绑定、录音、跟读不受影响；切换文档无残留曲目。

### 阶段 1 · 页签减到 4 个并显示文字

- 自绘逻辑改为「图标 + 文字」，高度 40px，宽度 4 等分（下限 96px）。
- 顶层改为 目录 / 标注 / 翻译 / 学习；音频页先临时挂到学习页底部。
- 增加 `Ctrl+1..4` 与会话内页签记忆。
- 验收：100%/125%/150%/200% DPI 下文字不裁切、不换行；夜间模式可读。

### 阶段 2 · 拆掉二级/三级页签

- `PdfReadingSidebarPanel`：删除分段条，改为页头「列表/缩略图」切换器。
- `PdfAudioSidebarPanel`：不再创建；音频面板改挂抽屉宿主。
- 录音管理器 `MountTabPage` 由音频子页改为抽屉内容宿主。
- 跟读不再占子页，改由学习页按钮打开。
- 验收：侧栏内不存在二级/三级导航页签；音频绑定、录音、跟读均可达。

### 阶段 3 · 学习页整合与去重

- 学习页新增「配套音频」「录音与跟读」卡片。
- 移除翻译页「句子跟读」；「加入学习」改名「加入本页译文」；「批量 OCR」改名「批量识别导出」。
- 音频抽屉内切换书籍，不再调用 `ShowFilesTab()` 强制跳页。
- 验收：跟读只有 1 个主入口；OCR 页级/批量入口各 1 个且名称可区分。

### 阶段 4 · 抽屉与细节打磨

- 新增右侧抽屉宿主（非模态），完成打开/关闭、焦点、`Esc`、页签互斥。
- 页头统一为「图标 + 标题 + 状态 + 右侧主操作」。
- 可选：侧栏宽度可拖动、可折叠。
- 验收：抽屉打开时仍可翻页；播放条与抽屉状态同步；焦点闭环。

### 阶段 5 · 可选增强

- `Ctrl+K` 命令搜索（翻译/跟读/导出笔记/批量识别）。
- 「页签悬停切换」设置项（默认关闭，400ms 稳定悬停）。
- 页签记忆按文档持久化。

## 11. 风险与回退

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 档案异步加载晚于首屏 | 播放条晚出现，布局跳变 | 首屏隐藏；加载完成后一次性显示；120ms 过渡；不做骨架占位 |
| 删除音频页签后录音管理器仍按 `TabPage` 挂载 | 录音界面不显示 | 阶段 2 先把 `MountTabPage` 改为抽屉宿主，再删页签 |
| `ShowFilesTab()` 依赖顶层 TabControl | 书籍切换失效 | 改为抽屉内书籍弹窗；保留兼容访问方法 |
| 页签从 5 个减到 4 个，宽度变大 | 200% DPI 溢出 | 宽度按 `ClientSize.Width / 4` 且下限 96px；必要时两字截断 |
| 抽屉遮挡内容 | 用户找不到面板 | 抽屉仅覆盖右侧 420px，不遮画布；点击页签自动关闭 |
| 旧布局记忆指向已删除页签 | 打开后空白 | 读取旧索引时做范围校验，越界回落「目录」 |
| 悬停切换误操作 | 体验回退 | 默认关闭；400ms 稳定悬停；排除缩略图页；输入/拖拽/弹窗期间禁用 |

回退策略：阶段 0 可独立回退（只影响播放条显隐）；阶段 1~4 每阶段独立提交。若抽屉方案效果不佳，可先保留「学习」页内的音频卡片，暂不上抽屉。
