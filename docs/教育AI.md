# 教育AI全品类大盘点（2026，适配K12提分赛道视角）
按**底层垂类大模型、C端学生工具、AI教育硬件、校内智慧教学系统、海外主流教育AI**五大类划分，覆盖国内主流合规产品，区分K12提分刚需类与通用教学类。

## 一、国内教育垂直大模型（底层核心引擎）
专为中小学应试、解题、批改、学情诊断训练，区别于通用大模型，适配教材、中高考考点
1. **科大讯飞·星火教育大模型**
    教育赛道龙头，数学逻辑、口语测评、作文批改最强；服务5万+公立校，适配智慧课堂、学习机、中高考阅卷。
2. **学而思·九章MathGPT**
    理科专项天花板，手写公式识别、分步讲题、错题归因，小初高数理化全覆盖，主打提分专项训练。
3. **猿辅导·猿力（看云）大模型**
    题库数据海量，拍照搜题、个性化学习路径、五重错因分析，搭载小猿APP、墨水屏学练机。
4. **作业帮·银河大模型**
    C端工具流量第一，全科搜题、真题拆解、AI答疑、错题本自动化，家用提分工具核心底座。
5. **网易有道·子曰大模型**
    语言类优势突出：AI口语陪练、英语作文批改、古诗文解析，搭载词典笔、有道学习App。
6. **松鼠Ai自适应大模型**
    自适应学习标杆，依靠BKT知识追踪算法，精准诊断薄弱点，自动生成专属刷题提分方案。
7. **百度·文心一言（教育版）**
    大语文、教案生成、虚拟数字人授课，配套小度学习机，家校通用轻量化AI助手。
8. **其他垂类模型**
    超星汇雅（高校/中小学备课）、腾讯青少年大模型、GLM-Edu（学术开源）、九科星（区域公立校AI教学平台）

## 二、C端学生AI工具（K12提分赛道主流软件）
面向中小学生、家庭自主学习，合规替代传统学科补课，核心作用：刷题、诊断、专项提分
### 1. 搜题&错题AI工具（刚需流量入口）
- 作业帮App：AI搜题、错题自动归集、薄弱知识点专项练习、真题冲刺课
- 小猿AI（猿辅导）：自适应题库、AI讲题、分层刷题、中考/高考考点预测
- 夸克AI学习助手：免费全科答疑、文档解析、试卷整理、作文优化
- 快对：作业核对、整本书答案、错题打印配套工具

### 2. 单科专项AI（细分提分赛道）
- 英语类：有道词典、百词斩AI、Speak口语AI（发音测评、情景对话、作文批改）
- 数学类：九章理科讲题、松鼠Ai、几何AI绘图解题
- 语文类：AI作文批改、古诗文赏析、阅读理解答题模板生成

### 3. 自适应学习AI（精准提分核心）
松鼠Ai、精准学AI、小猿自适应系统：通过答题数据定位知识漏洞，自动删减无效题海，只推送薄弱题型，是当下提分赛道主流产品。

## 三、AI教育智能硬件（软硬件一体化提分终端）
全部搭载自研教育大模型，居家自主刷题、AI一对一辅导，双减后增长最快赛道
1. **AI学习机/学练机**
    - 科大讯飞学习机：星火模型，全科答疑、口语测评、校内同步、错题本
    - 小猿墨水屏学练机：护眼无纸化刷题，AI自动批改、生成提分计划
    - 学而思X系列学练机：九章数学模型，教材100%同步，理科专项拔高
    - 作业帮学习机、小度学习机、有道AI学习机
2. **AI词典笔**
    有道词典笔、讯飞翻译笔、新东方词典笔：单词扫读、长难句AI拆解、口语跟读测评
3. **配套小型硬件**
    AI错题打印机（小猿、作业帮）、AI自习台灯、听力复读机

## 四、B端校内智慧教育AI（公立学校课堂、教师工具）
服务学校、老师，用于课堂教学、作业批改、学情分析，校内提分数字化工具
1. **科大讯飞智慧课堂**：AI黑板、课堂实时答题、学情大数据、自动阅卷系统
2. **九科星AI教学平台**：智能组卷、分层作业、班级薄弱点可视化报表
3. **超星智慧教育**：AI备课、课件自动生成、课后测评系统
4. **国家智慧中小学AI工具**：官方免费，AI教案、理科讲题、综合素质评价

### 教师专用AI备课工具
豆包爱学、WPS灵犀、MagicSchool（海外）：一键生成教案、试卷、课后练习题、学生评语

## 五、海外主流教育AI（国际K12赛道）
1. **Khanmigo（可汗学院）**
    全球最知名AI全科导师，启发式讲题，不直接给答案，自适应学习路径，覆盖中小学全科
2. **Claude for Education**
    长文本教材解析、苏格拉底式辅导，高校与国际中学广泛使用
3. **Google Gemini教育套件**
    NotebookLM教材总结、课堂互动出题、Chromebook平板内置AI助教
4. **Quizlet AI**
    自动生成单词卡、专项习题、记忆曲线复习，语言学习刚需工具
5. **Grammarly教育版**：英文作文AI批改、语法逻辑优化，海外初高中标配写作工具

## 六、教育AI按功能分类（贴合K12提分赛道）
1. **AI自适应学习（核心提分）**：松鼠Ai、小猿自适应、Khanmigo——查漏补缺、定制刷题计划
2. **AI解题答疑**：作业帮、九章MathGPT、讯飞星火——全科讲题、步骤拆解
3. **AI智能测评批改**：讯飞阅卷、有道作文批改、口语AI打分——试卷/作文自动评分、错因分析
4. **AI备课教研**：超星、豆包爱学、文心教育——教案、试卷、课件一键生成
5. **语言学习AI**：词典笔、Speak、Grammarly——单词、口语、写作专项提升
6. **硬件终端AI**：学习机、墨水屏学练机——一体化居家提分设备

## 行业小结（结合之前K12提分赛道）
双减之后，传统线下学科班萎缩，**教育AI软件+智能硬件**成为提分赛道主力；核心逻辑是用自适应题库、AI诊断替代人工补课，主打“自主刷题、精准补差、高效提分”，也是资本当前重点布局方向。
