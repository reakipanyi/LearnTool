学习助手APP新增功能开发完整提示词（含新旧功能联动）
本次开发基于已有完整功能的PDF学习助手APP进行迭代升级，保留原有全部核心功能，新增多项学习、工具、数据可视化、语音交互、资源拓展类功能，重点实现AI与PDF内容编辑联动、各模块数据互通、配套技术栈落地，所有新增功能需完美适配原有架构，兼容现有学习数据、PDF阅读、AI助手、TTS语音、学习模式等模块。
一、APP原有保留核心功能（全部保留、兼容适配新功能）
1. PDF阅读器基础操作
支持PDF文件拖拽/菜单打开、页面导航、缩放控制；支持文字高亮标注（多色可选）、高亮记录管理；支持书签添加、书签快速跳转功能。
2. 文本翻译功能
支持PDF选中文本一键翻译、右键翻译；双语对照展示原文译文；支持原文/译文语音朗读；支持单词一键添加至生词本。
3. AI助手基础功能
支持联网智能问答、PDF文本智能总结、根据PDF内容自动生成练习题；通过AI面板输入提问、发送即可获取智能回复。
4. 多元化学习模式
覆盖英语单词、英语短语、英语句子、语文综合、古诗词、成语多类型学习；支持选择学习类型、启动学习、完成任务、查看基础学习进度与成就。
5. TTS语音合成功能
基于阿里云DashScope API Key配置，支持中英文选中文本朗读，可自定义调节朗读语速、音量，支持设置开关启用/禁用TTS功能。
二、重点新增核心功能（含联动逻辑、技术要求、使用场景）
1. AI智能提取PDF内容 + 内容编辑双向联动（核心重点）
基于原有PDF阅读器与AI助手模块深度联动，实现双向数据互通，具体需求如下：
- AI自动提取：支持AI一键提取当前PDF内的文字、知识点、重点段落、错题、考点、公式、名句等核心内容，自动分类整理，无需手动复制
- 编辑联动同步：用户在PDF内高亮、标注、修改、批注的内容，实时同步至AI数据库；AI提取整理后的内容，支持反向同步展示、编辑、保存至PDF对应位置
- 联动拓展：提取的PDF内容可直接用于AI总结、出题、知识点梳理、生成学习任务，打通PDF阅读与AI学习全流程
2. 网盘资源接入功能
集成百度网盘接口，实现学习资源便捷获取与导入：
- 支持用户授权登录百度网盘，直接在APP内浏览、检索网盘内PDF、学习资料、题库、课件等学习资源
- 支持网盘资源一键导入APP，直接打开阅读、加入学习列表、同步至本地学习库
- 支持将用户学习笔记、导出的报告、生词本、学习资料一键备份至百度网盘
3. 内置工具素材库（即拿即用学习素材）
- 名人名言库：内置海量分类名人名言（励志、学习、哲理、古今中外分类），支持搜索、复制、收藏，可插入学习笔记、PDF批注
- 数学公式库：覆盖小学至高中/大学常用数学公式，支持分类检索、可视化展示、一键复制、插入PDF笔记，配套公式释义、使用场景
- 科学知识卡片：内置物理、化学、生物、地理等理科知识点卡片，碎片化展示，支持收藏、随机学习、纳入学习计划
- 历史事件时间线：可视化历史时间轴，梳理中外重大历史事件，支持按朝代、年份检索，可关联语文、历史刷题学习
4. 记忆曲线学习系统
基于艾宾浩斯记忆曲线算法，联动生词本、单词、短语、公式、知识点学习模块：
- 自动记录用户每一个知识点、单词、公式的学习、复习时间
- 根据遗忘规律智能推送复习内容，精准安排复习计划
- 生成个人专属遗忘曲线数据，可视化展示记忆掌握程度
5. 学习计划与智能提醒系统
- 支持用户自定义添加学习计划：可设置学习类型、学习时长、学习内容、每日/每周学习目标
- 支持定时提醒、弹窗提醒，未完成计划自动记录，联动学习数据统计
- 支持计划完成状态标记、自动复盘，纳入学习报告统计
6. 学习数据可视化与数据分析系统
基于LiveCharts、ScottPlot双图表库开发，可视化展示全维度学习数据：
- 核心统计数据：实时统计每日/累计学习时长、刷题正确率、知识点掌握率、单词记忆量、复习完成率
- 可视化图表：生成学习时长趋势图、正确率走势图、遗忘曲线对比图、知识点掌握分布图
- 智能分析：自动分析薄弱知识点、遗忘高发内容、学习短板，给出优化建议
7. 学习报告生成功能
- 支持自动生成每日学习报告、每周学习报告
- 报告包含：学习时长、学习内容、正确率、复习情况、遗忘数据、成就进度、薄弱点总结、次日学习建议
- 支持报告预览、保存、导出、分享
8. 智能语音交互系统（新增语音能力）
基于Azure Speech、百度语音识别双接口适配，兼容原有TTS朗读功能：
- 实时语音识别：支持语音输入提问AI、语音录入笔记、语音查单词/公式/知识点
- 听写评分系统：支持中英文听写练习，自动识别听写内容、校对答案、评分纠错，标注错误点位
- 联动原有TTS朗读，实现“听-读-听写-评分”闭环语音学习
9. 文本智能纠错功能
- 实时拼写检查：对用户笔记、输入文本、听写内容、生词本备注进行中英文实时拼写、语法纠错
- 错误标红提示，提供修正建议，支持一键替换正确内容
10. 数据导入导出与分享功能增强
- 学习内容导入导出升级：支持生词本、学习笔记、错题、学习计划、报告批量导入/导出（通用格式）
- 成就分享：支持将学习成就、学习报告、打卡成果生成图片/文字格式，一键复制、保存、分享
- 词库分享平台集成：支持用户上传自制词库、下载全网共享词库，支持词库预览、收藏、一键导入学习
11. 数学公式专项学习模块
依托内置数学公式库，搭建专属学习练习体系：
- 支持公式背诵、公式释义学习、公式专项练习题
- 结合记忆曲线推送公式复习，统计公式掌握正确率
- 联动PDF提取功能，自动识别PDF内公式，加入公式学习列表
三、指定技术栈要求
本次新增功能全部基于 CefSharp 框架开发适配，兼容原有APP内核，所有新增模块、接口、图表、语音、网盘功能均需适配CefSharp运行环境，保证软件运行流畅、无冲突、兼容旧版本数据。
四、整体开发规则
1. 完全保留原有所有功能，新旧模块无缝融合，UI风格统一，操作逻辑一致
2. 所有学习数据（时长、正确率、记忆数据、计划数据）全局互通，统一统计、统一展示、统一生成报告
3. AI、PDF编辑、学习模块、语音模块、数据模块深度联动，实现数据实时同步
4. 所有第三方接口（阿里云TTS、百度网盘、Azure/百度语音）支持开关配置、密钥自定义设置
5. 功能轻量化设计，保证软件启动、运行、加载无卡顿


# AI 功能集成提示词（简洁版）
## 核心需求
为现有PDF学习助手新增以下功能，与原有PDF阅读、标注、翻译、AI助手、学习模式、TTS功能无缝联动：

1. **PDF内容联动**
AI提取PDF文本/高亮/书签，支持一键编辑、整理、生成学习素材

2. **CefSharp浏览器集成**
内置浏览器窗口，直接抓取网页学习内容，导入学习库

3. **百度网盘对接**
连接网盘获取学习资源，支持PDF/文档直接打开、导入

4. **首页模块**
展示励志名人名言，每日自动更新

5. **学习管理**
- 学习计划+定时提醒
- LiveCharts/ScottPlot绘制学习进度图表
- 学习时长、正确率、遗忘曲线数据分析
- 每日/每周学习报告生成

6. **语言学习增强**
- 实时拼写检查
- 听写功能+自动评分
- 学习内容导入/导出优化

7. **学科学习扩展**
- 数学公式学习与练习题
- 科学知识卡片
- 历史事件时间线

## 技术要求
基于现有应用架构开发，界面统一、功能联动、稳定兼容
