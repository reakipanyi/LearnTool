 
我想合并两个项目到一个项目里面，功能可以结合使用也可以单独使用，界面要求能自适应窗口，TTS 统一使用QwenTts，PDF阅读工具里面也可以融合AI的功能进行提问，目前界面使用不够友好，需要优化。
结合内容帮我设计提示词，才能让AI工具不跑偏，设计编码一步到位。不需要反复修改调试。

 
## 两个项目的功能描述

---

### 一、BilingualLearningTool（双语智能学习工具）

**项目定位**：基于 .NET 8/6 Core + WinForms + MVP 架构开发的桌面端双语综合学习控制台工具。

#### 核心功能

| 功能模块 | 详细描述 |
|---------|---------|
| **两大学习品类** | - 中文学习：汉字识字、汉字组词、成语识记、常用短语、古诗词背诵<br>- 英语学习：英语单词、常用短语、基础句子认读 |
| **两种学习模式** | - **快速模式**：全量内容摸底测试，快速自检掌握度，仅做会/不会标记<br>- **学习模式**：针对未掌握内容深度学习，调用AI接口获取释义、音标、发音、例句 |
| **多玩家进度** | 支持新建/切换多个玩家，每人独立记录已掌握清单，数据以JSON持久化 |
| **自动保存** | 支持Ctrl+C强制退出、程序关闭时自动保存学习进度，杜绝数据丢失 |
| **启动记忆** | 自动恢复上次用户、模式、语言品类、子类、词库、排序、语音开关等设置 |
| **语音朗读** | 本地中英文TTS语音朗读，学习模式配合AI发音辅助跟读 |
| **学习统计** | 自动统计测试时长、掌握数量、正确率，支持对未掌握内容集中复习 |
| **AI接口集成** | 输入字词/句子，输出详细释义、拼音/音标、发音朗读、例句、用法搭配，支持本地缓存 |

#### 界面组成
- **主界面 (MainForm)**：用户选择、语言选择、学习类型选择、模式选择、进度摘要展示
- **学习界面 (StudyForm)**：超大文字显示区、会/不会/下一个按钮、进度条、AI释义面板
- **设置界面 (SettingForm)**：AI接口配置、字体大小、朗读声音选择、词库路径选择
- **结果统计界面 (ResultForm)**：正确率、已会/未会列表、复习按钮

#### 数据持久化文件
- `config.json`：系统设置（AI配置、字体大小、语音开关等）
- `settings.json`：用户级会话设置（上次用户、模式、语言品类等）
- `user_{用户名}.json`：用户独立进度（已掌握列表、未掌握列表、历史测试结果）

### 二、KidWinApp（PDF阅读学习助手）

**项目定位**：面向儿童的PDF阅读器，集成OCR识别、语音朗读、翻译等学习功能。

#### 核心功能

| 功能模块 | 详细描述 |
|---------|---------|
| **PDF阅读** | - 支持文件夹浏览，树形结构展示PDF文件<br>- 异步页面渲染与缓存，支持翻页、缩放<br>- 自动记忆上次打开的文件和页码 |
| **图片划词OCR** | - 在PDF图片上框选区域进行OCR文字识别<br>- 自动调用百度翻译API进行中英互译 |
| **语音朗读** | - 支持多种TTS服务（QwenTTS、Coqui、Index等）<br>- 可调节朗读速度<br>- 双击文本区域即可朗读 |
| **语音听写** | 打开独立听写窗口，支持语音识别输入，可保存听写内容 |
| **标注功能** | - 在PDF页面上绘制红线/黄高亮标记<br>- 标注持久化保存，每页独立管理 |
| **翻译服务** | 集成百度翻译API，支持OCR识别文字的即时翻译 |
| **音频播放** | 集成VLC音频服务，支持播放TTS生成的音频文件 |

#### 技术架构
- **PDF处理**：使用PdfiumPdfService进行PDF渲染和文本提取
- **OCR引擎**：集成Tesseract引擎进行光学字符识别
- **TTS支持**：QwenTTS（阿里云）、CoquiTTS、IndexTTS等多种语音合成服务
- **翻译服务**：百度翻译API
- **音频播放**：VLC媒体播放器集成

#### 界面特点
- 大字体展示，适合儿童使用
- 鼠标滚轮缩放、翻页操作
- Ctrl+滚轮缩放预览
- 手型光标设计，模拟"手指点读"交互

#### 配置文件 (`appsettings.json`)
```json
{
  "Baidu": { "AppId": "...", "SecretKey": "..." },
  "QwenTts": { "Key": "...", "Endpoint": "..." },
  "Vlc": { "LibPath": "..." }
}
```

- **底部状态栏**：显示当前TTS服务（QwenTTS/Coqui等），音频播放状态。

## 数据持久化与交互说明（不写代码但提供原型逻辑）

- 主窗体启动时自动加载 `config.json` 和 `settings.json`，同时读取所有 `user_*.json` 并显示在玩家列表中。
- **学习窗体**的进度条刷新会实时保存至当前用户的 JSON 文件（自动保存间隔或点击按钮时触发）。
- 设置窗体的所有选项立即生效并写回 config/settings。
- PDF 标注保存为每页一个独立 XML/JSON 文件，存储在 `%AppData%\KidWinApp\Annotations`。
- OCR 识别结果支持一键复制和语音朗读，调用百度翻译 API 时自动使用本地缓存减少请求。
