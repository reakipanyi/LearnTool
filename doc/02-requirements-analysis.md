# LearningAssistant 需求分析文档

> **文档说明**：对需求挖掘结果进行过滤、冲突识别、边界场景分析和约束汇总。

---

## 一、需求有效性过滤

| 需求编号 | 需求描述 | 有效性判断 | 理由 |
|---------|---------|-----------|------|
| R-001 ~ R-020 | 已识别的 20 项显性需求 | ✅ 全部有效 | 代码中均有对应实现，为产品核心功能 |
| I-001 ~ I-010 | 已识别的 10 项隐性需求 | ✅ 全部有效 | 均有代码支撑，是系统必要能力 |
| - | **多用户社交功能**（好友、排行榜） | ❌ 过滤 | 当前代码中只有本地多用户切换，无社交属性 |
| - | **在线课程/视频播放** | ❌ 过滤 | 产品定位为知识记忆辅助工具，非课程平台 |
| - | **实时多人协作学习** | ❌ 过滤 | 桌面单机应用，无协作基础设施 |

## 二、需求冲突识别

| 冲突编号 | 冲突描述 | 涉及需求 | 冲突类型 | 严重程度 | 建议方案 |
|---------|---------|---------|---------|---------|---------|
| C-001 | 本地文件存储 vs 数据库存储并存 | R-016 数据分析 / I-007 数据迁移 | 架构冲突 | 🔴 高 | 按 `UNIFIED_EXECUTION_PLAN` 分阶段迁移，保留兼容层 |
| C-002 | 多种间隔重复算法（SM2/FSRS）并存 | R-003 间隔重复 | 功能重叠 | 🟡 中 | 统一算法选型，FSRS 为推荐，SM2 为兼容 |
| C-003 | 多个学习入口重复（学习页/错题本/收藏夹/路径） | R-001/R-008/R-010/R-013 | 体验冲突 | 🟡 中 | 统一学习引擎入口，不同来源走相同学习流程 |
| C-004 | AI 能力多面板分散（AI问答/导师/费曼/渐进提示） | R-004 AI 增强 | 功能分散 | 🟡 中 | 整合 AI 能力面板，统一对话入口 |
| C-005 | TTS 多引擎但缺乏统一协调 | R-015 TTS 语音 | 架构冲突 | 🟠 中高 | 已通过 `ISpeechCoordinator` 解决（Phase 2 中） |

## 三、边界场景识别

| 场景编号 | 边界场景描述 | 影响模块 | 风险等级 | 当前处理状态 |
|---------|-------------|---------|---------|-------------|
| B-001 | 学习项数量巨大（>10万条）时的加载性能 | 学习引擎 / 数据层 | 🔴 高 | 部分缓存，未做分页/虚拟列表 |
| B-002 | 离线状态下 AI / 云同步 / 在线 TTS 不可用 | AI服务 / 云存储 / TTS | 🟠 中高 | 本地 KokoroSharp TTS 可降级，AI 无降级 |
| B-003 | 多用户数据隔离与切换 | 用户系统 | 🟡 中 | 有 UserId 字段，但 UI 切换不完善 |
| B-004 | 学习过程中程序崩溃/意外退出 | 崩溃恢复 | 🟡 中 | 有 CrashRecoveryService，但恢复粒度待验证 |
| B-005 | PDF 超大文件（>500MB）渲染性能 | PDF 模块 | 🟡 中 | 依赖 PdfiumViewer，未做懒加载优化 |
| B-006 | 并发写入冲突（多实例同时运行） | 数据持久化 | 🟠 中高 | 有 RowVersion 但主要针对 LearningItem |
| B-007 | 极低配置机器运行本地 AI/TTS | AI / TTS | 🟡 中 | KokoroSharp 支持 CPU 模式，但性能无保障 |
| B-008 | 数据迁移过程中断电/崩溃 | 数据迁移 | 🔴 高 | 迁移事务性待确认 |

## 四、约束条件汇总

| 约束类型 | 约束项 | 具体内容 | 影响范围 |
|---------|-------|---------|---------|
| **技术约束** | 框架版本 | .NET 10 + WinForms | 全系统 |
| **技术约束** | 数据库 | SQLite + EF Core | 数据层 |
| **技术约束** | 平台 | Windows 桌面（net10.0-windows7.0） | 部署运行 |
| **技术约束** | 架构模式 | MVP（Presenter 层已存在） | UI 层 |
| **性能约束** | 启动时间 | 桌面应用期望 < 3s | 启动流程 |
| **性能约束** | 学习项加载 | 万级数据量下 < 1s 响应 | 学习引擎 |
| **兼容性约束** | 数据格式 | 需兼容旧版 JSON 格式数据 | 数据迁移 |
| **兼容性约束** | 操作系统 | Windows 7 及以上 | 部署运行 |
| **资源约束** | 内存占用 | 常规使用 < 500MB | 全系统 |
| **安全约束** | 敏感配置 | API Key 等需加密存储 | 配置系统 |
| **开源约束** | 许可证 | EPPlus 非商业授权 / 各开源组件许可证 | 商业化限制 |
