# LearningAssistant 需求全流程总结

> **文档说明**：汇总需求分析全流程的核心结论与后续建议。

---

## 一、各阶段核心产出

| 阶段 | 核心产出 | 关键发现 |
|------|---------|---------|
| **需求挖掘** | 20项显性需求 + 10项隐性需求 | 产品功能丰富，但入口分散 |
| **需求分析** | 5项需求冲突 + 8个边界场景 + 10项约束 | 数据存储架构正在转型（JSON→SQLite） |
| **业务梳理** | 4类用户角色 + 3条核心流程 + 8个用户痛点 | 学习入口不统一、AI能力分散是主要体验痛点 |
| **方案设计** | 6层架构 + 18个模块 + 25项功能 + 4维验收标准 | 推荐按DDD重构，统一学习引擎入口 |

---

## 二、关键风险与应对

| 风险项 | 风险等级 | 影响范围 | 应对建议 |
|-------|---------|---------|---------|
| 数据迁移过程中的数据丢失 | 🔴 高 | 全系统 | 保留旧 JSON 兼容层，分阶段迁移，迁移前全量备份 |
| 学习项大数据量加载性能 | 🔴 高 | 学习引擎 | 引入分页、虚拟列表、索引优化、缓存策略 |
| 移动端缺失限制使用场景 | 🔴 高 | 产品战略 | 长期规划 Web/移动端，短期支持数据导出到移动端 |
| AI 离线不可用 | 🟠 中高 | AI 模块 | 设计本地离线题库/提示模板作为降级方案 |
| 多实例并发写入冲突 | 🟠 中高 | 数据层 | 完善 RowVersion 并发控制，限制单实例运行或加文件锁 |
| AI/TTS 多引擎维护成本 | 🟡 中 | 基础设施 | 统一接口抽象，降低厂商切换成本 |

---

## 三、后续建议优先级

### P0 - 立即执行

1. **架构重构**：按 `UNIFIED_EXECUTION_PLAN.md` 推进实体聚合重构，完成 JSON→SQLite 的数据持久化转型
2. **统一学习引擎入口**：将错题本、收藏夹、学习路径等不同来源的学习内容统一接入 `StudyEngine`
3. **大数据量性能优化**：为学习项加载引入分页/虚拟列表，避免全量加载到内存

### P1 - 短期规划

4. **AI 能力整合**：将问答、导师、费曼、渐进提示整合为统一的 AI 侧边栏或对话入口
5. **游戏化体验增强**：优化即时反馈、成就触发、彩纸庆祝等细节，提升学习动力
6. **数据安全与备份**：增加自动本地备份、增量备份机制，降低数据丢失风险

### P2 - 中长期规划

7. **智能推荐升级**：结合知识图谱、错题本、薄弱点分析，构建个性化学习推荐
8. **多平台规划**：评估 Web/移动端技术选型，制定跨平台数据同步方案
9. **数据分析深化**：增加学习效率评估、遗忘曲线分析、学习建议生成
